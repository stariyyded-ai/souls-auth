## Лекция

В разных вариантах ТЗ встречаются «дополнительные» функции: отзыв о выполненной услуге, фото до/после, аватар, документ к заявке. Почти всегда это **загрузка файла**. Сегодня сделаем отзыв с фотографией к выполненной заявке — и разберём, почему загрузка файлов считается одной из самых опасных функций сайта.

**Почему это опасно.** Если сервер сохранит загруженный файл как есть, злоумышленник загрузит не `photo.jpg`, а `shell.php` с кодом, откроет `http://сайт/uploads/shell.php` — и получит управление сервером. Поэтому у загрузки есть железные правила:

1. Проверять код ошибки загрузки.
2. Ограничивать размер.
3. Определять тип файла **по содержимому**, а не по расширению и не по тому, что прислал браузер.
4. Придумывать имя файла **самим** (случайное), с расширением по реальному типу.
5. Запретить выполнение скриптов в папке загрузок.

**Как загрузка выглядит в HTML.** Форма обязательно с `method="post"` и `enctype="multipart/form-data"` — без этого атрибута файл просто не уйдёт на сервер (самая частая ошибка):

```html
<form method="post" enctype="multipart/form-data">
    <input type="file" name="photo" accept="image/jpeg,image/png,image/webp">
</form>
```

`accept` лишь фильтрует выбор в окне браузера, защитой не является.

**Как файл выглядит в PHP.** Файлы приходят не в `$_POST`, а в `$_FILES`:

```php
<?php
// $_FILES['photo'] после загрузки:
// [
//   'name'     => 'IMG_2031.jpg',          // имя у пользователя — НЕ доверяем
//   'type'     => 'image/jpeg',            // прислал браузер — НЕ доверяем
//   'tmp_name' => 'C:\xampp\tmp\php1A2B.tmp',  // временный файл на сервере
//   'error'    => 0,                       // UPLOAD_ERR_OK
//   'size'     => 245113,                  // размер в байтах
// ]
```

PHP сохраняет файл во временную папку и удаляет его после окончания скрипта. Наша задача — проверить и переместить его в `uploads/` функцией `move_uploaded_file()`.

**Коды ошибок.** `UPLOAD_ERR_OK` (0) — всё хорошо; `UPLOAD_ERR_NO_FILE` (4) — файл не выбран (для необязательного фото это нормально); `UPLOAD_ERR_INI_SIZE` (1) — файл больше `upload_max_filesize` из `php.ini` (в XAMPP по умолчанию 40 МБ, но лучше ограничить своим лимитом).

**Тип по содержимому.** Расширение `.jpg` можно приписать чему угодно. Класс `finfo` читает «подпись» в начале файла и возвращает настоящий MIME-тип:

```php
<?php
$mime = (new finfo(FILEINFO_MIME_TYPE))->file($_FILES['photo']['tmp_name']);
// 'image/jpeg', 'image/png', 'text/x-php' ...
```

Если XAMPP пишет `Class "finfo" not found` — откройте `C:\xampp\php\php.ini`, найдите строку `;extension=fileinfo`, уберите `;` и перезапустите Apache.

**Структура данных.** Добавим таблицу отзывов (одна заявка — один отзыв):

```sql
CREATE TABLE reviews (
  id         INT AUTO_INCREMENT PRIMARY KEY,
  request_id INT NOT NULL UNIQUE,
  text       TEXT NOT NULL,
  photo      VARCHAR(100) NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (request_id) REFERENCES requests(id)
) ENGINE=InnoDB;
```

В базе храним **только имя файла**, а сам файл лежит в папке `uploads/`. Хранить картинки в базе (BLOB) для такого портала неудобно и медленно.

**Защита папки `uploads/`.** Файл `uploads/.htaccess` запрещает Apache выполнять в ней PHP, даже если такой файл туда как-то попадёт:

```apache
# uploads/.htaccess — в папке загрузок скрипты не выполняются
<FilesMatch "\.(php\d?|phtml|phar)$">
    Require all denied
</FilesMatch>
Options -Indexes
```

`Options -Indexes` запрещает просмотр списка файлов папки. Это второй рубеж; первый — наши проверки.

**Новая страница `review.php`.** Для вариативной части структура дополняется одним файлом — это нормально. Ссылку «Оставить отзыв» показываем в `requests.php` у выполненных заявок: `<a href="review.php?id=<?= e($r['id']) ?>">`.

**Полный файл `review.php`:**

```php
<?php
require_once __DIR__ . '/includes/auth.php';
require_user();

const MAX_PHOTO_SIZE = 2 * 1024 * 1024;   // 2 МБ
const PHOTO_TYPES = ['image/jpeg' => 'jpg', 'image/png' => 'png', 'image/webp' => 'webp'];

$user = current_user();
$id = (int)($_GET['id'] ?? 0);

// Заявка должна быть своей и выполненной
$stmt = $pdo->prepare(
    'SELECT r.id, r.status, s.name AS service_name
     FROM requests r JOIN services s ON s.id = r.service_id
     WHERE r.id = ? AND r.user_id = ?'
);
$stmt->execute([$id, $user['id']]);
$request = $stmt->fetch();
if (!$request || $request['status'] !== 'done') {
    set_flash('danger', 'Отзыв можно оставить только к своей выполненной заявке.');
    redirect('requests.php');
}

$stmt = $pdo->prepare('SELECT text, photo, created_at FROM reviews WHERE request_id = ?');
$stmt->execute([$id]);
$review = $stmt->fetch();

$errors = [];
$text = '';

if ($_SERVER['REQUEST_METHOD'] === 'POST' && !$review) {
    check_csrf();
    $text = post('text');
    if (mb_strlen($text) < 10 || mb_strlen($text) > 1000) {
        $errors['text'] = 'Текст отзыва — от 10 до 1000 символов';
    }

    $photoName = null;
    $file = $_FILES['photo'] ?? null;
    if (is_array($file) && is_int($file['error']) && $file['error'] !== UPLOAD_ERR_NO_FILE) {
        if ($file['error'] !== UPLOAD_ERR_OK) {
            $errors['photo'] = 'Не удалось загрузить файл (код ' . $file['error'] . ')';
        } elseif ($file['size'] > MAX_PHOTO_SIZE) {
            $errors['photo'] = 'Файл больше 2 МБ';
        } else {
            $mime = (new finfo(FILEINFO_MIME_TYPE))->file($file['tmp_name']);
            if (!isset(PHOTO_TYPES[$mime])) {
                $errors['photo'] = 'Можно загрузить только JPG, PNG или WEBP';
            } else {
                $photoName = bin2hex(random_bytes(16)) . '.' . PHOTO_TYPES[$mime];
            }
        }
    }

    if (!$errors) {
        if ($photoName !== null
            && !move_uploaded_file($file['tmp_name'], __DIR__ . '/uploads/' . $photoName)) {
            $errors['photo'] = 'Не удалось сохранить файл на сервере';
        } else {
            $stmt = $pdo->prepare('INSERT INTO reviews (request_id, text, photo) VALUES (?, ?, ?)');
            $stmt->execute([$id, $text, $photoName]);
            set_flash('success', 'Спасибо за отзыв!');
            redirect('review.php?id=' . $id);
        }
    }
}

$title = 'Отзыв о заявке №' . $id;
require __DIR__ . '/includes/header.php';
?>
<div class="row justify-content-center">
<div class="col-md-8 col-lg-6">
    <h1 class="h4 mb-3">Отзыв о заявке №<?= e($id) ?>: <?= e($request['service_name']) ?></h1>

    <?php if ($review): ?>
        <div class="card">
            <?php if ($review['photo'] !== null): ?>
                <img src="uploads/<?= e($review['photo']) ?>" class="card-img-top" alt="Фото к отзыву">
            <?php endif; ?>
            <div class="card-body">
                <p class="card-text"><?= nl2br(e($review['text'])) ?></p>
                <p class="small text-muted mb-0"><?= e(format_dt($review['created_at'])) ?></p>
            </div>
        </div>
    <?php else: ?>
        <form method="post" enctype="multipart/form-data">
            <?= csrf_field() ?>
            <div class="mb-3">
                <label class="form-label" for="text">Ваш отзыв</label>
                <textarea class="form-control<?= isset($errors['text']) ? ' is-invalid' : '' ?>"
                          id="text" name="text" rows="5" required><?= e($text) ?></textarea>
                <?php if (isset($errors['text'])): ?>
                    <div class="invalid-feedback"><?= e($errors['text']) ?></div>
                <?php endif; ?>
            </div>
            <div class="mb-3">
                <label class="form-label" for="photo">Фото (необязательно, JPG/PNG/WEBP до 2 МБ)</label>
                <input class="form-control<?= isset($errors['photo']) ? ' is-invalid' : '' ?>"
                       type="file" id="photo" name="photo" accept="image/jpeg,image/png,image/webp">
                <?php if (isset($errors['photo'])): ?>
                    <div class="invalid-feedback"><?= e($errors['photo']) ?></div>
                <?php endif; ?>
            </div>
            <button class="btn btn-primary w-100" type="submit">Отправить отзыв</button>
        </form>
    <?php endif; ?>
    <p class="mt-3"><a href="requests.php">&larr; К моим заявкам</a></p>
</div>
</div>
<?php require __DIR__ . '/includes/footer.php'; ?>
```

Ключевые моменты.

- Права проверяются запросом `WHERE r.id = ? AND r.user_id = ?` — нельзя оставить отзыв к чужой заявке, подставив другой `id` в адрес.
- Имя файла — 32 случайных шестнадцатеричных символа + расширение **по реальному типу**. Имя пользователя (`$file['name']`) нигде не используется: в нём могут быть `../`, русские буквы, пробелы или `.php`.
- Файл перемещается только после того, как **все** проверки пройдены; запись в базу — только после успешного перемещения.
- `nl2br(e(...))` — сначала экранируем, потом превращаем переносы строк в `<br>`. Наоборот нельзя: `e()` испортит `<br>`.
- При повторной отправке (`$review` уже есть) POST игнорируется: одна заявка — один отзыв (и `UNIQUE` в базе это подстрахует).

**Типичные ошибки.**

- `$_FILES` пустой — нет `enctype="multipart/form-data"`.
- `move_uploaded_file(): failed to open stream` — нет папки `uploads/` или неверный путь (используйте `__DIR__`).
- Проверка по `$_FILES['photo']['type']` — его присылает браузер, подделывается за секунду.
- Картинка не показывается — в `src` указан полный путь диска `C:\...` вместо адреса `uploads/имя.jpg`.
- Загруженные файлы попали в Git — забыли `uploads/` в `.gitignore` (но `uploads/.htaccess` в репозиторий добавить нужно: `git add -f uploads/.htaccess`).

**Связь с экзаменом.** Вариативная часть ТЗ отличается от варианта к варианту, а приём «загрузка + проверка + случайное имя + запрет выполнения» универсален. Аспект «безопасность ИС» эксперт может проверить, попытавшись загрузить `.php` вместо картинки.

## Задание

**Цель:** реализовать безопасную загрузку фотографии к отзыву о выполненной заявке.

**Ход работы:**

1. Создайте таблицу `reviews` (SQL из лекции), добавьте запрос в `database.sql`.

3. Проверьте, что расширение `fileinfo` включено (`php.ini`), при необходимости включите и перезапустите Apache.
4. Создайте `review.php` по образцу. В `requests.php` у заявок со статусом «Выполнена» добавьте кнопку «Оставить отзыв» / «Мой отзыв».
5. Оставьте отзыв с фото JPG и отзыв без фото. Проверьте файлы в `uploads/` (случайные имена) и строки в `reviews`.
6. Тесты безопасности:
   - переименуйте текстовый файл в `photo.jpg` и загрузите — отказ;
   - загрузите файл больше 2 МБ — отказ;
   - откройте `review.php?id=` с номером чужой заявки и заявки в статусе «Новая» — отказ с сообщением;
   - положите в `uploads/` файл `test.php` с `<?php echo 'hello';` и откройте его в браузере — должна быть ошибка 403. Удалите файл.
7. Коммит «ЛР31: отзывы с фото».

**Что сдать:** `review.php`, `uploads/.htaccess`, обновлённые `requests.php` и `database.sql`, скриншоты отзыва с фото и результатов тестов из п. 6.

## Критерии оценки

| Аспект | 2 балла | 1 балл | 0 баллов |
|---|---|---|---|
| Загрузка работает | Фото сохраняется и показывается в отзыве, отзыв без фото тоже работает | Работает только с фото | Не работает |
| Проверка файла | Код ошибки, размер, MIME через `finfo` | Проверка только по расширению или `type` | Проверок нет |
| Имя и хранение | Случайное имя с расширением по типу, в БД только имя | Имя пользователя сохраняется как есть | Файл в БД или вне `uploads/` |
| Защита папки | `.htaccess` запрещает PHP, тест с `test.php` пройден | `.htaccess` есть, но не проверен | Нет |
| Права доступа | Отзыв только к своей выполненной заявке, один раз | Нет одной проверки | Отзыв можно оставить к любой заявке |
