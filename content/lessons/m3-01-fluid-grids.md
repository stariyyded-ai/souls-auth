Адаптивная вёрстка — это не отдельный сайт для телефона, а одна страница, которая перестраивается под ширину экрана.

## Метатег viewport

Без него телефон рисует страницу шириной 980px и уменьшает её. Он нужен на каждой странице:

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

## Медиазапросы

```css
.gear { display: grid; grid-template-columns: repeat(3, 1fr); gap: 16px; }

@media (max-width: 600px) {
  .gear { grid-template-columns: 1fr; }
}
```

Внутри медиазапроса — правила, которые сработают только на узких экранах.

## Главные враги адаптива

- фиксированная ширина в пикселях: `width: 960px` → замени на `max-width: 960px`;
- картинки без `max-width: 100%`;
- длинные строки без переноса и таблицы — оборачивай таблицу в блок с `overflow-x: auto`.

Проверяй страницу на ширине 360px: так выглядит большинство телефонов.

:::quiz
? Зачем метатег viewport?
- [x] Чтобы телефон не уменьшал страницу, а рисовал её по своей ширине
- [ ] Чтобы страница грузилась быстрее
- [ ] Чтобы поисковик нашёл страницу
> Без него мобильный браузер притворяется экраном шириной 980px.

? Шапка задана как `width: 960px` и вылезает на телефоне. Что поменять?
- [ ] width: 360px
- [x] max-width: 960px
- [ ] overflow: hidden у body
> max-width ограничивает сверху и не мешает сжиматься.

? Как сделать, чтобы широкая таблица не растягивала страницу?
- [ ] Уменьшить шрифт до 8px
- [x] Обернуть в блок с overflow-x: auto
- [ ] Убрать половину колонок
> Таблица прокручивается в своей обёртке, а страница остаётся на месте.
:::
