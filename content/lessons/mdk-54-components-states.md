## Коротко о теории

**Компонент** — повторяющаяся часть интерфейса с одним назначением: кнопка, поле, карточка врача, слот времени, уведомление. В Figma это компонент с вариантами, в коде — класс CSS и разметка, которую копируют.

**Состояние** — то, как компонент выглядит и ведёт себя в конкретный момент. Состояния бывают двух уровней:

| Уровень | Примеры состояний | Пример |
|---|---|---|
| **Компонент** | обычное, наведение, фокус, нажато, выбрано, выключено, ошибка, загрузка | Слот 10:30 — «занято» (выключен) |
| **Экран** | загрузка, данные есть, данных нет (пусто), ошибка, успех | «Мои записи» без единой записи |

Состояние экрана «пусто» называют **пустым состоянием** (empty state). Его часто забывают нарисовать, и пользователь видит белый экран без подсказки. Хорошее пустое состояние объясняет, почему пусто, и предлагает действие: «У вас пока нет записей. **Записаться к врачу**».

Для экранного диктора состояния тоже нужно «озвучить» атрибутами **ARIA** (вы встречали `aria-label`, `aria-expanded`, `aria-invalid`):

| Состояние | Как сказать браузеру и диктору |
|---|---|
| Выключено | атрибут `disabled` |
| Выбрано (кнопка-переключатель) | `aria-pressed="true"` / `"false"` |
| Текущая страница в меню | `aria-current="page"` |
| Ошибка в поле | `aria-invalid="true"` и `aria-describedby="id-сообщения"` |
| Сообщение о результате | `role="status"` — диктор прочитает изменение вслух |

> Частая ошибка: показывать состояние только цветом. Занятый слот серого цвета человек с плохим зрением не отличит от свободного. Добавляйте второй признак: зачёркивание, иконку, слово «занято».

### Шаг 4. Слоты времени — задание 1 на сайте

Слот — кнопка, которую можно «выбрать». Состояние «выбрано» хранится в атрибуте `aria-pressed`, а CSS оформляет его селектором по атрибуту:

```html
<style>
  .slot { min-height: 48px; padding: 0 16px; font-size: 16px; border: 2px solid #1f5f8b; border-radius: 8px; background-color: #ffffff; color: #1f5f8b; }
  .slot[aria-pressed="true"] { background-color: #1f5f8b; color: #ffffff; }
  .slot:disabled { background-color: #eaeef2; color: #57606a; border-color: #8c959f; text-decoration: line-through; cursor: not-allowed; }
</style>
<button class="slot" type="button" aria-pressed="true">09:00</button>
<button class="slot" type="button" aria-pressed="false" disabled>09:30</button>
<button class="slot" type="button" aria-pressed="false">10:00</button>
<script>
  const slots = document.querySelectorAll('.slot');
  for (const slot of slots) {
    slot.addEventListener('click', () => {
      for (const other of slots) other.setAttribute('aria-pressed', 'false');
      slot.setAttribute('aria-pressed', 'true');
    });
  }
</script>
```

09:00 выбран (синий), 09:30 занят (серый, зачёркнут), 10:00 свободен. Нажмите 10:00 — выбор переедет. На 09:30 нажать нельзя: у выключенной кнопки событие click не срабатывает.

> **Попробуйте сами.** Уберите из правила `.slot:disabled` строку `text-decoration: line-through`. Представьте, что вы не различаете цвета: понятно ли теперь, какой слот занят? Верните зачёркивание.

### Шаг 5. Экран входа по отчёту — задание 2 на сайте

Это самое большое задание занятия. Исправляйте строго по отчёту из шага 3, пункт за пунктом:

1. **Подписи.** Над каждым полем — `<label for="…">`. Placeholder можно убрать: подпись важнее.
2. **Настоящая кнопка.** `div` нельзя выбрать клавишей Tab и нажать Enter. Замените его на `<button class="btn" type="submit">Войти</button>`, а в JavaScript слушайте не click по кнопке, а **submit у формы** — так форма отправится и мышью, и клавишей Enter в поле.
3. **Видимый фокус.** Удалите `outline: none`, добавьте правило с `:focus-visible`.
4. **Понятные ошибки.** Каждая ошибка стоит в своём `<p class="error" id="…">` под полем, а поле ссылается на неё: `aria-describedby="policy-error"`. Диктор, попав в поле, прочитает и подпись, и ошибку. Полю с ошибкой ставим `aria-invalid="true"`, исправленному — `"false"`.
5. **Сообщение об успехе.** У `#status` атрибут `role="status"`: когда в нём меняется текст, диктор читает его вслух.

Схема проверки одного поля — та же, что на занятии 30:

```js
const policyOk = policy.value.trim().length === 16;
policyError.textContent = policyOk ? '' : 'Номер полиса — 16 цифр. Он напечатан на лицевой стороне полиса.';
policy.setAttribute('aria-invalid', policyOk ? 'false' : 'true');
```

Запись `условие ? A : B` читается «если условие верно — A, иначе — B». Если номер верный, текст ошибки пустой, иначе — подсказка.

### Шаг 6. Пустое состояние — задание 3 на сайте

Блок пустого состояния есть в HTML с самого начала, но скрыт атрибутом `hidden`. Когда последняя запись удалена, JavaScript прячет пустой список и показывает блок:

```js
item.remove();
const left = list.querySelectorAll('.item').length;
count.textContent = left;
if (left === 0) {
  list.hidden = true;
  empty.hidden = false;
}
```

`item.remove()` удаляет элемент со страницы целиком. Ловушка та же, что на занятии 50: у `.empty` в CSS `display: flex`, и без правила `.empty[hidden] { display: none; }` блок будет виден всегда.
