## Что такое CSS

**CSS** (Cascading Style Sheets) — каскадные таблицы стилей. Это язык, которым описывают, **как выглядит** страница: цвета, шрифты, отступы, рамки, расположение блоков. Вспомните сравнение с домом из первого занятия: HTML — стены и комнаты, CSS — отделка и мебель.

Почему не делать всё в HTML? Раньше так и делали: был тег `<font color="red">`, атрибуты `bgcolor` и `align`. Получался ад. Чтобы поменять цвет заголовков на сайте из 50 страниц, нужно было исправить 50 файлов, а в каждом — десятки тегов. Поэтому договорились разделить:

- **HTML** отвечает за смысл: это заголовок, это список, это форма;
- **CSS** отвечает за вид: заголовки — тёмно-синие, списки — без точек, форма — с рамкой.

Одна и та же разметка может выглядеть совершенно по-разному с разными стилями. И наоборот: один файл стилей оформляет все страницы сайта сразу. На демоэкзамене оценивают именно так: разметка семантическая, всё оформление — в CSS.

Слово «каскадные» значит, что правила могут накладываться друг на друга, как струи воды в каскаде, и браузер по особым законам решает, какое победит. Этим законам посвящено следующее занятие.

## Как устроено CSS-правило

Вы уже видели CSS-правило на прошлой практике. Разберём его по частям:

```css
h1 {
  color: #1f4e79;
  text-align: center;
}
```

- `h1` — **селектор**: кого оформляем. Здесь — все заголовки первого уровня.
- `{ … }` — **блок объявлений** в фигурных скобках.
- `color: #1f4e79;` — **объявление**: **свойство** `color` (цвет текста), двоеточие, **значение** `#1f4e79`, точка с запятой.

Объявлений в правиле сколько угодно, каждое заканчивается точкой с запятой. Пробелы и переносы строк браузеру не важны: можно написать и в одну строку `h1 { color: #1f4e79; text-align: center; }`. Но в несколько строк читать удобнее, особенно когда свойств много.

Комментарии в CSS пишутся так: `/* это комментарий */`. Не так, как в HTML!

Что делает браузер с ошибками? Он их **молча пропускает**. Написали `colr: red` — браузер не знает такого свойства и просто не применит его. Никаких сообщений, просто цвет не поменялся. Поэтому в редакторе заданий работает линтер: он подчёркивает такие места красным.

Частые ошибки:

- **забыли точку с запятой**: `color: red text-align: center;` — браузер решит, что значение цвета — «red text-align: center», и выбросит оба объявления;
- **пробел между числом и единицей**: `font-size: 16 px` — ошибка, правильно `16px`;
- **не закрыли фигурную скобку** — сломаются все следующие правила;
- **по-русски**: `color: красный` — браузер понимает только английские названия.

## Три способа подключить CSS

### Способ 1. Атрибут style

Стиль пишется прямо в теге, в атрибуте `style`. Вы видели его на занятии 4:

```html
<p style="color: #8e1f14; font-weight: bold;">Внимание! Завтра пар не будет.</p>
<p>Обычный абзац.</p>
```

Что вы увидите: первый абзац тёмно-красный и жирный, второй — обычный.

Здесь нет селектора: стиль относится только к этому одному элементу. Из-за этого атрибут `style` — худший способ:

- стиль приходится копировать в каждый элемент;
- чтобы поменять цвет всех предупреждений, надо найти и исправить каждое;
- HTML превращается в кашу из разметки и оформления.

На этом курсе автопроверка считает атрибут `style` ошибкой качества. Его используют разве что программы на JavaScript, когда что-то двигают на странице.

### Способ 2. Тег style

Правила пишутся в теге `<style>`, который ставят в `head` страницы. Стили действуют на всю эту страницу:

```html
<style>
  p { color: #1f4e79; }
  h1 { text-align: center; }
</style>
<h1>Расписание звонков</h1>
<p>Первая пара: 8:30–10:00.</p>
<p>Вторая пара: 10:10–11:40.</p>
```

Что вы увидите: заголовок по центру, оба абзаца тёмно-синие. Одно правило оформило все абзацы сразу.

(В песочнице `style` стоит прямо перед разметкой, чтобы пример работал сам. В настоящем файле его место — внутри `head`.)

Уже лучше, но если на сайте пять страниц, каждой нужен свой `style` с одинаковыми правилами. Поменять цвет — снова пять правок.

### Способ 3. Внешний файл и тег link

Правила пишутся в отдельном файле с расширением `.css`, например `css/style.css`. Каждая страница подключает его тегом `<link>` в `head`:

```text
<head>
  <meta charset="utf-8">
  <title>Кафе «Пенка»</title>
  <link rel="stylesheet" href="css/style.css">
</head>
```

- `rel="stylesheet"` — «это таблица стилей»;
- `href` — путь к файлу, такой же относительный путь, как у ссылок и картинок.

А в файле `style.css` — только правила, без тегов:

```css
/* css/style.css — стили всего сайта */
body {
  font-family: Arial, sans-serif;
  color: #222222;
}
h1 {
  color: #6b3e1f;
}
```

Это **правильный способ**. Один файл оформляет весь сайт: поменяли цвет в одном месте — он поменялся на всех страницах. Браузер скачивает файл один раз и запоминает (кэширует), поэтому остальные страницы открываются быстрее. А HTML остаётся чистым.

| Способ | Где пишем | На что действует | Когда использовать |
|---|---|---|---|
| Атрибут `style` | В теге | Один элемент | Почти никогда |
| Тег `<style>` | В `head` страницы | Одна страница | Быстрый пример, песочница |
| Файл через `<link>` | В `style.css` | Весь сайт | Всегда в реальных проектах и на экзамене |

Частая ошибка: файл стилей не подключился. Проверьте путь в `href` (папка `css/`?), имя файла (`style.css` или `styles.css`?) и что `link` стоит в `head`. Если стили «не работают вообще», почти всегда дело в пути.

В заданиях курса вкладка CSS — это и есть ваш файл `style.css`: сайт сам подключает его к странице.

> **Попробуйте сами.** Нажмите «Попробовать» под примером с расписанием звонков. Поменяйте цвет абзацев на `#8e1f14`. Потом допишите второму абзацу атрибут `style="color: green;"`. Чей цвет победил — правила из `style` или атрибута?

## Селекторы: кого оформляем

Селектор выбирает элементы, к которым применится правило. Сегодня — три главных вида.

### Селектор тега

Имя тега без скобок: `p`, `h1`, `li`, `a`. Выбирает **все** такие элементы на странице.

```css
p { line-height: 1.5; }
```

Удобно для общих правил: все абзацы, все заголовки.

### Селектор класса

А если нужно выделить не все абзацы, а только некоторые — например, предупреждения? Даём им **класс**: атрибут `class` в HTML. В CSS класс пишется **с точкой**:

```html
<style>
  .warning { color: #8e1f14; font-weight: bold; }
</style>
<p>Столовая работает с 9:00.</p>
<p class="warning">Завтра столовая закрыта.</p>
<p>Библиотека работает до 18:00.</p>
<p class="warning">Сдайте книги до пятницы.</p>
```

Что вы увидите: четыре абзаца, второй и четвёртый — тёмно-красные и жирные.

Свойства класса:

- один класс можно дать **сколько угодно** элементам, даже разным тегам: `<li class="warning">` тоже станет красным;
- у одного элемента может быть **несколько классов** через пробел: `class="warning big"`;
- имя класса пишут латиницей, по смыслу: `warning`, `price`, `card`. Не по виду: `red-text` плохо — завтра дизайнер сделает предупреждения оранжевыми, и имя станет враньём.

Частая ошибка: поставить точку в HTML (`class=".warning"`) или забыть её в CSS (`warning { … }` — браузер будет искать несуществующий тег `<warning>`).

Классы — главный инструмент вёрстки. На реальных сайтах почти все правила пишут через классы.

### Селектор id

Вы знаете `id` по якорям. В CSS его пишут **с решёткой**: `#special`. Он выбирает один-единственный элемент, ведь `id` на странице уникален.

```html
<style>
  #special { font-size: 20px; text-align: center; }
</style>
<p>Меню на неделю.</p>
<p id="special">Блюдо дня: тыквенный суп</p>
```

Что вы увидите: второй абзац крупнее и по центру.

На практике `id` для стилей используют редко: правило нельзя применить ко второму такому же элементу, и у `id` слишком «сильный» вес в каскаде (об этом — на следующем занятии). Правило верстальщиков: **`id` — для якорей и подписей форм, классы — для стилей**.

| Селектор | Пишется | Выбирает | Пример |
|---|---|---|---|
| Тега | `p` | Все такие теги | `p { … }` |
| Класса | `.имя` | Все элементы с этим классом | `.price { … }` |
| id | `#имя` | Один элемент с этим `id` | `#special { … }` |

Если нескольким селекторам нужны одинаковые свойства, их перечисляют через запятую: `h1, h2, h3 { color: #1f4e79; }`.

## Цвета

Цвет текста задаёт свойство `color`, цвет фона — `background-color`. Значение цвета можно записать по-разному.

**Название.** В CSS больше 140 английских названий: `red`, `white`, `black`, `tomato`, `navy`. Удобно для быстрых проб, но оттенков мало, и в настоящих макетах их не используют.

**HEX** (шестнадцатеричный код). Решётка и шесть символов: `#1f4e79`. Это три пары: сколько красного (`1f`), зелёного (`4e`) и синего (`79`), от `00` (нисколько) до `ff` (максимум). Цифры здесь — от 0 до 9 и буквы от a до f.

- `#000000` — чёрный (ничего не светит);
- `#ffffff` — белый (всё на максимум);
- `#ff0000` — чистый красный.

Если пары одинаковые, можно сократить: `#ffffff` = `#fff`, `#336699` = `#369`. Именно HEX-коды вы будете копировать из Figma, поэтому это самый частый способ.

**RGB.** Те же три канала, но числами от 0 до 255: `rgb(31, 78, 121)` — это тот же цвет, что `#1f4e79`. Браузер внутри всё равно переводит цвета в такой вид.

```html
<style>
  .a { color: navy; }
  .b { color: #1f4e79; }
  .c { color: rgb(31, 78, 121); }
  .d { color: #ffffff; background-color: #1f4e79; }
</style>
<p class="a">Цвет по названию: navy</p>
<p class="b">Цвет в HEX: #1f4e79</p>
<p class="c">Тот же цвет в RGB</p>
<p class="d">Белый текст на синем фоне</p>
```

Что вы увидите: первые три строки — оттенки тёмно-синего (вторая и третья совершенно одинаковые), четвёртая — белая на синей полосе.

Про другие модели цвета, прозрачность и подбор палитр поговорим на занятиях 38–39. А одно правило запомните уже сейчас: **текст должен хорошо читаться**. Светло-серый на белом и жёлтый на белом — плохо. По правилам доступности контраст обычного текста с фоном — не меньше 4,5 к 1. Автопроверка на сайте следит за этим в каждом задании.

## Шрифт и текст

| Свойство | Что задаёт | Пример |
|---|---|---|
| `font-family` | Шрифт | `font-family: Georgia, serif;` |
| `font-size` | Размер | `font-size: 18px;` |
| `font-weight` | Жирность | `font-weight: bold;` или `700` |
| `font-style` | Курсив | `font-style: italic;` |
| `line-height` | Межстрочный интервал | `line-height: 1.5;` |
| `text-align` | Выравнивание | `text-align: center;` |

**`font-family`** — список шрифтов через запятую. Браузер берёт первый, который есть на компьютере. Последним всегда пишут **общее семейство** — запасной вариант:

- `serif` — шрифт с засечками (как в книгах);
- `sans-serif` — без засечек (как на большинстве сайтов);
- `monospace` — моноширинный, все буквы одной ширины (для кода).

Если в названии шрифта есть пробелы, его берут в кавычки: `font-family: "Times New Roman", serif;`. Как подключить красивый шрифт, которого нет на компьютере, разберём на занятии 20.

**`font-weight`** — жирность: `normal` (то же, что `400`) или `bold` (`700`). Бывают и промежуточные `300`, `500`, `600`, если они есть у шрифта.

**`line-height`** — высота строки. Пишут обычно числом без единиц: `1.5` значит «в полтора раза больше размера шрифта». Для основного текста на сайте хорошо от 1.4 до 1.6: строки не слипаются, и глаз не теряет, где следующая. Частая ошибка — оставить текст «как есть»: по умолчанию строки слишком плотные для длинного чтения.

**`text-align`** — выравнивание: `left` (по левому краю, обычное), `center`, `right`, `justify` (по ширине). По центру хорошо выравнивать короткие заголовки и подписи, но не длинные абзацы: глазу трудно искать начало каждой строки. А `justify` на сайтах даёт неровные дыры между словами — лучше не использовать.

```html
<style>
  h1 { font-family: Georgia, serif; text-align: center; }
  p { font-family: Arial, sans-serif; font-size: 18px; line-height: 1.5; }
  .note { font-style: italic; font-weight: bold; }
</style>
<h1>Новое меню кафе «Пенка»</h1>
<p>С понедельника в кафе у колледжа появятся сырники, тыквенный суп и какао с зефиром.</p>
<p class="note">Студентам с билетом — скидка 10%.</p>
```

Что вы увидите: заголовок с засечками по центру, абзацы без засечек, крупные и с просторными строками; последний — жирным курсивом.

> **Попробуйте сами.** В примере выше поменяйте `line-height: 1.5` на `1` и на `2.5`. Какой текст читать удобнее? Потом поменяйте `text-align: center` у заголовка на `right`.

## Единицы измерения: px, %, em, rem

Размеры в CSS пишут числом с единицей, без пробела.

**`px`** — пиксели, точки экрана. Понятная абсолютная единица: `16px` — всегда 16 пикселей. В Figma все размеры тоже в пикселях.

**`%`** — проценты от родителя. `width: 50%` — половина ширины блока, в котором лежит элемент. Для размера шрифта `150%` — в полтора раза больше шрифта родителя.

**`em`** — относительно размера шрифта. `2em` у элемента с шрифтом 16px — это 32px. Удобно для отступов, которые должны расти вместе с текстом. Ловушка: `em` наследуется и умножается. Список в списке с `font-size: 0.8em` будет всё мельче и мельче.

**`rem`** (root em) — относительно шрифта **корня** страницы, тега `html`. По умолчанию это 16px, поэтому `1rem` = 16px, `1.5rem` = 24px, `2rem` = 32px. Никаких умножений: `rem` всегда от одного и того же числа.

Зачем относительные единицы, если пиксели понятнее? Многие люди со слабым зрением увеличивают шрифт в настройках браузера: 16px по умолчанию превращаются в 20px. Размеры в `rem` вырастут вместе с ними, а в `px` — останутся мелкими. Поэтому популярное правило: **размеры шрифтов — в `rem`, тонкие детали вроде рамок — в `px`**.

```html
<style>
  h1 { font-size: 2rem; }
  p { font-size: 1.125rem; }
  .small { font-size: 0.875rem; }
</style>
<h1>Заголовок 2rem = 32px</h1>
<p>Основной текст 1.125rem = 18px</p>
<p class="small">Примечание 0.875rem = 14px</p>
```

Что вы увидите: три строки разного размера. Если в настройках браузера увеличить шрифт, вырастут все три.

Как перевести пиксели из макета в `rem`: разделите на 16. 24px → 1.5rem, 20px → 1.25rem, 14px → 0.875rem.

## Главное за занятие

- CSS описывает вид страницы. HTML — смысл, CSS — оформление.
- Правило = селектор + `{ свойство: значение; }`. Ошибки браузер молча пропускает.
- Подключать CSS правильно внешним файлом: `<link rel="stylesheet" href="css/style.css">` в `head`. Атрибут `style` — худший способ.
- Селекторы: тега `p`, класса `.price` (главный инструмент), id `#special` (редко).
- Цвета: названия, HEX `#1f4e79`, RGB `rgb(31, 78, 121)`. Текст должен быть контрастным.
- Шрифт: `font-family` с запасным семейством, `font-size`, `font-weight`, `line-height` около 1.5, `text-align`.
- Единицы: `px` — абсолютные, `%` — от родителя, `em` — от шрифта, `rem` — от шрифта страницы (16px).

## Словарик

- **CSS** — язык описания внешнего вида страницы.
- **Правило** — селектор и блок объявлений в фигурных скобках.
- **Селектор** — указание, к каким элементам применить правило.
- **Свойство** — что меняем: цвет, размер, шрифт.
- **Значение** — каким делаем: `#1f4e79`, `18px`, `center`.
- **Класс** — имя для группы элементов, атрибут `class`; в CSS пишется с точкой.
- **HEX** — запись цвета шестнадцатеричным кодом: `#ff6600`.
- **rem** — единица размера, равная шрифту корня страницы (обычно 16px).

## Если осталось время

Сделайте в песочнице «визитку в трёх стилях». Напишите один и тот же HTML (имя, абзац о себе, список навыков) и три разных набора правил `<style>`: строгий (шрифт с засечками, тёмно-синий), весёлый (крупный шрифт, яркие цвета с хорошим контрастом), минималистичный (чёрный текст, много воздуха, `line-height: 1.8`). Убедитесь, что HTML при этом не меняется.

:::quiz
? Как правильно подключить внешний файл стилей?
- [ ] `<style src="style.css">`
- [x] `<link rel="stylesheet" href="style.css">` в `head`
- [ ] `<script href="style.css">`
> Внешние стили подключают тегом `link` с `rel="stylesheet"`.

? Что здесь селектор: `.price { color: #1d5c3a; }`?
- [x] `.price`
- [ ] `color`
- [ ] `#1d5c3a`
> Селектор стоит перед фигурными скобками и говорит, кого оформлять. `color` — свойство, `#1d5c3a` — значение.

? Как выбрать в CSS все элементы с `class="warning"`?
- [ ] `warning { … }`
- [ ] `#warning { … }`
- [x] `.warning { … }`
> Класс пишется с точкой, id — с решёткой, тег — без знаков.

? Что случится с правилом `p { color: red font-size: 20px; }`?
- [ ] Абзацы станут красными и крупными
- [x] Ни цвет, ни размер не применятся: пропущена точка с запятой
- [ ] Браузер покажет сообщение об ошибке
> Без `;` браузер видит одно непонятное значение и молча выбрасывает объявление.

? Какой цвет записан кодом `#ffffff`?
- [ ] Чёрный
- [ ] Красный
- [x] Белый
> Все три канала (красный, зелёный, синий) на максимуме — `ff` — дают белый.

? Почему размеры шрифтов советуют задавать в `rem`?
- [x] Они растут, если человек увеличил шрифт в настройках браузера
- [ ] `rem` работает быстрее, чем `px`
- [ ] В `px` нельзя задать размер шрифта
> `rem` считается от шрифта корня страницы, а его меняют настройки браузера.

? Зачем в `font-family: Georgia, serif;` слово `serif`?
- [ ] Оно делает текст жирным
- [x] Это запасной вариант: любой шрифт с засечками, если Georgia нет
- [ ] Без него Georgia не загрузится
> Браузер идёт по списку слева направо и берёт первый найденный шрифт.

? Какое значение `line-height` удобнее всего для длинного текста на сайте?
- [ ] `0.8`
- [ ] `1`
- [x] `1.5`
> Межстрочный от 1.4 до 1.6 не даёт строкам слипаться.
