## Что такое DOM

Когда браузер читает HTML, он строит из тегов **дерево объектов**. Каждый тег становится объектом-**узлом**: у него есть родитель, дети, текст, атрибуты. Это дерево называется **DOM** (Document Object Model, объектная модель документа).

```html
<main>
  <h1>Кофейня «Зерно»</h1>
  <p>Открыто с 8:00</p>
</main>
```

В DOM это выглядит так:

```
document
└── html
    └── body
        └── main
            ├── h1  → «Кофейня „Зерно“»
            └── p   → «Открыто с 8:00»
```

JavaScript работает не с текстом HTML-файла, а с этим деревом. Поменяли что-то в DOM — браузер сразу перерисовал страницу. Сам файл при этом не меняется: обновите страницу, и всё вернётся как было.

Главный объект — `document`, это вся страница. Через него мы ищем элементы.

## Найти элемент: querySelector

`document.querySelector('селектор')` находит **первый** элемент, подходящий под CSS-селектор. Селекторы те же, что вы пишете в CSS:

```js
const title = document.querySelector('h1');          // по тегу
const card = document.querySelector('.card');        // по классу
const button = document.querySelector('#order');     // по id
const link = document.querySelector('nav a');        // потомок
```

Найденный элемент кладём в переменную через `const`: сам элемент не поменяется, мы будем менять только его содержимое.

Если ничего не нашлось, `querySelector` вернёт `null` — «пусто». Частая ошибка: опечатка в селекторе или забытая точка у класса (`'card'` вместо `'.card'`). Тогда следующая строка упадёт с ошибкой `TypeError: Cannot read properties of null`. Увидели слово `null` в ошибке — проверьте селектор.

Если элементов несколько и нужны **все**, используйте `document.querySelectorAll`. Он возвращает список, по которому удобно пройти циклом `for…of` с прошлого занятия:

```js
const buttons = document.querySelectorAll('.size');
for (const button of buttons) {
  console.log(button.textContent);
}
```

## Поменять текст: textContent

Свойство `textContent` — текст внутри элемента. Его можно прочитать и записать:

```html
<p id="status">Кофейня закрыта</p>
<script>
  const status = document.querySelector('#status');
  console.log(status.textContent);        // Кофейня закрыта
  status.textContent = 'Кофейня открыта!';
</script>
```

Что увидите: на странице сразу написано «Кофейня открыта!». Старый текст скрипт успел прочитать и вывести в консоль, а потом заменил.

`textContent` вставляет именно **текст**: если записать туда `<b>Привет</b>`, на странице так и появятся угловые скобки. Это хорошо: если текст пришёл от пользователя, он не сможет подсунуть на страницу свой HTML.

## Классы: classList

Менять внешний вид прямо из JavaScript (через стили) неудобно. Правильный путь: **описать оформление в CSS через класс, а в JavaScript только добавлять или убирать класс**.

```js
const card = document.querySelector('.card');
card.classList.add('selected');      // добавить класс
card.classList.remove('selected');   // убрать класс
card.classList.toggle('selected');   // нет — добавить, есть — убрать
card.classList.contains('selected'); // есть ли класс: true или false
```

В CSS при этом заранее описан вид:

```css
.card.selected {
  border-color: #8a3b12;
  background: #fff4e8;
}
```

Запись `.card.selected` без пробела значит «элемент, у которого есть **оба** класса». Так дизайн остаётся в CSS, а логика — в JS. Частая ошибка: писать точку в `classList.add('.selected')`. Точка нужна только в селекторах, а имя класса — без неё.

## Показать и скрыть: hidden

У любого HTML-элемента есть атрибут `hidden`: элемент с ним не показывается. В JavaScript это логическое свойство:

```js
const answer = document.querySelector('#answer');
answer.hidden = true;     // спрятать
answer.hidden = false;    // показать
answer.hidden = !answer.hidden;   // переключить: было true — станет false
```

Скрытый через `hidden` элемент не видят ни глазами, ни программы экранного доступа. Это удобнее, чем добавлять класс со `display: none`.

Осторожно: если в CSS для элемента задан `display` (например, `display: flex`), он перебивает `hidden`, и элемент не спрячется. Тогда добавьте в CSS правило `[hidden] { display: none; }`.

## События и addEventListener

**Событие** — то, что происходит на странице: щелчок мышью, нажатие клавиши, ввод текста, отправка формы. JavaScript может «подписаться» на событие и выполнить код, когда оно случится. Для этого есть `addEventListener`:

```html
<button id="hello" type="button">Поздороваться</button>
<p id="out"></p>
<script>
  const button = document.querySelector('#hello');
  const out = document.querySelector('#out');

  button.addEventListener('click', function () {
    out.textContent = 'Привет! Рады видеть вас на курсе.';
  });
</script>
```

Что увидите: пока кнопку не нажали, абзац пустой. Нажали — появилось приветствие.

Разберём строку `button.addEventListener('click', function () { … })`:

- `button` — на каком элементе ждём событие;
- `'click'` — какое событие;
- `function () { … }` — **обработчик**: функция без имени, которую браузер вызовет при каждом щелчке. Сами мы её не вызываем.

Частая ошибка — написать имя функции со скобками: `addEventListener('click', show())`. Тогда функция выполнится сразу, при загрузке, а не по щелчку. Если обработчик — готовая функция с именем, передаём её **без скобок**: `addEventListener('click', show)`.

### Пример: счётчик

```html
<p>Чашек кофе за сегодня: <span id="cups">0</span></p>
<button id="add" type="button">+1 чашка</button>
<script>
  const cups = document.querySelector('#cups');
  const add = document.querySelector('#add');
  let count = 0;

  add.addEventListener('click', function () {
    count = count + 1;
    cups.textContent = count;
  });
</script>
```

Что увидите: каждое нажатие увеличивает число на странице на 1. Переменная `count` объявлена через `let` и **снаружи** обработчика: она живёт всё время, пока открыта страница, и помнит старое значение. Если объявить её внутри функции, при каждом щелчке она будет создаваться заново с нулём.

> **Попробуйте сами.** Добавьте кнопку «Сбросить», которая кладёт в `count` ноль и обновляет число на странице.

### Пример: показать или скрыть

```html
<button id="toggle" type="button" aria-expanded="false">Показать расписание</button>
<p id="schedule" hidden>Пн–Пт с 8:00 до 20:00, Сб с 10:00 до 16:00</p>
<script>
  const toggle = document.querySelector('#toggle');
  const schedule = document.querySelector('#schedule');

  toggle.addEventListener('click', function () {
    schedule.hidden = !schedule.hidden;
    if (schedule.hidden) {
      toggle.textContent = 'Показать расписание';
      toggle.setAttribute('aria-expanded', 'false');
    } else {
      toggle.textContent = 'Скрыть расписание';
      toggle.setAttribute('aria-expanded', 'true');
    }
  });
</script>
```

Что увидите: первый щелчок показывает расписание и меняет надпись на «Скрыть расписание», второй прячет обратно.

Атрибут `aria-expanded` сообщает программе экранного доступа, раскрыт ли блок. Его меняют через `setAttribute('имя', 'значение')`. На практической работе он понадобится для меню-«бургера».

### Пример: тёмная тема

Классы удобно вешать и на весь `body`:

```html
<style>
  body { background: #ffffff; color: #222222; }
  body.dark { background: #1d1a22; color: #f2ede6; }
</style>
<h1>Настройки</h1>
<button id="theme" type="button">Сменить тему</button>
<script>
  const theme = document.querySelector('#theme');
  theme.addEventListener('click', function () {
    document.body.classList.toggle('dark');
  });
</script>
```

Что увидите: каждый щелчок переключает страницу между светлой и тёмной темой. Весь вид описан в CSS, JavaScript только переключает один класс.

## Поля ввода: value и событие input

У полей `input`, `textarea` и `select` есть свойство `value` — то, что ввёл пользователь. Оно **всегда строка**, даже если поле `type="number"`.

Событие `input` срабатывает при **каждом** изменении поля: напечатали букву, стёрли, вставили текст.

```html
<label for="nick">Ваше имя</label>
<input id="nick" type="text">
<p id="greeting">Здравствуйте!</p>
<script>
  const nick = document.querySelector('#nick');
  const greeting = document.querySelector('#greeting');

  nick.addEventListener('input', function () {
    greeting.textContent = 'Здравствуйте, ' + nick.value + '!';
  });
</script>
```

Что увидите: приветствие меняется прямо во время набора, буква за буквой.

Полезный приём — `trim()`: он убирает пробелы в начале и в конце строки. Если человек ввёл только пробелы, `nick.value.trim()` будет пустой строкой `''`. Проверка «поле пустое» выглядит так:

```js
if (nick.value.trim() === '') {
  console.log('Имя не заполнено');
}
```

А чтобы получить из поля число, используйте `Number(field.value)` — помните ловушку `'2' + 3`.

## Отправка формы: submit и preventDefault

Когда человек нажимает кнопку отправки или Enter в поле, у **формы** происходит событие `submit`. По умолчанию браузер отправляет данные по адресу из `action` и **перезагружает страницу**. Если мы хотим сначала проверить форму или показать сообщение без перезагрузки, это поведение нужно отменить.

```html
<form id="order">
  <label for="drink">Напиток</label>
  <input id="drink" type="text">
  <button type="submit">Заказать</button>
</form>
<p id="result"></p>
<script>
  const form = document.querySelector('#order');
  const drink = document.querySelector('#drink');
  const result = document.querySelector('#result');

  form.addEventListener('submit', function (event) {
    event.preventDefault();
    if (drink.value.trim() === '') {
      result.textContent = 'Напишите, что вам приготовить.';
    } else {
      result.textContent = 'Заказ принят: ' + drink.value.trim();
    }
  });
</script>
```

Что увидите: страница не перезагружается. Пустое поле — просьба заполнить, заполненное — «Заказ принят».

Разберём новое:

- `function (event)` — браузер передаёт в обработчик объект **события**. Имя параметра любое, чаще пишут `event` или `e`.
- `event.preventDefault()` — «отменить действие по умолчанию»: форма не отправится, страница не перезагрузится.
- Обработчик вешаем на **форму** и событие `submit`, а не на кнопку и `click`. Тогда сработает и щелчок, и Enter.

Частая ошибка: забыть `preventDefault()`. Сообщение мелькнёт на долю секунды и исчезнет вместе с перезагрузкой.

> **Попробуйте сами.** Добавьте в пример выше второе поле «Объём» и выведите в сообщении оба значения: «Заказ принят: капучино, 0,4 л».

## Как собрать сценарий: порядок действий

Почти любой сценарий на странице пишется по одному шаблону. Запомните четыре шага:

1. **Найти** элементы: `const button = document.querySelector('#…');`
2. **Подготовить** данные: `let count = 0;`
3. **Подписаться** на событие: `button.addEventListener('click', function () { … });`
4. **Внутри обработчика** — поменять данные и страницу: `textContent`, `classList`, `hidden`.

Перед тем как писать код, проговорите сценарий словами: «Когда нажимают кнопку „+1“, число увеличивается на один и показывается в span». Сразу видно, что найти (кнопку и span), какое событие (click) и что менять (textContent).

## Когда ничего не происходит

Нажали кнопку — и тишина. Это самая частая ситуация у новичков. Проверяйте по порядку:

| Что видите | Скорее всего | Как проверить |
|---|---|---|
| В консоли `Cannot read properties of null` | Селектор ничего не нашёл: опечатка, нет точки или решётки, скрипт стоит выше элемента | `console.log(button)` сразу после `querySelector` — должно быть не `null` |
| Ошибок нет, но щелчок ничего не меняет | Обработчик повешен не на тот элемент или функция не меняет страницу | Первой строкой в обработчике напишите `console.log('щелчок')` |
| Число на странице «склеивается»: 1, 11, 111 | Сложили строку с числом | Храните счётчик в переменной-числе, а не читайте его из `textContent` |
| Класс добавился, но вид не поменялся | В CSS нет правила для этого класса или опечатка в имени | В инструментах разработчика (F12 → Elements) посмотрите, какой класс у элемента |
| Сообщение мелькает и исчезает | Нет `event.preventDefault()` в обработчике `submit` | Добавьте его первой строкой обработчика |

Приём с `console.log('щелчок')` очень полезен: если надпись в консоли появилась, событие ловится, и ошибка дальше, внутри обработчика. Если нет — ошибка в поиске элемента или в `addEventListener`.

## Главное за занятие

- DOM — дерево объектов, которое браузер строит из HTML; JavaScript меняет его, и страница сразу перерисовывается.
- `document.querySelector('селектор')` находит первый элемент, `querySelectorAll` — все.
- `textContent` — текст элемента, `value` — содержимое поля (всегда строка).
- Оформление — в CSS через классы, в JS — только `classList.add / remove / toggle`.
- `element.hidden = true` прячет элемент, `false` — показывает.
- `addEventListener('click' | 'input' | 'submit', function () { … })` — реакция на событие.
- У формы ловим `submit` и вызываем `event.preventDefault()`, чтобы страница не перезагружалась.

## Словарик

- **DOM** — дерево объектов страницы, с которым работает JavaScript.
- **Узел (элемент DOM)** — объект в дереве, соответствующий тегу.
- **Селектор** — правило поиска элемента, как в CSS.
- **Событие** — действие на странице: щелчок, ввод, отправка формы.
- **Обработчик** — функция, которую браузер вызывает при событии.
- **Действие по умолчанию** — то, что браузер делает сам: переход по ссылке, отправка формы.
- **null** — «пусто»: так `querySelector` сообщает, что ничего не нашёл.
