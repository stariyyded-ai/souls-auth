## Зачем столько селекторов

**Селектор** — часть CSS-правила до фигурных скобок. Он говорит браузеру, к каким элементам применить стили. Пока вы знаете три простых селектора:

| Селектор | Что выбирает | Пример |
|---|---|---|
| `p` | все элементы с этим тегом | все абзацы |
| `.card` | все элементы с этим классом | все карточки |
| `#main` | один элемент с этим id | блок с `id="main"` |

Этого хватает, если вы сами пишете HTML и можете расставить классы. Но бывает иначе:

- HTML генерирует конструктор сайтов или CMS, и добавить класс нельзя.
- Нужно выделить каждую вторую строку таблицы — не ставить же класс на каждую строку вручную.
- Нужно оформить первую букву абзаца или добавить значок перед ссылкой, не меняя HTML.

Для этого в CSS есть сложные селекторы. Сегодня разберём все основные.

## Комбинаторы: выбор по положению

**Комбинатор** соединяет два селектора и говорит, как элементы связаны в дереве HTML. Вспомните вложенность: элемент внутри другого — его **потомок**, а элемент прямо внутри (на один уровень глубже) — **дочерний** элемент, или ребёнок. Элементы с общим родителем — **соседи**.

| Запись | Название | Что выбирает |
|---|---|---|
| `nav a` | потомок (пробел) | все `a` внутри `nav` на любой глубине |
| `nav > ul` | дочерний (`>`) | `ul`, которые лежат прямо в `nav` |
| `h2 + p` | соседний (`+`) | `p`, который стоит сразу после `h2` |
| `h2 ~ p` | все следующие соседи (`~`) | все `p` после `h2` у того же родителя |

### Потомок — пробел

```html
<style>
  nav a { color: #1f4e79; text-decoration: none; font-weight: bold; }
</style>
<nav>
  <ul>
    <li><a href="#news">Новости</a></li>
    <li><a href="#clubs">Секции</a></li>
  </ul>
</nav>
<p>Подробнее о турнире — у <a href="#coach">тренера секции</a>.</p>
```

Что увидите: ссылки в меню жирные и без подчёркивания, а ссылка в абзаце осталась обычной. Селектор `nav a` нашёл ссылки внутри `nav`, хотя они лежат на три уровня глубже: `nav → ul → li → a`.

### Дочерний — знак >

`article > p` выбирает только абзацы, которые лежат прямо в `article`. Абзац внутри цитаты в этой статье уже не подойдёт: его родитель — `blockquote`.

```html
<style>
  article > p { color: #1f4e79; }
</style>
<article>
  <p>Этот абзац — ребёнок article. Он синий.</p>
  <blockquote>
    <p>А этот — внук: он внутри цитаты и остался чёрным.</p>
  </blockquote>
</article>
```

### Соседи — знаки + и ~

`h2 + p` — абзац, который идёт **сразу** после заголовка `h2`. Удобно, чтобы выделить вводный абзац раздела:

```html
<style>
  h2 + p { font-size: 20px; color: #444444; }
</style>
<h2>Осенний турнир</h2>
<p>Турнир пройдёт 25 октября. Этот абзац крупнее: он сразу после заголовка.</p>
<p>А этот — обычный: перед ним абзац, а не заголовок.</p>
```

`h2 ~ p` выбрал бы оба абзаца: все `p`, которые стоят после `h2` у того же родителя.

> **Попробуйте сами.** В последнем примере замените `+` на `~` и посмотрите, что изменится. Потом поставьте между заголовком и первым абзацем `<hr>` — сработает ли `h2 + p`?

Частая ошибка: путать `nav a` (пробел, любая глубина) и `nav > a` (только прямые дети). В меню ссылки обычно лежат в `li`, поэтому `nav > a` ничего не найдёт.

## Селекторы атрибутов

Элементы можно выбирать по атрибутам и их значениям. Атрибут пишется в квадратных скобках:

| Запись | Что выбирает |
|---|---|
| `[disabled]` | элементы, у которых есть атрибут `disabled` |
| `[type="email"]` | значение атрибута точно равно `email` |
| `[href^="https"]` | значение **начинается** с `https` |
| `[href$=".pdf"]` | значение **заканчивается** на `.pdf` |
| `[href*="college"]` | значение **содержит** `college` |

Обычно перед скобками пишут тег: `input[type="email"]`, `a[href$=".pdf"]`.

```html
<style>
  input[type="email"] { border: 2px solid #1f4e79; }
  a[href$=".pdf"] { color: #b3541e; font-weight: bold; }
  a[href^="mailto:"] { color: #2e7d32; }
</style>
<p><label for="mail">Почта</label> <input id="mail" type="email"></p>
<p><label for="nm">Имя</label> <input id="nm" type="text"></p>
<p><a href="docs/rules.pdf">Правила приёма (PDF)</a></p>
<p><a href="mailto:priem@college.example">Написать в приёмную комиссию</a></p>
```

Что увидите: у поля почты синяя рамка, у поля имени — обычная. Ссылка на PDF-файл — оранжевая и жирная, ссылка на почту — зелёная.

Где это полезно: оформить все поля определённого типа без классов, отметить ссылки на файлы и на другие сайты, выбрать элементы по data-атрибуту из прошлого занятия: `[data-category="events"]`.

## Псевдоклассы: выбор по состоянию и номеру

**Псевдокласс** пишется через одно двоеточие. Вы уже знаете состояния `:hover`, `:focus-visible` и `:disabled`. Ещё есть псевдоклассы, которые выбирают элемент по его **месту среди соседей**:

| Псевдокласс | Что выбирает |
|---|---|
| `:first-child` | элемент, который первый у своего родителя |
| `:last-child` | последний у своего родителя |
| `:nth-child(2)` | второй по счёту |
| `:nth-child(even)` | чётные: 2, 4, 6… |
| `:nth-child(odd)` | нечётные: 1, 3, 5… |
| `:nth-child(3n)` | каждый третий: 3, 6, 9… |
| `:not(селектор)` | все, кроме подходящих под селектор |
| `:focus` | элемент в фокусе |

### Таблица-«зебра»

Длинную таблицу легче читать, когда строки через одну подкрашены — глаз не съезжает:

```html
<style>
  table { border-collapse: collapse; }
  th, td { padding: 6px 12px; text-align: left; }
  thead th { background-color: #1f4e79; color: #ffffff; }
  tbody tr:nth-child(even) { background-color: #eef3f8; }
  tbody td:first-child { font-weight: bold; }
</style>
<table>
  <thead><tr><th scope="col">Секция</th><th scope="col">День</th></tr></thead>
  <tbody>
    <tr><td>Волейбол</td><td>Понедельник</td></tr>
    <tr><td>Шахматы</td><td>Вторник</td></tr>
    <tr><td>Баскетбол</td><td>Среда</td></tr>
    <tr><td>Футбол</td><td>Пятница</td></tr>
  </tbody>
</table>
```

Что увидите: тёмная шапка, вторая и четвёртая строки — голубые, названия секций в первом столбце — жирные.

### Всё, кроме последнего: `:not`

Нужна линия между пунктами списка, но не под последним. Можно дать линию всем и убрать у последнего. А можно одним правилом:

```css
li:not(:last-child) { border-bottom: 1px solid #c9d3df; }
```

Читается так: «пункты списка, которые не последние».

Частая ошибка: думать, что `p:first-child` — «первый абзац». На самом деле это «абзац, который первый у своего родителя». Если перед ним стоит заголовок, первым ребёнком будет заголовок, и правило не сработает. Для «первого абзаца после заголовка» подойдёт `h2 + p`.

> **Попробуйте сами.** В примере с таблицей замените `even` на `odd`, потом на `3n`. Посмотрите, какие строки подкрасились. Вместо `td:first-child` попробуйте `td:last-child`.

## Псевдоэлементы: оформление без лишних тегов

**Псевдоэлемент** — часть элемента, которой нет в HTML, но которую можно оформить. Пишется через **два двоеточия**.

| Псевдоэлемент | Что это |
|---|---|
| `::before` | вставка в начало содержимого элемента |
| `::after` | вставка в конец содержимого элемента |
| `::first-letter` | первая буква текста |
| `::first-line` | первая строка текста |
| `::placeholder` | текст-подсказка в поле |

У `::before` и `::after` обязательно свойство `content` — что вставить. Без `content` псевдоэлемент не появится. Пустая строка `content: ""` тоже годится — так рисуют декоративные полоски и значки, которым задают размеры и фон.

```html
<style>
  a[href^="https"]::after { content: " ↗"; }
  a[href^="tel:"]::before { content: "☎ "; }
  .lead::first-letter { font-size: 32px; color: #b3541e; font-weight: bold; }
</style>
<p class="lead">Приёмная комиссия работает с 20 июня по 15 августа.</p>
<p>Наш сайт: <a href="https://college.example">college.example</a></p>
<p>Телефон: <a href="tel:+74950000000">+7 495 000-00-00</a></p>
<p>Расписание: <a href="#schedule">на этой странице</a></p>
```

Что увидите: крупную оранжевую первую букву абзаца «Приёмная…», стрелку ↗ после ссылки на другой сайт и трубку ☎ перед телефоном. У ссылки «на этой странице» значка нет: её адрес не начинается с `https`.

Важно: текст из `content` — это оформление, а не содержимое. Его нельзя выделить мышью, а экранный диктор может не прочитать. Не пишите в `content` важную информацию — только украшения и значки.

## Группировка

Если у нескольких селекторов одинаковые стили, их записывают через **запятую** — одно правило вместо нескольких:

```css
h1, h2, h3 { font-family: Georgia, "Times New Roman", serif; }
a:hover, a:focus-visible { color: #b3541e; }
```

Частая ошибка — забыть запятую. `h1 h2` (через пробел) — это уже не группа, а «h2 внутри h1», и такое правило ничего не найдёт.

Ещё одна ловушка: если в группе один селектор с ошибкой (например, опечатка в псевдоклассе), браузер отбросит всё правило целиком.

## Специфичность ещё раз

Когда на один элемент действуют несколько правил с разными значениями, побеждает правило с большей **специфичностью** — «весом» селектора. Если вес одинаковый — то, что ниже в коде.

Вес считают тремя числами (a, b, c):

- **a** — число id в селекторе;
- **b** — число классов, атрибутов и псевдоклассов;
- **c** — число тегов и псевдоэлементов.

Сравнивают слева направо: один id сильнее любого количества классов.

| Селектор | id | классы, атрибуты, псевдоклассы | теги, псевдоэлементы | Вес |
|---|---|---|---|---|
| `p` | 0 | 0 | 1 | 0-0-1 |
| `nav a` | 0 | 0 | 2 | 0-0-2 |
| `.menu__link` | 0 | 1 | 0 | 0-1-0 |
| `a[href^="https"]` | 0 | 1 | 1 | 0-1-1 |
| `tbody tr:nth-child(even)` | 0 | 1 | 2 | 0-1-2 |
| `.button:hover` | 0 | 2 | 0 | 0-2-0 |
| `#main p` | 1 | 0 | 1 | 1-0-1 |

```html
<style>
  .note { color: #2e7d32; }
  p { color: #b3541e; }
  article p { color: #1f4e79; }
</style>
<article>
  <p class="note">Какого я цвета?</p>
  <p>А я?</p>
</article>
```

Что увидите: первый абзац зелёный — у `.note` вес 0-1-0, это больше, чем 0-0-2 у `article p`. Второй абзац синий — `article p` (0-0-2) тяжелее `p` (0-0-1), хотя стоит раньше.

Внутри `:not()` вес считается по селектору в скобках: `li:not(:last-child)` = 0-1-1.

Советы, чтобы не воевать со специфичностью:

- Оформляйте классами — у них одинаковый вес, и правила легко перебивать порядком.
- Не пишите длинных цепочек вроде `body div.page ul li a` — такое правило потом ничем не перебить.
- Не используйте `!important` — это «ядерная кнопка», после которой порядок перестаёт работать. На сайте курса проверка качества его запрещает.

На экзамене чистый CSS с короткими селекторами — признак аккуратной вёрстки.

## Как читать сложный селектор

Длинный селектор удобно читать **справа налево**: сначала — какой элемент оформляем, потом — где он должен находиться. Браузер, кстати, проверяет селекторы именно так.

| Селектор | Читаем справа налево |
|---|---|
| `nav li a` | ссылки, которые лежат в пунктах списка, которые лежат в `nav` |
| `article > p:first-child` | абзац, который первый у родителя, и этот родитель — `article` |
| `form input[type="email"]` | поля с типом email внутри формы |
| `tbody tr:nth-child(even) td` | ячейки в чётных строках тела таблицы |
| `.card:not(.card--hit) .card__title` | заголовки в карточках, которые не хиты |

Если правило не срабатывает, проверьте селектор по шагам:

1. Есть ли на странице сам элемент (последняя часть селектора)? Нет ли опечатки в имени класса?
2. Правда ли он лежит внутри того, что написано слева? Откройте инструменты разработчика (F12) и посмотрите дерево элементов.
3. Не перебивает ли его другое правило с большей специфичностью? В инструментах разработчика перебитые свойства зачёркнуты.

Привычка читать селекторы справа налево помогает и писать их короче: часто достаточно последней части с классом.

## Главное за занятие

- Комбинаторы: пробел — потомок, `>` — ребёнок, `+` — сосед сразу после, `~` — все следующие соседи.
- Атрибуты: `[type="email"]`, `[href^="https"]`, `[href$=".pdf"]`, `[href*="…"]`.
- Псевдоклассы через одно двоеточие: `:first-child`, `:last-child`, `:nth-child(even)`, `:not()`, `:hover`, `:focus`.
- Псевдоэлементы через два двоеточия: `::before` и `::after` (обязателен `content`), `::first-letter`.
- Группировка через запятую — одно правило для нескольких селекторов.
- Специфичность: id > классы, атрибуты и псевдоклассы > теги. При равенстве побеждает правило ниже.

## Словарик

- **Комбинатор** — знак между селекторами, который задаёт связь элементов: пробел, `>`, `+`, `~`.
- **Потомок** — элемент внутри другого на любой глубине.
- **Дочерний элемент** — элемент прямо внутри родителя.
- **Селектор атрибута** — выбор по атрибуту в квадратных скобках: `[type="email"]`.
- **Псевдокласс** — выбор по состоянию или месту: `:hover`, `:nth-child()`.
- **Псевдоэлемент** — часть элемента, которой нет в HTML: `::before`, `::first-letter`.
- **Специфичность** — вес селектора, по которому браузер выбирает победившее правило.
