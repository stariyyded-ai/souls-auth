## Зачем вообще что-то готовое

Посмотрите на сайты кафе, спортзала и колледжа. У всех есть шапка с меню, кнопки, карточки, сетка колонок, форма, подвал. Каждый раз писать всё это с нуля — долго. Поэтому в веб-разработке много **готовых инструментов**:

- **CSS-фреймворк** — большой готовый файл CSS с сеткой, кнопками, формами и компонентами. Вы подключаете его и пишете в HTML нужные классы.
- **Препроцессор** — язык «CSS с суперсилами»: переменные, вложенность, повторное использование кусков. Его код превращается в обычный CSS.
- **CMS** — программа, в которой сайт собирают и наполняют без написания кода, из готовых шаблонов.
- **Типовые решения** — проверенные способы сделать часто встречающиеся элементы: меню, карточку, модальное окно.

На демоэкзамене обычно верстают **без** фреймворков, на чистом HTML и CSS. Но понимать, как они устроены, нужно: на работе вы встретите их в первую же неделю. И главное — всё, что делает фреймворк, сделано из тех же `display: flex`, `grid` и медиазапросов, что вы уже знаете.

## CSS-фреймворки и Bootstrap

Самый известный CSS-фреймворк — **Bootstrap**. Его подключают одной строкой `<link>` в `head` (адрес берут на официальном сайте getbootstrap.com), и сразу становятся доступны сотни готовых классов.

### Сетка Bootstrap

Главное в Bootstrap — **сетка из 12 колонок**. Почему 12? Это число делится на 2, 3, 4 и 6, поэтому из него легко собрать половины, трети и четверти.

```html
<div class="container">
  <div class="row">
    <div class="col-12 col-md-6">Левая половина</div>
    <div class="col-12 col-md-6">Правая половина</div>
  </div>
</div>
```

Как это читать:

- `container` — контейнер с максимальной шириной и отступами по бокам, по центру страницы;
- `row` — строка сетки;
- `col-12` — «занять 12 колонок из 12», то есть всю ширину. Это значение для телефона;
- `col-md-6` — «от средних экранов (md, от 768px) занять 6 колонок из 12», то есть половину.

Узнаёте? Это mobile first: базовый класс для телефона, а размеры для широких экранов добавляются через `md`, `lg`, `xl`. Внутри Bootstrap — те же медиазапросы `min-width`, что вы писали на прошлых занятиях.

> **Попробуйте сами.** Нажмите «Попробовать» под примером. Ничего особенного не произошло: блоки идут друг под другом, как обычные `div`. Это потому что в песочнице Bootstrap не подключён. Класс сам по себе ничего не делает — работает только CSS, который его описывает. В задании 2 вы напишете этот CSS сами.

### Компоненты

Кроме сетки, во фреймворке есть готовые **компоненты** — оформленные части интерфейса:

```html
<button class="btn btn-primary">Записаться</button>
<button class="btn btn-outline-secondary">Отмена</button>
<div class="card">
  <div class="card-body">
    <h5 class="card-title">Абонемент</h5>
    <p class="card-text">12 занятий в месяц</p>
  </div>
</div>
```

`btn` — базовый вид кнопки, `btn-primary` — главная (синяя), `btn-outline-secondary` — второстепенная с рамкой. Ещё есть меню (`navbar`), формы, модальные окна, всплывающие подсказки, вкладки.

### Плюсы и минусы

| Плюсы | Минусы |
|---|---|
| Быстро: сетка и компоненты уже готовы | Много лишнего кода: подключаете всё, используете десятую часть |
| Работает во всех браузерах, проверено тысячами сайтов | Сайты похожи друг на друга — «бутстраповский» вид узнаётся сразу |
| Команда пишет в одном стиле | Чтобы переделать под макет, приходится перебивать стили фреймворка |
| Хорошая документация | Нужно выучить сотни классов |

Частая ошибка новичков: подключить Bootstrap и бороться с ним, чтобы сделать «как в макете», переопределяя каждое правило. Если дизайн сильно отличается от фреймворка, быстрее и чище сверстать самим.

## Утилитарный подход

Есть другой стиль фреймворков — **утилитарный** (самый известный — Tailwind CSS). В нём каждый класс делает **одну маленькую вещь**:

```html
<div class="p-4 rounded-lg bg-white shadow text-center">
  <h3 class="text-xl font-bold">Библиотека</h3>
</div>
```

`p-4` — внутренний отступ, `rounded-lg` — скругление, `shadow` — тень, `text-center` — выравнивание. CSS вы почти не пишете: внешний вид собирается из классов прямо в HTML.

Сравните с тем, как мы делали раньше: класс **по смыслу** `.card`, а оформление — в CSS. У обоих подходов есть сторонники. В этом курсе и на экзамене мы пишем классы по смыслу (вспомните БЭМ: `card__title`) — так код понятнее новичку и проверяющему.

## Препроцессор LESS

Когда CSS-файл вырастает до тысячи строк, в нём становится тесно: один и тот же цвет повторяется в двадцати местах, селекторы `.card .card__title`, `.card .card__btn` пишутся снова и снова. **Препроцессоры** решают эти проблемы. Самые известные — **LESS** и **Sass** (SCSS). Сегодня разберём LESS: у него самый простой синтаксис.

Браузер **не понимает** LESS. Файл `style.less` сначала **компилируют** — превращают в обычный `style.css` — и уже его подключают к странице. Компилирует специальная программа: консольная `lessc` или расширение для VS Code (например, Easy LESS: сохранили `.less` — рядом появился `.css`).

### Переменные

```less
@primary: #1a56b0;
@radius: 12px;

.btn {
  background-color: @primary;
  border-radius: @radius;
}
```

После компиляции:

```css
.btn {
  background-color: #1a56b0;
  border-radius: 12px;
}
```

Переменная LESS начинается с `@`. При компиляции её имя просто **заменяется** значением.

Вы уже знаете CSS-переменные `--primary` и `var(--primary)`. В чём разница? CSS-переменные живут **в браузере**: их можно поменять в медиазапросе или из JavaScript (так делают тёмную тему). Переменные LESS **исчезают** после компиляции, в готовом CSS от них не остаётся следа. Сегодня многие проекты обходятся CSS-переменными, а LESS используют ради остальных возможностей.

### Вложенность

В LESS правила можно вкладывать друг в друга, повторяя структуру HTML:

```less
.menu {
  display: flex;
  gap: 24px;

  a {
    color: @primary;

    &:hover {
      text-decoration: underline;
    }
  }
}
```

Компилируется в:

```css
.menu {
  display: flex;
  gap: 24px;
}
.menu a {
  color: #1a56b0;
}
.menu a:hover {
  text-decoration: underline;
}
```

Знак `&` значит «родительский селектор». `&:hover` внутри `a` — это `a:hover`. С БЭМ `&` особенно удобен: `&__title` внутри `.card` превращается в `.card__title`.

Частая ошибка: вкладывать слишком глубоко — пять-шесть уровней. После компиляции получаются длинные селекторы вроде `.page .main .catalog .card .card__body a`, которые трудно перебить. Правило: не глубже двух-трёх уровней.

### Миксины

**Миксин** — кусок стилей, который можно вставить в любое правило, как готовую заготовку. Можно с параметрами:

```less
.rounded(@r: 8px) {
  border-radius: @r;
}

.card {
  .rounded(12px);
}
.btn {
  .rounded();
}
```

Компилируется в:

```css
.card {
  border-radius: 12px;
}
.btn {
  border-radius: 8px;
}
```

`@r: 8px` — значение по умолчанию: если в скобках ничего не передали, подставится 8px.

### Операции

LESS умеет считать: `padding: (@gap / 2) @gap;` при `@gap: 16px` превратится в `padding: 8px 16px;`. В обычном CSS для расчётов есть функция `calc()`, но она считает уже в браузере.

> **Попробуйте сами.** Возьмите лист бумаги (или блокнот) и «скомпилируйте» в уме: `@gap: 20px; .box { margin: (@gap * 2) 0; &__inner { padding: @gap; } }`. Какие два правила CSS получатся? Ответ: `.box { margin: 40px 0; }` и `.box__inner { padding: 20px; }`.

## CMS: сайт без кода

**CMS** (Content Management System, система управления содержимым) — программа, в которой сайт наполняют через удобную админку: написать новость, поменять цену, добавить фото — без правки HTML.

| CMS | Что это | Где встречается |
|---|---|---|
| WordPress | Бесплатная, самая популярная в мире; тысячи тем и плагинов | блоги, сайты компаний, новости |
| Тильда | Конструктор: страница собирается из готовых блоков мышкой | лендинги, сайты мероприятий, портфолио |
| 1С-Битрикс | Платная российская CMS, связана с учётом 1С | интернет-магазины, сайты организаций и госучреждений |

Внешний вид сайта на CMS задаёт **шаблон** (в WordPress его называют **темой**). Шаблон — это те же HTML, CSS и JavaScript, только с «дырками», куда CMS подставляет содержимое: заголовок новости, список товаров, меню. Поэтому верстальщик нужен и тем, кто работает с CMS: кто-то должен сверстать шаблон по макету дизайнера.

Когда что выбирать:

- Нужен лендинг за день и без программиста — конструктор вроде Тильды.
- Сайт, который будут постоянно наполнять (новости, каталог), — CMS с шаблоном.
- Уникальный интерфейс, веб-приложение, высокие требования к скорости — ручная вёрстка.

## Типовые решения

Некоторые элементы есть почти на каждом сайте. Их не изобретают заново, а делают по проверенной схеме — **типовому решению** (иногда говорят «паттерн»):

| Компонент | Как устроен | Что важно |
|---|---|---|
| Меню в шапке | `nav` → `ul` → `li` → `a`, flex | текущая страница отмечена, видимый фокус |
| Карточка | `article`, картинка, заголовок, текст, кнопка | кнопка внизу, одинаковая высота в ряду |
| Кнопка | `a` для перехода, `button` для действия | состояния `:hover`, `:focus-visible` |
| Модальное окно | затемнение на весь экран + окно по центру | заголовок, кнопка «Закрыть», `role="dialog"` |
| Аккордеон | вопрос — кнопка, ответ — скрываемый блок | `aria-expanded` |
| Вкладки | ряд кнопок, под ними панели | одна активная вкладка |

Аккордеон и вкладки оживляют JavaScript — мы сделаем их в практической работе №6. А вот модальное окно разберём сейчас: его внешний вид — чистый CSS.

### Модальное окно

**Модальное окно** — окно поверх страницы, которое требует ответа: «Вы записаны», «Удалить запись?», форма входа. Пока оно открыто, страница под ним затемнена и недоступна.

Для него понадобится новое свойство — `position`. До сих пор все элементы стояли **в потоке**, друг за другом. `position` позволяет вынуть элемент из потока и поставить в точное место:

| Значение | Что делает |
|---|---|
| `static` | обычное поведение, в потоке (по умолчанию) |
| `relative` | элемент в потоке, но становится «точкой отсчёта» для вложенных `absolute` |
| `absolute` | вынут из потока, ставится по `top`, `right`, `bottom`, `left` относительно ближайшего предка с `position: relative` |
| `fixed` | вынут из потока и **приклеен к окну браузера**: не двигается при прокрутке |

Свойство `inset: 0` — короткая запись для `top: 0; right: 0; bottom: 0; left: 0`, то есть «растянуть на всё окно».

```html
<style>
  .modal {
    position: fixed;
    inset: 0;
    display: flex;
    justify-content: center;
    align-items: center;
    padding: 16px;
    background-color: rgba(0, 0, 0, 0.6);
  }
  .modal__dialog {
    position: relative;
    max-width: 400px;
    padding: 24px;
    border-radius: 12px;
    background-color: #ffffff;
  }
  .modal__close {
    position: absolute;
    top: 8px;
    right: 8px;
  }
</style>
<p>Обычный текст страницы под окном.</p>
<div class="modal">
  <section class="modal__dialog" role="dialog" aria-modal="true" aria-labelledby="ok-title">
    <h2 id="ok-title">Вы записаны</h2>
    <p>Ждём вас в среду в 15:00.</p>
    <button class="modal__close" type="button" aria-label="Закрыть">×</button>
  </section>
</div>
```

Что вы увидите: страница затемнена, в центре — белое окно с заголовком, а в его правом верхнем углу — кнопка с крестиком.

Как это работает:

1. `.modal` — затемнение: `position: fixed` и `inset: 0` растягивают его на всё окно браузера, полупрозрачный фон `rgba` затемняет страницу.
2. Затемнение — flex-контейнер с центрированием (помните «три строки» из урока про Flexbox?). Окно встаёт ровно в центр.
3. `.modal__dialog` получает `position: relative` — становится точкой отсчёта для крестика.
4. `.modal__close` с `position: absolute; top: 8px; right: 8px` — в 8px от верхнего и правого края **окна**, а не страницы.
5. `padding: 16px` у затемнения — чтобы на телефоне окно не прилипало к краям экрана.

Атрибуты для доступности: `role="dialog"` говорит экранному диктору, что это диалоговое окно; `aria-modal="true"` — что страница под ним сейчас недоступна; `aria-labelledby` связывает окно с его заголовком по `id`, и диктор прочитает «Вы записаны, диалог». У кнопки-крестика текст «×» ничего не говорит незрячему человеку, поэтому ей нужен `aria-label="Закрыть"`.

Частая ошибка: забыть `position: relative` у окна. Тогда крестик с `absolute` ищет точку отсчёта выше и улетает в угол экрана.

> **Попробуйте сами.** Нажмите «Попробовать» под примером с модальным окном. Удалите строку `position: relative;` у `.modal__dialog` — куда переехал крестик? Верните её, а потом поменяйте прозрачность затемнения с `0.6` на `0.9` и на `0.2`. При каком значении страница под окном ещё видна, но уже не отвлекает?

Открывать и закрывать окно по кнопке научимся на занятиях по JavaScript. Кстати, в HTML есть и готовый тег `<dialog>` — с ним тоже познакомимся, когда будем писать скрипты.

## Главное за занятие

- CSS-фреймворк (Bootstrap) — готовый CSS с сеткой и компонентами; сетка из 12 колонок и классы `col-12 col-md-6` — это mobile first на медиазапросах `min-width`.
- Утилитарные классы (`p-4`, `text-center`) собирают вид прямо в HTML; в курсе мы пишем классы по смыслу.
- LESS — препроцессор: переменные `@name`, вложенность с `&`, миксины, расчёты. Браузер его не понимает: LESS компилируют в CSS.
- CMS (WordPress, Тильда, 1С-Битрикс) позволяют наполнять сайт без кода; внешний вид задаёт шаблон (тема), который тоже кто-то верстает.
- Типовые решения — проверенные схемы меню, карточки, кнопки, модального окна.
- Модальное окно: затемнение `position: fixed; inset: 0` + flex-центрирование, крестик `position: absolute` внутри окна с `position: relative`, атрибуты `role="dialog"`, `aria-modal`, `aria-labelledby`.

## Словарик

- **CSS-фреймворк** — готовый набор CSS (и иногда JavaScript) с сеткой, компонентами и классами.
- **Компонент** — оформленная часть интерфейса: кнопка, карточка, меню, модальное окно.
- **Препроцессор** — язык, код на котором превращается в CSS; добавляет переменные, вложенность, миксины.
- **Компиляция** — превращение кода препроцессора в обычный CSS.
- **Миксин** — именованный кусок стилей, который вставляют в разные правила.
- **CMS** — система управления содержимым сайта.
- **Шаблон (тема)** — оформление сайта на CMS: HTML, CSS и JavaScript с местами для содержимого.
- **Модальное окно** — окно поверх страницы, которое требует ответа и блокирует страницу под собой.

? Может ли браузер прочитать файл `style.less` напрямую?
- [ ] Да, все современные браузеры понимают LESS
- [ ] Да, если подключить его тегом `<style>`
- [x] Нет, LESS сначала компилируют в CSS
> Браузер понимает только CSS. LESS — инструмент разработчика.

? Во что скомпилируется `.card { &:hover { color: red; } }`?
- [ ] `.card &:hover { color: red; }`
- [x] `.card:hover { color: red; }`
- [ ] `.card .hover { color: red; }`
> `&` — это родительский селектор, `&:hover` превращается в `.card:hover`.

? Что такое миксин в LESS?
- [ ] Смешивание двух цветов
- [ ] Медиазапрос для телефонов
- [x] Именованный кусок стилей, который можно вставить в разные правила
> Например, `.rounded(12px)` вставит `border-radius: 12px`.

? Что задаёт внешний вид сайта на WordPress?
- [ ] Плагин для резервных копий
- [x] Тема (шаблон): HTML, CSS и JavaScript с местами для содержимого
- [ ] Только настройки в админке, кода там нет
> Тему кто-то верстает по макету, поэтому верстальщик нужен и в мире CMS.

? Как растянуть затемнение модального окна на всё окно браузера, чтобы оно не уезжало при прокрутке?
- [ ] `position: relative; width: 100%;`
- [ ] `position: absolute; top: 0;`
- [x] `position: fixed; inset: 0;`
> `fixed` приклеивает элемент к окну, `inset: 0` растягивает его до всех четырёх краёв.

? Кнопка закрытия окна с текстом «×». Что добавить для доступности?
