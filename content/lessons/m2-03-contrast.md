Серый текст на тёмном фоне выглядит стильно ровно до тех пор, пока его не нужно прочитать на солнце или со слабым зрением.

## Что требует WCAG

Стандарт доступности WCAG 2.1 уровня AA задаёт минимальный контраст:

| Текст | Минимальный контраст |
|---|---|
| Обычный | 4,5 : 1 |
| Крупный (от 24px или 18,7px жирный) | 3 : 1 |
| Иконки и рамки полей | 3 : 1 |

Контраст считается по относительной яркости цветов: от 1 : 1 (одинаковые) до 21 : 1 (чёрный на белом).

## Как проверить

В DevTools наведи пипетку на цвет текста — браузер покажет контраст и галочки AA и AAA. Автотесты в заданиях проверяют контраст каждого текста на странице.

```css
.lead { color: #e6dcc6; } /* на #241f2b — 12 : 1 */
.hint { color: #b3a892; } /* на #241f2b — 6,9 : 1 */
```

## Размер

Основной текст — не меньше 16px. Мелкий текст подходит только для подписей и сносок.
