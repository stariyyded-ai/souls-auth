## Коротко о теории

**Блочная модель** (повторение). У каждого блока есть содержимое, внутренний отступ `padding`, рамка `border` и внешний отступ `margin`. После правила `* { box-sizing: border-box; }` ширина блока включает padding и рамку.

Сокращённая запись отступов идёт по часовой стрелке, начиная сверху:

| Запись | Что значит |
|---|---|
| `padding: 24px;` | со всех сторон 24px |
| `padding: 8px 12px;` | сверху и снизу 8px, слева и справа 12px |
| `margin: 0 16px 16px 0;` | сверху 0, справа 16px, снизу 16px, слева 0 |

**Рамка** задаётся тремя значениями: толщина, стиль, цвет — `border: 1px solid #d0d7e2`. Можно задать рамку только с одной стороны: `border-bottom: 3px solid #ffd166`.

**Скругление углов** — свойство `border-radius`. Чем больше значение, тем круглее угол: `border-radius: 12px` — мягкая карточка, `border-radius: 999px` — «таблетка». Скругление работает и без рамки, по краю фона. Подробнее о скруглениях, тенях и градиентах — на занятии 20.

**Строчно-блочные элементы.** `display: inline-block` ставит блоки в строку, как слова в предложении, но разрешает им ширину, высоту и все отступы. Так можно сделать горизонтальное меню и ряд карточек. Если у блоков разная высота, добавьте `vertical-align: top`, чтобы они выровнялись по верху. На занятии 21 вы узнаете Flexbox — он решает те же задачи удобнее.

**Состояния кнопки:**

| Псевдокласс | Состояние | Что обычно меняют |
|---|---|---|
| `:hover` | наведение мыши | фон темнее |
| `:focus-visible` | фокус с клавиатуры | заметная рамка `outline` |
| `:active` | момент нажатия | фон ещё темнее |
| `:disabled` | кнопка недоступна (атрибут `disabled`) | серый фон, `cursor: not-allowed` |

```html
<style>
  .button { padding: 12px 24px; border: 2px solid #1f4e79; border-radius: 8px; background-color: #1f4e79; color: #ffffff; font-size: 16px; cursor: pointer; }
  .button:hover { background-color: #163a5a; border-color: #163a5a; }
  .button:focus-visible { outline: 3px solid #f2a541; outline-offset: 2px; }
  .button:disabled { background-color: #e1e5ea; border-color: #e1e5ea; color: #5a6470; cursor: not-allowed; }
</style>
<button class="button" type="button">Записаться</button>
<button class="button" type="button" disabled>Мест нет</button>
```

Что увидите: синюю кнопку со скруглёнными углами и серую недоступную рядом. Наведите мышь на обе: синяя темнеет, у серой курсор «запрещено».

> **Попробуйте сами.** В примере выше поменяйте `border-radius: 8px` на `999px` — кнопки станут «таблетками». Потом щёлкните по предпросмотру и нажмите Tab: рамка фокуса появится только у активной кнопки, недоступная фокус не получает.

**Шаг 3.** Меню в строку:

```css
.nav { display: inline-block; }
.nav__list { list-style: none; margin: 0; padding: 0; }

```

Блок `.nav` делаем строчно-блочным, чтобы он встал рядом с логотипом. Ссылке `display: inline-block` нужен, чтобы вертикальный `padding` увеличил область нажатия.

**Шаг 4.** Состояния и активный пункт. `.nav__link:hover` — фон `#34446b`. `.nav__link:focus-visible` — `outline: 3px solid var(--color-accent)`. Пункт текущей страницы `.nav__link--active` — жёлтая линия снизу: `border-bottom: 3px solid var(--color-accent)`. Проверьте задание.
