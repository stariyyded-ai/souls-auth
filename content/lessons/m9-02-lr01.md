## Лекция

**Почему нельзя «просто открыть файл в браузере».** Когда вы два раза щёлкаете по `index.html`, браузер открывает адрес вида `file:///C:/Users/.../index.html`. Для HTML и CSS этого хватает. Но портал заявок написан на PHP, а PHP — язык, который выполняется **на сервере**. Браузер PHP не понимает: если открыть `.php` как файл, вы увидите исходный код или пустую страницу. Нужен веб-сервер, который получит запрос, отдаст PHP-файл интерпретатору, а браузеру вернёт готовый HTML.

Похоже на ресторан. Браузер — это гость, он делает заказ (HTTP-запрос). Веб-сервер Apache — официант. PHP — повар, который готовит блюдо по рецепту (вашему коду). MySQL/MariaDB — склад продуктов (данные). Гость видит только готовое блюдо, то есть HTML, а на кухню не заходит. Поэтому в браузере через «Просмотр кода» вы никогда не увидите PHP-код, только его результат.

**XAMPP: сервер в одной коробке.** XAMPP — бесплатная сборка для Windows, Linux и macOS. В ней:

- **Apache** — веб-сервер;
- **MariaDB** — СУБД, совместимая с MySQL (в панели XAMPP она по старой памяти подписана «MySQL», команды SQL те же);
- **PHP** — нужна версия 8.2, на ней работает весь курс; при скачивании выбирайте сборку XAMPP с PHP 8.2.x;
- **phpMyAdmin** — веб-интерфейс к базе данных по адресу `http://localhost/phpmyadmin`.

На экзамене стек обычно уже установлен, но запускать сервер, находить папку проекта и чинить «не стартует Apache» придётся самим. Это первые 5 минут, и терять их на панику не стоит.

**Главное про XAMPP:**

| Что | Где / как |
|---|---|
| Панель управления | `C:\xampp\xampp-control.exe`, кнопки Start у Apache и MySQL |
| Папка сайтов | `C:\xampp\htdocs\` |
| Адрес проекта | папка `htdocs\portal\` открывается как `http://localhost/portal/` |
| phpMyAdmin | `http://localhost/phpmyadmin`, пользователь `root`, пароль по умолчанию пустой |
| Настройки PHP | `C:\xampp\php\php.ini` |
| Логи ошибок Apache | `C:\xampp\apache\logs\error.log` |

**Типичная беда: Apache не стартует.** Почти всегда порт 80 или 443 уже занят: Skype старых версий, IIS, другой сервер, иногда VPN-клиент. В панели XAMPP нажмите **Netstat** и посмотрите, кто держит порт. Варианты: закрыть программу или в `httpd.conf` поменять `Listen 80` на `Listen 8080` и заходить на `http://localhost:8080/`. С MySQL так же: порт 3306 может быть занят другой установленной СУБД.

**Проверка PHP.** Создайте файл `htdocs/portal/info.php`:

```php
<?php
phpinfo();
```

Откройте `http://localhost/portal/info.php`. Появится большая таблица с версией PHP: ищите `PHP Version 8.2.x`. Ниже, в разделе `pdo_mysql`, должна быть строка `enabled`: через PDO мы будем подключаться к базе. После проверки файл удалите. Оставлять `phpinfo()` на настоящем сервере — дыра в безопасности, он показывает всю конфигурацию.

**VS Code.** Редактор, в котором пишем весь код. Что настроить сразу:

- **File → Open Folder** и открыть `C:\xampp\htdocs\portal`. Открывайте именно папку, а не отдельный файл: тогда работают поиск по проекту, Git и автодополнение путей.
- Расширения: **PHP Intelephense** (подсказки и подсветка ошибок PHP), **Russian Language Pack** (по желанию). Расширение **Live Server** знакомо по HTML, но PHP оно не выполняет. Для PHP-страниц смотрите проект через `localhost`.
- Кодировка файлов **UTF-8** (внизу справа в статусной строке). Если там Windows-1251, русские буквы превратятся в «кракозябры».
- Встроенный терминал: `` Ctrl+` ``. Понадобится в ЛР2 для Git.
- Emmet: наберите `!` и нажмите Tab, получится каркас HTML5. Работает и в `.php` файлах, если в настройках `emmet.includeLanguages` добавить `"php": "html"`.

**DevTools: рентген браузера.** Клавиша **F12** (или Ctrl+Shift+I) в Chrome, Edge, Яндекс Браузере. Вкладки, которые нужны уже сейчас:

- **Elements** — HTML-дерево страницы и CSS выбранного элемента. Стили можно менять прямо там и сразу видеть результат (после перезагрузки правки пропадут).
- **Console** — ошибки JavaScript и место для экспериментов: введите `2+2` или `document.title`.
- **Network** — все запросы страницы. Код `200` значит «всё хорошо», `404` — файл не найден (чаще всего опечатка в пути к CSS), `500` — ошибка на сервере (смотрите PHP).
- **Device Toolbar** (Ctrl+Shift+M) — режим мобильного устройства. Здесь можно задать размер **390×844**, тот самый размер мобильного макета из задания 2 экзамена. В списке устройств ему соответствует пресет iPhone 12 Pro; можно ввести размеры и вручную.

**Структура проекта портала.** Договоримся сразу, чтобы в следующих модулях не переезжать:

```
htdocs/
└── portal/
    ├── index.php        ← главная (пока заглушка)
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    ├── img/
    ├── docs/            ← проектная документация (ЛР4)
    └── README.md
```

Имена файлов и папок — латиницей, маленькими буквами, без пробелов: `order_new.php`, а не `Новая заявка.php`. На Windows регистр букв не важен, но на Linux-хостинге, куда вы будете выкладывать проект в модуле 7, `Style.css` и `style.css` — разные файлы.

**Первая PHP-страница.** PHP можно вставлять прямо в HTML:

```php
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Портал заявок</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1>Портал «<?= 'Мой Не Сам' ?>»</h1>
  <p>Сегодня <?= date('d.m.Y') ?>, сервер работает на PHP <?= PHP_VERSION ?>.</p>
</body>
</html>
```

`<?= ... ?>` — короткая запись для `<?php echo ... ?>`. Откройте страницу через `localhost`, затем «Просмотр кода страницы» (Ctrl+U): PHP-тегов там нет, только готовые дата и версия. Так вы своими глазами увидите, что PHP работает на сервере.

**Типичные ошибки:**

- Страница открыта как `file:///...` вместо `http://localhost/...`, и PHP «не работает».
- Проект лежит на рабочем столе, а не в `htdocs`, поэтому `localhost` его не видит.
- Apache запущен, а MySQL нет. Сейчас это не мешает, но в модуле 4 вы получите ошибку `Connection refused`.
- Кэш браузера: CSS поменяли, а страница старая. Помогает **Ctrl+F5** или галочка *Disable cache* на вкладке Network при открытых DevTools.
- Файл сохранён как `index.php.txt`, потому что в Windows скрыты расширения. Включите показ расширений в Проводнике.

**Связь с экзаменом.** На экзамене нет интернета для поиска «почему не запускается Apache», поэтому всё это должно быть отработано до автоматизма. Сегодня вы делаете то, что на ДЭ займёт первые три минуты: открыть папку, запустить сервер, проверить, что `localhost` отвечает.

## Задание

**Цель:** подготовить рабочее место и создать каркас своего портала заявок, который открывается на `localhost`.

**Исходные данные:** установленные XAMPP (PHP 8.2), VS Code, Chrome или другой Chromium-браузер; вариант проекта от преподавателя.

**Ход работы:**

1. Запустите панель XAMPP, стартуйте Apache и MySQL. Если не стартует, найдите через Netstat, кто занял порт, и устраните проблему (запишите, что было и как решили).
2. Создайте папку `C:\xampp\htdocs\portal` и откройте её в VS Code через **Open Folder**. Установите PHP Intelephense.
3. Создайте `info.php` с `phpinfo()`, откройте через `localhost`, сделайте скриншот строки с версией PHP и строки `pdo_mysql`. Удалите файл.
4. Создайте структуру папок из лекции (`css`, `js`, `img`, `docs`) и файлы `index.php`, `css/style.css`, `js/main.js`.
5. В `index.php` сверстайте заглушку портала по своему варианту: название компании, слоган, кнопки-ссылки «Войти» и «Регистрация» (ссылки пока ведут на `login.php` и `register.php`, которых ещё нет), текущая дата через PHP.
6. В `style.css` задайте шрифт, цвета, отступы. В `main.js` выведите в консоль `console.log('Портал загружен')`.
7. Откройте DevTools:
   - в Console найдите своё сообщение;
   - в Network нажмите на ссылку «Войти» и найдите ошибку 404, запишите её;
   - в Device Toolbar выставьте 390×844 и сделайте скриншот, как выглядит заглушка на телефоне;
   - в Elements временно поменяйте цвет заголовка и убедитесь, что после F5 правка исчезла.
8. Откройте `http://localhost/phpmyadmin` и проверьте, что он запускается (база пока не нужна).
9. Создайте `README.md`: название проекта, вариант, ваша фамилия, как запустить проект (3–4 строки).

**Что сдать:** папку `portal` (архивом или показать на ПК); 3 скриншота (phpinfo, мобильный вид 390×844, вкладка Network с 404); в `README.md` — запись о проблеме с запуском, если была.

## Критерии оценки

| Аспект | 2 балла | 1 балл | 0 баллов |
|---|---|---|---|
| Сервер | Apache и MySQL запущены, проект открывается по `localhost` | Работает только Apache или проект открыт как `file://` | Сервер не запущен |
| Структура проекта | Все папки и файлы по соглашению, имена латиницей | 1–2 отступления от структуры | Структуры нет, файлы где попало |
| PHP-страница | Заглушка по варианту, дата выводится PHP, подключены CSS и JS | Страница есть, но PHP или CSS не работает | Страницы нет |
| DevTools | Все 4 действия выполнены, скриншоты есть | Выполнено 2–3 действия | Меньше 2 |
| README | Вариант, автор, инструкция запуска | Неполный | Отсутствует |

## Если не успел / для сильных

**Минимум для зачёта:** `http://localhost/portal/` открывает `index.php` с датой, выведенной через PHP.
**Усложнение:** настройте виртуальный хост `http://portal.local` (файлы `httpd-vhosts.conf` и `hosts`) и опишите шаги в README.
