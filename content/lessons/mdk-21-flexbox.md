## Что такое вёрстка

**Вёрстка** — это превращение макета в работающую страницу: расставить блоки так, как их нарисовал дизайнер. Шапка: логотип слева, меню справа. Ниже — три карточки в ряд. В самом низу — подвал с контактами. Всё это нужно разложить по местам, и разложить так, чтобы не развалилось на другом экране.

На демоэкзамене вёрстка по макету — самая большая часть работы. И почти вся она делается двумя инструментами: **Flexbox** (сегодня) и **Grid** (на следующем занятии).

## Поток документа

Сначала вспомним, как браузер расставляет элементы, если мы ничего не говорим. Это называется **нормальный поток документа**:

- **Блочные** элементы (`div`, `p`, `h1`, `section`, `ul`) идут **сверху вниз**, каждый с новой строки, и растягиваются на всю ширину родителя.
- **Строчные** элементы (`a`, `span`, `strong`, `img`) идут **слева направо**, как слова в тексте, и переносятся на новую строку, когда место кончается.

```html
<style>
  .box { padding: 8px; margin-bottom: 4px; background-color: #f2d58a; }
</style>
<div class="box">Первый блок</div>
<div class="box">Второй блок</div>
<p>Абзац со <a href="#a">ссылкой</a> и <strong>важным словом</strong> внутри.</p>
```

Что вы увидите: два жёлтых блока во всю ширину друг под другом, ниже абзац, где ссылка и жирное слово стоят прямо в строке текста.

Поток хорош для текста. Но поставить три карточки в ряд он не умеет: блочные элементы упрямо встают друг под друга. Раньше это обходили хитростями (`float`, `inline-block`), и вёрстка постоянно ломалась. Flexbox решил эту проблему.

## Flex-контейнер и flex-элементы

Flexbox включается одной строкой — у **родителя**:

```html
<style>
  .row { display: flex; }
  .box { padding: 8px; background-color: #f2d58a; border: 1px solid #8a3b12; }
</style>
<div class="row">
  <div class="box">Первый</div>
  <div class="box">Второй</div>
  <div class="box">Третий</div>
</div>
```

Что вы увидите: три блока встали **в ряд** слева направо. Каждый шириной по своему содержимому.

Запомните два слова:

- **Flex-контейнер** — родитель, у которого `display: flex`. Здесь это `.row`.
- **Flex-элементы** — его **прямые** дети. Здесь это три `.box`.

Flexbox управляет только прямыми детьми. Внуков он не трогает: если внутри `.box` лежит список, тот останется обычным списком.

Частая ошибка: написать `display: flex` у самих карточек, а не у их общего родителя. Карточки от этого в ряд не встанут — каждая станет контейнером для своего содержимого. Правило простое: **flex пишем тому, кто должен расставить своих детей**.

Ещё одна частая ошибка: `display: flexbox`. Такого значения нет, браузер молча пропустит строку. Правильно — `display: flex`.

## Две оси

Всё во Flexbox держится на двух осях.

- **Главная ось** — направление, по которому выстраиваются элементы. По умолчанию — слева направо.
- **Поперечная ось** — перпендикулярно главной. По умолчанию — сверху вниз.

Направление главной оси задаёт `flex-direction`:

| Значение | Главная ось | Что получится |
|---|---|---|
| `row` (по умолчанию) | слева направо | элементы в ряд |
| `column` | сверху вниз | элементы в столбик |
| `row-reverse`, `column-reverse` | в обратную сторону | ряд или столбик задом наперёд |

```css
.menu { display: flex; flex-direction: column; }
```

Зачем столбик, если блоки и так идут друг под другом? Потому что во flex-столбике работает всё выравнивание, которое мы сейчас разберём. Например, вертикальное меню на телефоне удобно делать именно так.

Почему оси так важны: свойства выравнивания называются не «по горизонтали» и «по вертикали», а **«по главной оси»** и **«по поперечной»**. Повернули главную ось в `column` — и `justify-content` начал работать сверху вниз.

## justify-content: выравнивание по главной оси

`justify-content` решает, куда девать **свободное место** в ряду.

| Значение | Что делает |
|---|---|
| `flex-start` (по умолчанию) | все элементы прижаты к началу |
| `flex-end` | прижаты к концу |
| `center` | стоят по центру |
| `space-between` | первый у левого края, последний у правого, остальное место поровну между ними |
| `space-around` | одинаковые поля вокруг каждого элемента |
| `space-evenly` | все промежутки, включая края, одинаковые |

```html
<style>
  .row { display: flex; margin-bottom: 8px; padding: 4px; background-color: #eeeeee; }
  .box { padding: 8px; background-color: #f2d58a; }
  .start { justify-content: flex-start; }
  .center { justify-content: center; }
  .between { justify-content: space-between; }
</style>
<div class="row start"><div class="box">А</div><div class="box">Б</div><div class="box">В</div></div>
<div class="row center"><div class="box">А</div><div class="box">Б</div><div class="box">В</div></div>
<div class="row between"><div class="box">А</div><div class="box">Б</div><div class="box">В</div></div>
```

Что вы увидите: в первом ряду блоки слева, во втором — по центру, в третьем — растянуты по краям с равными промежутками.

`space-between` — самое частое значение. Именно им делают шапку «логотип слева, меню справа».

> **Попробуйте сами.** Нажмите «Попробовать» под примером. Поменяйте у третьего ряда `space-between` на `space-evenly` и `space-around`. Чем они отличаются у краёв?

## align-items: выравнивание по поперечной оси

`align-items` выравнивает элементы **поперёк** главной оси — в ряду это по вертикали.

| Значение | Что делает |
|---|---|
| `stretch` (по умолчанию) | растягивает элементы на всю высоту контейнера |
| `flex-start` | прижимает к верху |
| `flex-end` | прижимает к низу |
| `center` | ставит по центру по высоте |
| `baseline` | выравнивает по линии текста |

```html
<style>
  .bar {
    display: flex;
    align-items: center;
    gap: 12px;
    padding: 8px;
    background-color: #eeeeee;
  }
  .bar img { width: 48px; height: 48px; }
</style>
<div class="bar">
  <img src="img/icon.svg" alt="">
  <p>Иконка и текст стоят по центру друг относительно друга</p>
</div>
```

Что вы увидите: иконка и строка текста выровнены по средней линии, текст не «прилип» к верху иконки.

`align-items: center` нужен почти в каждой шапке: логотип и пункты меню разной высоты, а стоять должны на одной линии.

Тут `alt` у иконки пустой: она украшение, рядом есть текст. Так мы договорились ещё на занятии про изображения.

Если одному элементу нужно выровняться иначе, чем остальным, у него пишут `align-self` с теми же значениями: `align-self: flex-end`.

## gap: расстояние между элементами

Раньше расстояние между элементами делали `margin-right`, а у последнего его убирали. С Flexbox всё проще:

```css
.menu {
  display: flex;
  gap: 24px;
}
```

`gap` ставит отступ **только между** элементами: снаружи, у краёв, ничего лишнего. Можно задать два значения: `gap: 16px 24px` — первое между рядами, второе между колонками.

Частая ошибка: и `gap`, и `margin` у элементов одновременно. Отступы складываются, и расстояние получается больше, чем в макете. Выберите что-то одно — лучше `gap`.

## flex-wrap: перенос на новую строку

По умолчанию flex-элементы **все** стараются поместиться в одну строку. Если места мало, они сжимаются, а если сжаться уже нельзя — вылезают за край, и у страницы появляется горизонтальная прокрутка.

`flex-wrap: wrap` разрешает переносить элементы на следующую строку:

```html
<style>
  .tags { display: flex; flex-wrap: wrap; gap: 8px; max-width: 300px; }
  .tag { padding: 4px 12px; border-radius: 999px; background-color: #f2d58a; }
</style>
<div class="tags">
  <span class="tag">HTML</span>
  <span class="tag">CSS</span>
  <span class="tag">Flexbox</span>
  <span class="tag">Grid</span>
  <span class="tag">Адаптивность</span>
  <span class="tag">JavaScript</span>
</div>
```

Что вы увидите: теги идут в ряд, а те, что не поместились в 300px, аккуратно переходят на следующую строку.

`flex-wrap: wrap` почти всегда нужен рядам карточек и тегов: на телефоне карточки встанут друг под друга сами.

## flex: 1 и размеры элементов

Пока что каждый flex-элемент был шириной по своему содержимому. А если нужно, чтобы три карточки **поровну** заняли весь ряд?

```html
<style>
  .cards { display: flex; gap: 16px; }
  .card { flex: 1; padding: 16px; border-radius: 12px; background-color: #f2d58a; }
</style>
<div class="cards">
  <div class="card">Короткий текст</div>
  <div class="card">Текст подлиннее, в две строки или даже в три</div>
  <div class="card">Ещё карточка</div>
</div>
```

Что вы увидите: три карточки одинаковой ширины во весь ряд, причём одинаковой высоты (это работает `align-items: stretch` по умолчанию).

`flex: 1` — это «бери свободное место наравне с остальными». На самом деле это сокращение трёх свойств:

- `flex-grow` — во сколько раз элемент **растёт**, когда есть свободное место. `0` — не растёт, `1` — растёт, `2` — растёт вдвое быстрее соседей;
- `flex-shrink` — может ли элемент **сжиматься**, когда места мало (`1` — может, `0` — нет);
- `flex-basis` — **начальная ширина** элемента до того, как начнут делить место.

Очень полезная запись: `flex: 1 1 220px`. Она значит «начни с 220px, расти и сжимайся по необходимости». Вместе с `flex-wrap: wrap` это даёт ряд, который сам решает, сколько карточек поместится: на широком экране три в ряд, на узком — по одной.

Ещё пример: поиск, где поле занимает всё место, а кнопка — сколько ей нужно:

```html
<style>
  .search { display: flex; gap: 8px; }
  .search input { flex: 1; padding: 8px; }
</style>
<form class="search">
  <label for="q">Поиск по каталогу</label>
  <input id="q" type="search">
  <button type="submit">Найти</button>
</form>
```

Что вы увидите: подпись и кнопка по своей ширине, а поле растянулось на всё оставшееся место.

> **Попробуйте сами.** В примере с тремя карточками поставьте второй карточке `flex: 2`. Как изменилась её ширина по сравнению с соседями?

## Типовые задачи

Почти вся вёрстка складывается из нескольких повторяющихся приёмов. Запомните их — на экзамене они встретятся обязательно.

### Шапка: логотип слева, меню справа

```html
<style>
  .header {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 16px 24px;
    background-color: #1f2a44;
  }
  .header a { color: #ffffff; text-decoration: none; }
  .menu { display: flex; gap: 24px; margin: 0; padding: 0; list-style: none; }
</style>
<header class="header">
  <a href="#top">Библиотека колледжа</a>
  <nav>
    <ul class="menu">
      <li><a href="#books">Книги</a></li>
      <li><a href="#rules">Правила</a></li>
      <li><a href="#contacts">Контакты</a></li>
    </ul>
  </nav>
</header>
```

Что вы увидите: тёмную полосу, где название прижато влево, меню — вправо, всё на одной линии по высоте.

Здесь **два** flex-контейнера. `.header` раздвигает логотип и `nav`. `.menu` ставит пункты списка в ряд. Это нормально: flex-контейнеры можно вкладывать друг в друга сколько угодно. У списка мы убрали маркеры (`list-style: none`) и отступы браузера (`margin: 0; padding: 0`).

Вариант: если справа от логотипа нужно меню, а у самого края — кнопка «Войти», кнопке ставят `margin-left: auto`. Автоматический отступ «съедает» всё свободное место и отталкивает элемент к краю.

### Ряд карточек

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 24px;
}
.card {
  flex: 1 1 240px;
}
```

На компьютере — несколько карточек в ряд одинаковой ширины, на телефоне — по одной друг под другом. Без единого медиазапроса.

### Центрирование

Поставить блок ровно в центр — когда-то это была головоломка. С Flexbox — три строки у родителя:

```html
<style>
  .screen {
    display: flex;
    justify-content: center;
    align-items: center;
    min-height: 300px;
    background-color: #e8f0fe;
  }
  .notice { padding: 24px; border-radius: 12px; background-color: #ffffff; }
</style>
<div class="screen">
  <p class="notice">Вы записаны к терапевту на 14:30</p>
</div>
```

Что вы увидите: белую плашку ровно в центре голубого блока — и по горизонтали, и по вертикали.

Обратите внимание на `min-height`. Без высоты контейнер будет ровно по размеру плашки, и центрировать по вертикали будет не в чем.

Частая ошибка: центрировать подбором отступов — `margin-left: 300px; margin-top: 120px`. На вашем экране выглядит ровно, а на другом — криво, на телефоне блок вообще уезжает за край.

### Карточка с кнопкой внизу

У карточек разный текст, а кнопки «Подробнее» должны стоять на одной линии внизу. Делаем карточку flex-столбиком, а кнопке — `margin-top: auto`:

```css
.card {
  display: flex;
  flex-direction: column;
}
.card__btn {
  margin-top: auto;
}
```

## Порядок на экране и в коде

У flex-элементов есть свойство `order`, которое меняет порядок показа, а `row-reverse` переворачивает ряд. Пользуйтесь ими осторожно: экранный диктор и клавиша Tab идут **по порядку в коде**, а не на экране. Если глазами видно «1, 2, 3», а Tab прыгает «3, 1, 2», человеку с клавиатурой будет трудно. Лучше сразу писать HTML в нужном порядке.

## Главное за занятие

- Без подсказок браузер раскладывает элементы по **потоку**: блочные сверху вниз, строчные в строку.
- `display: flex` пишется у **родителя**, а раскладывает его **прямых детей**.
- Главная ось задаётся `flex-direction` (`row` или `column`); `justify-content` выравнивает по главной оси, `align-items` — по поперечной.
- `gap` — расстояние между элементами, `flex-wrap: wrap` — перенос на новую строку.
- `flex: 1` делит место поровну; `flex: 1 1 240px` с переносом — ряд карточек, который сам подстраивается под экран.
- Типовые приёмы: шапка (`space-between` + `center`), ряд карточек (`wrap` + `gap` + `flex`), центрирование (`center` + `center` + высота).

## Словарик

- **Вёрстка** — перенос макета в HTML и CSS: расстановка блоков по местам.
- **Поток документа** — порядок, в котором браузер расставляет элементы без дополнительных указаний.
- **Flex-контейнер** — элемент с `display: flex`.
- **Flex-элемент** — прямой ребёнок flex-контейнера.
- **Главная ось** — направление, по которому выстраиваются flex-элементы.
- **Поперечная ось** — направление, перпендикулярное главной.
- **Свободное место** — часть контейнера, не занятая элементами; его распределяют `justify-content` и `flex-grow`.

- [ ] Добавляет внутренний отступ контейнеру
- [x] Ставит 16px между соседними элементами, но не у краёв
- [ ] Ставит отступ 16px снаружи каждого элемента
> `gap` — только промежутки между элементами.

? Карточки на телефоне вылезают за край экрана. Что добавить контейнеру?
- [x] `flex-wrap: wrap`
- [ ] `flex-direction: row`
- [ ] `align-items: stretch`
> По умолчанию flex-элементы держатся в одной строке. `wrap` разрешает перенос.

? Что сделает `flex: 1` у трёх карточек в одном ряду?
- [ ] Каждая станет шириной 1px
- [ ] Только первая карточка растянется
- [x] Свободное место поделится между ними поровну
> `flex: 1` — «расти наравне с остальными».

? Блок `.notice` должен стоять ровно в центре `.screen`. Чего не хватает в `.screen { display: flex; justify-content: center; align-items: center; }`, если `.screen` по высоте совпадает с плашкой?
- [ ] `flex-wrap: wrap`
- [x] Высоты контейнера, например `min-height: 300px`
- [ ] `text-align: center`
> Чтобы центрировать по вертикали, у контейнера должно быть свободное место по высоте.
