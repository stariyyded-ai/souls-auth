## От одной страницы к сайту

До сих пор мы оформляли одну страницу. Настоящий сайт — это десятки страниц: главная, «О нас», каталог, контакты. И у всех должен быть одинаковый вид: тот же шрифт, те же цвета, такая же шапка и такие же кнопки.

Представьте сайт кафе из пяти страниц. Если стили написаны внутри каждой страницы в теге `<style>`, то, чтобы поменять цвет кнопки, придётся открыть все пять файлов и в каждом найти нужное место. Забыли один — и на странице «Доставка» кнопка осталась старого цвета.

Поэтому правило простое: **один файл стилей на весь сайт**. Обычно его называют `style.css` и кладут в папку `css`:

```text
cafe/
├── index.html
├── menu.html
├── contacts.html
└── css/
    └── style.css
```

Каждая страница подключает этот файл одной строкой в `<head>`:

```html
<link rel="stylesheet" href="css/style.css">
```

Что это даёт:

- Поменяли цвет в одном месте — он поменялся на всех страницах.
- Браузер скачивает `style.css` один раз и запоминает (кэширует). Следующие страницы открываются быстрее.
- HTML остаётся чистым: в нём только содержимое, всё оформление — в CSS.

На демонстрационном экзамене тоже проверяют, что стили вынесены во внешний файл, а не разбросаны по страницам и атрибутам `style`.

## Порядок внутри style.css

Чтобы в большом файле не заблудиться, правила пишут в одном и том же порядке — от общего к частному:

1. **Переменные** — цвета и другие общие значения.
2. **Сброс** — убираем различия между браузерами.
3. **Общие стили** — `body`, заголовки, абзацы, ссылки.
4. **Блоки сайта** — шапка, меню, подвал.
5. **Компоненты** — кнопки, карточки, формы.

Разделы удобно подписывать комментариями. В CSS комментарий пишется так: `/* текст */`.

```css
/* ===== Переменные ===== */
:root { --color-main: #1f4e79; }

/* ===== Сброс ===== */
* { box-sizing: border-box; }

/* ===== Общие стили ===== */
body { margin: 0; font-family: Arial, sans-serif; line-height: 1.5; }

/* ===== Шапка ===== */
.header { padding: 16px 24px; }
```

Почему важен порядок? Вспомните **каскад** из прошлого занятия: при одинаковой специфичности побеждает правило, которое стоит ниже. Если общие стили окажутся в конце файла, они перебьют стили компонентов.

## Сброс стилей

У каждого браузера есть свои стили по умолчанию. Вы их уже видели: у `body` есть отступ 8px, у `h1` — большие отступы сверху и снизу, у списка `ul` — точки и отступ слева. В разных браузерах эти значения чуть-чуть отличаются.

**Сброс** (reset) — несколько правил в начале CSS, которые убирают ненужные стили браузера, чтобы дальше всё строить с чистого листа. Есть и мягкий вариант — **нормализация** (normalize): она не обнуляет всё подряд, а только выравнивает различия между браузерами. Готовые файлы `normalize.css` можно скачать, но для учебного сайта хватит короткого сброса:

```css
* { box-sizing: border-box; }

body {
  margin: 0;
  font-family: Arial, sans-serif;
  line-height: 1.5;
  color: #222222;
  background-color: #ffffff;
}

img { max-width: 100%; }
```

Разберём по строкам:

- `* { box-sizing: border-box; }` — звёздочка выбирает все элементы. Теперь ширина блока включает `padding` и рамку. Вы видели это на прошлом занятии: блок шириной 300px с отступами 20px остаётся шириной 300px.
- `body { margin: 0; }` — убираем отступ браузера вокруг страницы.
- Шрифт, межстрочный интервал и цвет задаём один раз в `body`. Эти свойства **наследуются**: все абзацы, списки и ячейки таблиц получат их сами.
- `img { max-width: 100%; }` — картинка никогда не станет шире своего блока.

Частая ошибка: сбросить у списков всё (`ul { list-style: none; padding: 0; }`) прямо в начале файла. Тогда точки исчезнут и у обычных списков в статьях. Сбрасывайте только у тех списков, которые станут меню, — через их класс.

## Классы для повторяющихся элементов

На сайте многое повторяется: десять карточек товаров, двадцать кнопок, три блока новостей. Оформлять каждый отдельно по `id` — плохая идея:

```css
#robot { padding: 16px; border: 1px solid #c9d3df; }
#design { padding: 16px; border: 1px solid #c9d3df; }
#chess { padding: 16px; border: 1px solid #c9d3df; }
```

Три одинаковых правила. Добавится четвёртый кружок — придётся писать четвёртое. А если решили поменять рамку — править в трёх местах.

**Класс** решает эту задачу: одно правило — сколько угодно элементов.

```html
<style>
  .card { width: 260px; padding: 16px; border: 1px solid #c9d3df; margin-bottom: 12px; }
</style>
<div class="card">Робототехника</div>
<div class="card">Веб-дизайн</div>
<div class="card">Шахматы</div>
```

Что увидите: три одинаковые рамки с отступами. Четвёртую карточку можно добавить, не трогая CSS.

Правило для сайта: **для оформления используем классы**. Селекторы по тегу — только для общих стилей (`body`, `h1`, `p`, `a`). Селекторы по `id` для оформления не используем: их специфичность слишком высокая, такое правило потом трудно перебить, и `id` на странице может быть только один.

У элемента может быть несколько классов через пробел: `class="card card--accent"`. Оба правила применятся к нему вместе.

> **Попробуйте сами.** Нажмите «Попробовать» под примером с карточками. Добавьте четвёртый `<div class="card">` со своим кружком. Потом поменяйте в CSS толщину рамки на 3px — изменятся сразу все карточки.

## Как называть классы

Имя класса придумываете вы. Хорошее имя говорит, **что это**, а не **как выглядит**:

| Плохо | Почему | Хорошо |
|---|---|---|
| `.red-text` | Завтра дизайнер сделает текст синим, а имя останется «красным» | `.error` |
| `.big` | Непонятно, что большое | `.page-title` |
| `.block1`, `.div2` | Через неделю не вспомнить, что это | `.news`, `.footer` |
| `.Menu_Top` | Разный регистр — легко ошибиться | `.menu` |

Правила для имён:

- Только латиница, цифры и дефис. Без пробелов и русских букв.
- Строчные буквы. Слова соединяются дефисом: `.site-header`, `.price-list`.
- Имя по смыслу: `.card`, `.button`, `.menu`, `.footer`.

### БЭМ — кратко

Когда классов становится много, их удобно называть по системе **БЭМ** (Блок, Элемент, Модификатор). Её придумали в Яндексе, и ею пользуются многие команды.

- **Блок** — самостоятельная часть страницы: `card`, `menu`, `header`.
- **Элемент** — часть блока, которая без него не имеет смысла. Пишется через два подчёркивания: `card__title`, `card__text`, `menu__link`.
- **Модификатор** — вариант блока или элемента. Пишется через два дефиса: `card--accent`, `button--secondary`, `menu__link--active`.

```html
<style>
  .card { width: 260px; padding: 16px; border: 1px solid #c9d3df; margin-bottom: 12px; }
  .card__title { margin: 0 0 8px; font-size: 20px; color: #1f4e79; }
  .card__text { margin: 0; }
  .card--accent { border: 2px solid #b3541e; background-color: #fff4ec; }
</style>
<div class="card">
  <h2 class="card__title">Робототехника</h2>
  <p class="card__text">Вторник, 16:00</p>
</div>
<div class="card card--accent">
  <h2 class="card__title">Шахматы</h2>
  <p class="card__text">Новый набор! Пятница, 17:00</p>
</div>
```

Что увидите: две карточки с синими заголовками. Вторая — с оранжевой рамкой и тёплым фоном: модификатор поменял только то, что отличается, остальное карточка взяла из `.card`.

Плюсы БЭМ: по имени `card__title` сразу понятно, где искать элемент; у всех классов одинаковая специфичность, поэтому стили не «воюют» друг с другом. Частая ошибка: писать модификатор без основного класса — `class="card--accent"`. Тогда пропадут все базовые стили карточки. Правильно: `class="card card--accent"`.

## CSS-переменные для цветов

В дизайне сайта обычно 3–5 цветов: основной, акцентный, цвет текста, фон. И каждый встречается в CSS десятки раз. Заказчик говорит: «Сделайте синий чуть темнее» — и вы ищете по всему файлу `#1f4e79`.

**CSS-переменная** (официально — пользовательское свойство) хранит значение под именем. Объявляем один раз, используем сколько угодно:

```css
:root {
  --color-main: #1f4e79;
  --color-accent: #b3541e;
  --color-text: #222222;
}

h1 { color: var(--color-main); }
a { color: var(--color-main); }
.button { background-color: var(--color-accent); }
```

Как это устроено:

- Имя переменной начинается с **двух дефисов**: `--color-main`.
- Объявляем в правиле `:root` — это корневой элемент страницы (`html`). Переменные наследуются, поэтому объявленные в `:root` видны во всём документе.
- Чтобы взять значение, пишем `var(--color-main)`.

```html
<style>
  :root { --color-main: #1f4e79; --color-accent: #b3541e; }
  h1 { color: var(--color-main); }
  p { border-left: 4px solid var(--color-accent); padding-left: 12px; }
  a { color: var(--color-main); }
</style>
<h1>Библиотека колледжа</h1>
<p>Учебники выдаются на две недели. <a href="#rules">Правила библиотеки</a></p>
```

Что увидите: синий заголовок, абзац с оранжевой полосой слева и синяя ссылка.

> **Попробуйте сами.** В примере выше поменяйте значение `--color-main` на `#2e7d32` (зелёный). Перекрасятся и заголовок, и ссылка — хотя вы изменили одну строку.

Частые ошибки: забыть дефисы (`var(color-main)`), написать с одним дефисом (`-color-main`) или опечататься в имени. Если переменная не найдена, свойство не сработает и браузер возьмёт значение по наследству или по умолчанию. Регистр в имени важен: `--Color-Main` и `--color-main` — разные переменные.

На экзамене переменные очень пригодятся: стайлгайд из Figma (палитра, размеры) удобно перенести в `:root` и дальше пользоваться только переменными. Подробнее о палитре поговорим в теме «Веб-дизайн».

## Ссылки и их состояния

У ссылки есть **состояния**: обычное, при наведении мыши, в фокусе с клавиатуры, уже посещённая. Для каждого состояния в CSS есть **псевдокласс** — слово через двоеточие после селектора:

| Псевдокласс | Когда срабатывает |
|---|---|
| `:hover` | Наведён указатель мыши |
| `:focus` | Элемент в фокусе: на него перешли клавишей Tab или кликнули |
| `:focus-visible` | Фокус, который нужно показать: обычно при переходе с клавиатуры |
| `:active` | В момент нажатия |
| `:visited` | Ссылка уже посещена |

```html
<style>
  a { color: #1f4e79; }
  a:hover { color: #b3541e; }
  a:focus-visible { outline: 3px solid #f2a541; }
</style>
<p>Расписание — на странице <a href="#schedule">«Расписание звонков»</a>.</p>
<p>Контакты — в разделе <a href="#contacts">«Приёмная комиссия»</a>.</p>
```

Что увидите: при наведении ссылка становится оранжевой. Нажмите в песочнице на предпросмотр, потом клавишу Tab — вокруг ссылки появится жёлтая рамка фокуса.

**Рамка фокуса** — свойство `outline`. Оно похоже на `border`, но не занимает места и не сдвигает соседей: `outline: 3px solid #f2a541;` (толщина, стиль, цвет). Свойство `outline-offset` отодвигает рамку от элемента.

Почему это важно. Многие люди пользуются сайтом без мыши: у кого-то болит рука, кто-то не видит экран и слушает экранного диктора, кому-то просто быстрее клавиатурой. Они переходят по ссылкам и кнопкам клавишей Tab и видят, где находятся, только по рамке фокуса.

Частая ошибка: убрать рамку, потому что «некрасиво»: `a:focus { outline: none; }`. После этого человек с клавиатурой теряется на странице. Если рамка браузера не нравится — не удаляйте её, а сделайте свою, красивую, через `:focus-visible`.

Ещё одно правило: ссылку в тексте **не отличают только цветом**. Человек, который плохо различает цвета, не увидит синий на чёрном. Поэтому в тексте статьи подчёркивание лучше оставлять. Убирать его можно там, где и так понятно, что это ссылка: в меню, в кнопке.

## Меню

Меню сайта — это **список ссылок** внутри `nav`. Список потому, что это перечень разделов, и экранный диктор скажет: «список, 3 пункта».

```html
<style>
  .menu__list { list-style: none; margin: 0; padding: 0; }
  .menu__item { display: inline-block; margin-right: 16px; }
  .menu__link { color: #1f4e79; font-weight: bold; text-decoration: none; }
  .menu__link:hover { text-decoration: underline; }
  .menu__link:focus-visible { outline: 3px solid #f2a541; }
</style>
<nav class="menu">
  <ul class="menu__list">
    <li class="menu__item"><a class="menu__link" href="#home">Главная</a></li>
    <li class="menu__item"><a class="menu__link" href="#schedule">Расписание</a></li>
    <li class="menu__item"><a class="menu__link" href="#contacts">Контакты</a></li>
  </ul>
</nav>
```

Что увидите: три жирные синие ссылки в одну строку, без точек. При наведении ссылка подчёркивается.

Что здесь происходит:

- `list-style: none` убирает маркеры, `padding: 0` — отступ слева, который браузер даёт спискам.
- `li` по умолчанию блочный — каждый пункт с новой строки. `display: inline-block` ставит пункты в строку, как слова, но разрешает им отступы.
- Стили меню привязаны к классам `.menu__…`, поэтому обычные списки на странице остаются с точками.

Позже, на занятии про Flexbox, вы узнаете более удобный способ раскладывать пункты в строку. А `inline-block` пригодится и потом: так работают значки, бейджи, кнопки в тексте.

## Кнопки

Кнопка — главный элемент действия: «Записаться», «Купить», «Отправить». Её стиль описывают классом, чтобы одинаково выглядели и `<button>`, и ссылка, оформленная как кнопка.

```html
<style>
  :root { --color-main: #1f4e79; --color-main-dark: #163a5a; --color-focus: #f2a541; }
  .button {
    display: inline-block;
    padding: 12px 24px;
    border: 0;
    background-color: var(--color-main);
    color: #ffffff;
    font-size: 16px;
    text-decoration: none;
    cursor: pointer;
  }
  .button:hover { background-color: var(--color-main-dark); }
  .button:focus-visible { outline: 3px solid var(--color-focus); outline-offset: 2px; }
</style>
<button class="button" type="button">Записаться</button>
<a class="button" href="#price">Смотреть цены</a>
```

Что увидите: две одинаковые синие кнопки — настоящая кнопка и ссылка. При наведении обе темнеют, у обеих курсор-«рука».

Разберём новое:

- `cursor: pointer` — указатель в виде руки, подсказывает: «на это можно нажать».
- `border: 0` — убираем серую рамку, которую браузер рисует у `button`.
- `text-decoration: none` нужен ссылке-кнопке: иначе текст будет подчёркнут.
- Цвет при наведении темнее основного — так пользователь видит, что кнопка «отзывается».

Когда что использовать: `<button>` — для действия на этой странице (отправить форму, открыть меню). `<a>` — для перехода на другую страницу или раздел. Выглядеть они могут одинаково, а работают по-разному.

> **Попробуйте сами.** В примере с кнопками добавьте правило `.button:active { background-color: #0f2a42; }`. Нажмите на кнопку и не отпускайте — она станет ещё темнее, как будто её вдавили.

## Главное за занятие

- На весь сайт — один файл `style.css`, подключённый через `<link>` на каждой странице.
- Внутри файла порядок: переменные, сброс, общие стили, блоки, компоненты.
- Сброс (`box-sizing`, `margin` у `body`) убирает различия браузеров. Шрифт и цвет задаём в `body` — их унаследуют все.
- Повторяющиеся элементы оформляем классами, а не `id`. Имя класса — по смыслу. БЭМ: `блок__элемент--модификатор`.
- Цвета храним в переменных `:root { --color-main: … }` и берём через `var(--color-main)`.
- У ссылок и кнопок есть состояния `:hover` и `:focus-visible`. Рамку фокуса не удаляем.
- Меню — список ссылок в `nav`; пункты в строку ставит `display: inline-block`.

## Словарик

- **Сброс (reset)** — правила в начале CSS, которые убирают стили браузера по умолчанию.
- **Нормализация (normalize)** — мягкий сброс: выравнивает различия между браузерами.
- **БЭМ** — система имён классов: блок, элемент (`__`), модификатор (`--`).
- **CSS-переменная** — именованное значение `--имя`, которое берут через `var(--имя)`.
- **`:root`** — корневой элемент документа, место для общих переменных.
- **Псевдокласс** — состояние элемента в селекторе: `:hover`, `:focus-visible`.
- **Фокус** — элемент, с которым сейчас работает клавиатура.
- **`outline`** — рамка вокруг элемента, которая не занимает места; используется для фокуса.
