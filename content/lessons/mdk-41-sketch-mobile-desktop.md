## Коротко о теории

Экран телефона в 4 раза уже экрана ноутбука. Всё, что на компьютере стоит рядом, на телефоне придётся поставить **друг под другом** — и тогда страница станет очень длинной. Поэтому мобильный эскиз — не «уменьшенная копия», а отдельное решение. Дизайнер отвечает на четыре вопроса:

| Вопрос | Пример решения | Как в CSS |
|---|---|---|
| **Что переставить?** | Колонки встают друг под другом; главный блок — первым | `grid-template-columns: 1fr`, `flex-direction: column`, `order` |
| **Что спрятать?** | Меню — за кнопку «Меню»; второстепенные подсказки — убрать или свернуть | `display: none` в медиазапросе |
| **Что растянуть?** | Поля и главная кнопка — на всю ширину, по ним проще попасть пальцем | `width: 100%` |
| **Что уменьшить?** | Отступы, размер крупных заголовков | меньшие `padding`, `gap`, `font-size` |

Главный принцип — **приоритет контента**. Составьте список блоков экрана от самого важного к наименее важному. На телефоне блоки идут именно в этом порядке. Если блок в конце списка и без него можно обойтись — его прячут или убирают за ссылку «Подробнее».

Частая ошибка — прятать на телефоне то, что нужно. Если пользователь пришёл с телефона забронировать книгу, а кнопка брони спрятана «для экономии места», сайт бесполезен. Прятать можно только второстепенное: декоративные картинки, дубли, подсказки, которые есть в другом месте.

Вспомните **mobile first** из занятия 22: сначала пишем стили для телефона, потом в `@media (min-width: …)` добавляем раскладку для больших экранов. В сегодняшних заданиях эскизы уже свёрстаны для компьютера — так часто бывает на работе, — поэтому будем дописывать `@media (max-width: 767px)` для телефона. Оба способа рабочие, важно понимать, какой выбран.

```css
/* Компьютер: две колонки */
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
}
/* Телефон: всё до 767px включительно */
@media (max-width: 767px) {
  .layout {
    grid-template-columns: 1fr;
  }
}
```

Порядок элементов в сетке и флексе меняет свойство **`order`**: по умолчанию у всех 0, элементы с бо́льшим числом уходят в конец. HTML при этом не меняется, поэтому экранный диктор читает блоки в исходном порядке — переставляйте только то, что не ломает смысл.

```html
<style>
  .box { display: flex; flex-direction: column; gap: 8px; font-family: Arial, sans-serif; }
  .box div { padding: 16px; background-color: #e0e0e0; }
  .first { order: 2; }
</style>
<div class="box">
  <div class="first">Первый в HTML, но order: 2</div>
  <div>Второй в HTML</div>
  <div>Третий в HTML</div>
</div>
```

Вы увидите три серых блока: «Первый в HTML» стоит последним, потому что у него `order: 2`, а у остальных — 0.

## Ход работы

### Шаг 1. Приоритет блоков (5 мин)

Возьмите список блоков главной страницы с прошлого занятия. Перепишите его в порядке важности для студента, который пришёл **с телефона**. Рядом с каждым блоком поставьте значок:

- ↓ — переставить в столбик;
- ✕ — спрятать на телефоне;
- ↔ — растянуть на всю ширину;
- = — оставить как есть.

Пример для экрана каталога: результаты поиска (=, первым), фильтр (свернуть в кнопку), новости библиотеки (↓, в конец), карточки (↓, в одну колонку).

### Шаг 2. Два эскиза от руки (5 мин)

1. На одном листе нарисуйте рядом две рамки: широкую (компьютер) и узкую высокую (телефон, примерно 1:2).
2. В широкую перенесите эскиз главной с прошлого занятия.
3. В узкую нарисуйте тот же экран по своему списку приоритетов: меню — кнопкой «Меню» в шапке, карточки — столбиком, поле поиска и кнопка — на всю ширину.
4. Стрелками соедините одинаковые блоки на двух эскизах. Если стрелки сильно перекрещиваются — значит, порядок блоков поменялся. Это нормально, но каждое такое решение нужно уметь объяснить.

### Шаг 3. Мобильный фрейм в Figma (10 мин)

1. В файле «Библиотека — эскизы» нажмите `F` и выберите фрейм **Android Small 360×640** (или задайте размер вручную).
2. Добавьте сетку: Layout grid → Columns, Count 4, Margin 16, Gutter 16. На телефоне 4 колонки, а не 12.
3. Скопируйте блоки из десктопного фрейма (Ctrl+C, Ctrl+V) и перестройте их в столбик по сетке.
4. Меню замените кнопкой «Меню» в правом верхнем углу; кнопки и поля растяните на все 4 колонки.
5. Фрейм может быть выше 640 — страница на телефоне прокручивается. Отметьте горизонтальной пунктирной линией, где заканчивается первый экран: что попало выше линии, пользователь увидит сразу.

### Шаг 4. Шапка для двух экранов — задание 1 (25 мин)

Откройте задание «Шапка эскиза: компьютер и телефон». Посмотрите предпросмотр: на широком экране всё в порядке, но кнопка «Меню» лишняя. Теперь нажмите «Проверить» и посмотрите на строки чек-листа с пометкой «телефон 360px»: на узком экране меню не помещается, страница уезжает вбок. Можно и сузить окно браузера, чтобы увидеть это глазами.

1. Спрячьте `.burger` для компьютера: `display: none`.
2. Добавьте `@media (max-width: 767px)` и внутри: спрячьте `.nav`, покажите `.burger`.
3. Уменьшите на телефоне `gap` и `padding` шапки, чтобы исчезла горизонтальная прокрутка.

Сама кнопка «Меню» в эскизе ничего не открывает — как сделать её рабочей с `aria-expanded`, вы уже знаете из занятия 29.

### Шаг 5. Каталог: что переставить — задание 2 (30 мин)

Откройте задание «Каталог: что переставить на телефоне». На компьютере колонка новостей стоит слева от результатов поиска. На телефоне она оказалась бы первой — а студент пришёл за книгой.

1. В медиазапросе переведите `.layout` в одну колонку.
2. Отправьте `.news` в конец с помощью `order: 2`.
3. Переведите сетку карточек `.cards` в одну колонку.
4. Проверьте ширину 360px: нет прокрутки, результаты первые, новости внизу.

Частая ошибка: поменять порядок в HTML. На телефоне станет хорошо, а на компьютере новости переедут вправо — сломалась другая версия. Порядок для одного экрана меняем в CSS.

### Шаг 6. Экран брони — задание 3 (25 мин)

Откройте задание «Экран брони: что спрятать и растянуть».

1. Спрячьте подсказку `.tips` на телефоне.
2. Разверните строку полей `.row` (и всю раскладку `.screen`) в столбик: `flex-direction: column`.
3. Растяните поля `input` и кнопку `.btn` на всю ширину формы. Не забудьте `box-sizing: border-box`, иначе поле с отступами вылезет за край.

```css
@media (max-width: 767px) {
  input {
    width: 100%;
    box-sizing: border-box;
  }
}
```

Широкая кнопка на телефоне — не прихоть: в неё легко попасть большим пальцем любой руки.

### Шаг 7. Проверка и сдача (5 мин)

1. Положите рядом бумажные эскизы, фреймы Figma и предпросмотр заданий на 360px и 1024px. Решения совпадают?
2. Пройдите по критериям оценки.
3. Покажите преподавателю оба эскиза на бумаге и оба фрейма в Figma.

## Задания на сайте

2. **Каталог: что переставить на телефоне** — одна колонка, главное первым, новости в конец.
