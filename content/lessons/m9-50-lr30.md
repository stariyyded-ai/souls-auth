## Лекция

Пока заявок десять, админ видит их все на одном экране. Когда их станет 500, страница превратится в бесконечную простыню. Сегодня добавим три инструмента, которые есть в любой настоящей админке: **фильтр по статусу**, **сортировку** и **постраничный вывод** (пагинацию).

**Всё через GET.** Фильтр и сортировка ничего не меняют в базе — только показывают. Значит, это GET-параметры: `admin.php?status=new&sort=date&page=2`. Плюсы: адрес можно сохранить в закладки, F5 не задаёт вопросов, кнопка «Назад» работает.

**Фильтр по статусу: белый список + подготовленный запрос.** Значение статуса приходит от пользователя, поэтому:

1. Проверяем, что оно есть среди ключей `STATUSES`. Нет — значит «все статусы».
2. В запрос подставляем через метку `:status`.

**Сортировка: только белый список.** В ПР19 мы говорили: имя столбца и `ASC/DESC` нельзя передать через `?`. Значит, нельзя и вклеивать `$_GET['sort']` в SQL — это прямая инъекция. Решение — словарь «код из адреса → готовый кусок SQL», который написали **мы**:

```php
<?php
const SORTS = [
    'new'  => ['Сначала новые',            'r.created_at DESC'],
    'old'  => ['Сначала старые',           'r.created_at ASC'],
    'date' => ['По дате выполнения',       'r.date_time ASC'],
    'fio'  => ['По ФИО заказчика',         'u.fio ASC, r.created_at DESC'],
];
$sort = $_GET['sort'] ?? 'new';
if (!is_string($sort) || !array_key_exists($sort, SORTS)) {
    $sort = 'new';
}
$orderBy = SORTS[$sort][1];   // в SQL попадает только наш текст
```

Что бы пользователь ни написал в адресе, в SQL попадёт одна из четырёх строк, написанных нами.

**Пагинация: LIMIT и OFFSET.** Показываем по 10 заявок. Для страницы `N`:

- `LIMIT 10` — взять 10 строк;
- `OFFSET (N − 1) × 10` — пропустить предыдущие.

Чтобы нарисовать кнопки страниц, нужно знать общее количество: отдельный запрос `SELECT COUNT(*)` с тем же фильтром. Тогда `страниц = ceil(всего / 10)`.

Номер страницы приводим к целому и ограничиваем: не меньше 1 и не больше последней. `LIMIT` и `OFFSET` передаём через `bindValue(..., PDO::PARAM_INT)` — они должны быть числами. (Мы выключили эмуляцию подготовки в `db.php`, поэтому числа и так передаются корректно, но явный тип — хорошая привычка.)

**Ссылки, сохраняющие фильтры.** Кнопка «Страница 3» должна помнить выбранный фильтр и сортировку. Собирать адрес вручную через точки — путь к ошибкам. Есть функция `http_build_query()`:

```php
<?php
echo http_build_query(['status' => 'new', 'sort' => 'fio', 'page' => 3]);
// status=new&sort=fio&page=3  (и правильно закодирует русские буквы и пробелы)
```

**После смены статуса — вернуться туда же.** Админ отфильтровал «Новые», открыл 3-ю страницу, сменил статус — и хочет остаться там же. Форма отправляется на `admin.php?` + текущие параметры, а после сохранения делаем редирект с теми же параметрами.

**Полный файл `admin.php` (итоговая версия):**

```php
<?php
require_once __DIR__ . '/includes/auth.php';
require_admin();

const PER_PAGE = 10;
const SORTS = [
    'new'  => ['Сначала новые',      'r.created_at DESC'],
    'old'  => ['Сначала старые',     'r.created_at ASC'],
    'date' => ['По дате выполнения', 'r.date_time ASC'],
    'fio'  => ['По ФИО заказчика',   'u.fio ASC, r.created_at DESC'],
];

// --- Параметры отображения (GET) ---
$status = $_GET['status'] ?? '';
if (!is_string($status) || !array_key_exists($status, STATUSES)) {
    $status = '';
}
$sort = $_GET['sort'] ?? 'new';
if (!is_string($sort) || !array_key_exists($sort, SORTS)) {
    $sort = 'new';
}
$page = max(1, (int)($_GET['page'] ?? 1));
$query = ['status' => $status, 'sort' => $sort, 'page' => $page];
$selfUrl = 'admin.php?' . http_build_query($query);

// --- Смена статуса (POST) ---
$error = '';
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    check_csrf();
    $id     = (int)post('id');
    $new    = post('status');
    $reason = post('cancel_reason');

    $stmt = $pdo->prepare('SELECT id FROM requests WHERE id = ?');
    $stmt->execute([$id]);

    if (!$stmt->fetch()) {
        $error = 'Заявка не найдена';
    } elseif (!array_key_exists($new, STATUSES)) {
        $error = 'Недопустимый статус';
    } elseif ($new === 'cancelled' && ($reason === '' || mb_strlen($reason) > 255)) {
        $error = "Заявка №$id: при отмене укажите причину (до 255 символов)";
    } else {
        $stmt = $pdo->prepare('UPDATE requests SET status = ?, cancel_reason = ? WHERE id = ?');
        $stmt->execute([$new, $new === 'cancelled' ? $reason : null, $id]);
        set_flash('success', "Статус заявки №$id сохранён.");
        redirect($selfUrl);
    }
}

// --- Фильтр ---
$where = '';
$params = [];
if ($status !== '') {
    $where = 'WHERE r.status = :status';
    $params[':status'] = $status;
}

// --- Сколько всего и сколько страниц ---
$stmt = $pdo->prepare("SELECT COUNT(*) FROM requests r $where");
$stmt->execute($params);
$total = (int)$stmt->fetchColumn();
$pages = max(1, (int)ceil($total / PER_PAGE));
$page  = min($page, $pages);
$offset = ($page - 1) * PER_PAGE;

// --- Сами заявки ---
$orderBy = SORTS[$sort][1];
$sql = "SELECT r.*, u.fio, u.email, s.name AS service_name
        FROM requests r
        JOIN users u    ON u.id = r.user_id
        JOIN services s ON s.id = r.service_id
        $where
        ORDER BY $orderBy
        LIMIT :limit OFFSET :offset";
$stmt = $pdo->prepare($sql);
foreach ($params as $name => $value) {
    $stmt->bindValue($name, $value);
}
$stmt->bindValue(':limit', PER_PAGE, PDO::PARAM_INT);
$stmt->bindValue(':offset', $offset, PDO::PARAM_INT);
$stmt->execute();
$requests = $stmt->fetchAll();

// Ссылка с текущими параметрами, где часть заменена
function admin_url(array $query, array $changes): string
{
    return 'admin.php?' . http_build_query(array_merge($query, $changes));
}

$title = 'Панель администратора';
require __DIR__ . '/includes/header.php';
?>
<h1 class="h3 mb-3">Панель администратора</h1>

<?php if ($error !== ''): ?>
    <div class="alert alert-danger"><?= e($error) ?></div>
<?php endif; ?>

<form method="get" action="admin.php" class="row g-2 align-items-end mb-3">
    <div class="col-12 col-sm-5">
        <label class="form-label small" for="f_status">Статус</label>
        <select class="form-select" id="f_status" name="status">
            <option value="">Все статусы</option>
            <?php foreach (STATUSES as $value => $label): ?>
                <option value="<?= e($value) ?>" <?= $value === $status ? 'selected' : '' ?>><?= e($label) ?></option>
            <?php endforeach; ?>
        </select>
    </div>
    <div class="col-12 col-sm-5">
        <label class="form-label small" for="f_sort">Сортировка</label>
        <select class="form-select" id="f_sort" name="sort">
            <?php foreach (SORTS as $value => [$label]): ?>
                <option value="<?= e($value) ?>" <?= $value === $sort ? 'selected' : '' ?>><?= e($label) ?></option>
            <?php endforeach; ?>
        </select>
    </div>
    <div class="col-12 col-sm-2 d-grid">
        <button class="btn btn-outline-primary" type="submit">Показать</button>
    </div>
</form>

<p class="text-muted">Найдено заявок: <?= $total ?>. Страница <?= $page ?> из <?= $pages ?>.</p>

<?php if (!$requests): ?>
    <div class="alert alert-secondary">Заявок с выбранными условиями нет.</div>
<?php else: ?>
<div class="table-responsive">
<table class="table table-bordered align-middle">
    <thead class="table-light">
        <tr><th>№</th><th>Заказчик</th><th>Услуга</th><th>Дата и время</th>
            <th>Адрес</th><th>Оплата</th><th>Статус</th><th>Изменить</th></tr>
    </thead>
    <tbody>
    <?php foreach ($requests as $r): ?>
        <tr>
            <td><?= e($r['id']) ?><br><span class="small text-muted"><?= e(format_dt($r['created_at'])) ?></span></td>
            <td><?= e($r['fio']) ?><br><span class="small"><?= e($r['phone']) ?><br><?= e($r['email']) ?></span></td>
            <td><?= $r['custom_service'] !== null ? 'Иная: ' . e($r['custom_service']) : e($r['service_name']) ?></td>
            <td><?= e(format_dt($r['date_time'])) ?></td>
            <td><?= e($r['address']) ?></td>
            <td><?= e(PAYMENTS[$r['payment']] ?? $r['payment']) ?></td>
            <td>
                <?= status_badge($r['status']) ?>
                <?php if ($r['cancel_reason'] !== null): ?>
                    <div class="small text-danger mt-1"><?= e($r['cancel_reason']) ?></div>
                <?php endif; ?>
            </td>
            <td style="min-width: 220px">
                <form method="post" action="<?= e($selfUrl) ?>" class="d-grid gap-1">
                    <?= csrf_field() ?>
                    <input type="hidden" name="id" value="<?= e($r['id']) ?>">
                    <select name="status" class="form-select form-select-sm">
                        <?php foreach (STATUSES as $value => $label): ?>
                            <option value="<?= e($value) ?>" <?= $value === $r['status'] ? 'selected' : '' ?>><?= e($label) ?></option>
                        <?php endforeach; ?>
                    </select>
                    <input name="cancel_reason" class="form-control form-control-sm" maxlength="255"
                           placeholder="Причина отмены" value="<?= e($r['cancel_reason'] ?? '') ?>">
                    <button class="btn btn-sm btn-primary" type="submit">Сохранить</button>
                </form>
            </td>
        </tr>
    <?php endforeach; ?>
    </tbody>
</table>
</div>
<?php endif; ?>

<?php if ($pages > 1): ?>
<nav aria-label="Страницы">
    <ul class="pagination flex-wrap">
        <li class="page-item <?= $page <= 1 ? 'disabled' : '' ?>">
            <a class="page-link" href="<?= e(admin_url($query, ['page' => $page - 1])) ?>">&laquo;</a>
        </li>
        <?php for ($i = 1; $i <= $pages; $i++): ?>
            <li class="page-item <?= $i === $page ? 'active' : '' ?>">
                <a class="page-link" href="<?= e(admin_url($query, ['page' => $i])) ?>"><?= $i ?></a>
            </li>
        <?php endfor; ?>
        <li class="page-item <?= $page >= $pages ? 'disabled' : '' ?>">
            <a class="page-link" href="<?= e(admin_url($query, ['page' => $page + 1])) ?>">&raquo;</a>
        </li>
    </ul>
</nav>
<?php endif; ?>
<?php require __DIR__ . '/includes/footer.php'; ?>
```

Пояснения.

- `foreach (SORTS as $value => [$label])` — «распаковка»: из пары `['Сначала новые', 'r.created_at DESC']` берём только первый элемент.
- При смене фильтра в форме нет поля `page`, поэтому всегда открывается первая страница — это правильно, ведь у отфильтрованного списка может не быть 5-й страницы.
- `$page = min($page, $pages)` — если кто-то введёт `page=999`, покажем последнюю.
- В `action` формы смены статуса и в ссылках адрес выводится через `e()`: символ `&` в HTML-атрибуте правильно писать как `&amp;`.
- Важно: `$where` и `$orderBy` вклеиваются в SQL, но это **наш** текст, а не пользовательский. Данные пользователя идут только через метки.

**Проверка с большим количеством данных.** Чтобы увидеть пагинацию, нужно больше 10 заявок. Быстро размножить тестовые заявки можно запросом в phpMyAdmin (выполните 2–3 раза):

```sql
INSERT INTO requests (user_id, address, phone, date_time, service_id, custom_service, payment, status)
SELECT user_id, CONCAT(address, ' (копия)'), phone, date_time + INTERVAL 1 DAY,
       service_id, custom_service, payment, status
FROM requests;
```

**Типичные ошибки.**

- `SQLSTATE[42000]: Syntax error ... near ''10' OFFSET '0''` — `LIMIT` передан строкой; используйте `PDO::PARAM_INT`.
- Пагинация «теряет» фильтр — ссылки страниц собраны без `status`/`sort`.
- Количество страниц не совпадает с количеством строк — `COUNT(*)` выполняется без того же `WHERE`.
- `SQLSTATE[HY093]` — в `$params` метка с двоеточием, а в SQL без (или наоборот), либо метка есть в SQL, но не передана.
- `$_GET['sort']` вклеен в `ORDER BY` напрямую — на вид работает, на деле SQL-инъекция.

**Связь с экзаменом.** Фильтры, сортировка и пагинация могут входить в вариативную часть ТЗ или в задание по оптимизации. Даже если их нет в вашем варианте, приём «белый список для сортировки + подготовленный фильтр» — показатель грамотной работы с безопасностью, который эксперт видит в коде.

## Критерии оценки

| Аспект | 2 балла | 1 балл | 0 баллов |
|---|---|---|---|
| Фильтр по статусу | Работает, значение по белому списку, через метку | Работает, но без проверки значения | Нет |
| Сортировка | 3+ варианта через белый список | Есть, но вклеивается значение из GET | Нет |
| Пагинация | LIMIT/OFFSET с PARAM_INT, верное число страниц, границы проверены | Работает, но ломается на крайних значениях | Нет |
| Сохранение параметров | Фильтр и сортировка сохраняются в ссылках и после смены статуса | Только в ссылках | Теряются |
| Устойчивость | Все «атаки» из п. 6 не ломают страницу | 1–2 ошибки | Ошибки SQL на экране |
