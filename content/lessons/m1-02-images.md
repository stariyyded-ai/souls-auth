Экранный диктор не видит картинку. Он читает её атрибут `alt`. Если `alt` нет, диктор прочитает имя файла — «ай-эм-джи-ноль-три-точка-пэ-эн-гэ».

## Три вида картинок

1. **Информативная** — несёт смысл. В `alt` опиши, что на ней важно: `alt="Карта: Изалит за огненным озером"`.
2. **Декоративная** — разделители, узоры. Ставь пустой `alt=""`, и диктор её пропустит.
3. **Картинка-кнопка или ссылка** — описывай действие, а не картинку: `aria-label="Добавить в бестиарий"`.

```html
<img src="boss.png" alt="Ложе Хаоса: огненное дерево">
<img src="divider.svg" alt="">
<button type="button" aria-label="Закрыть окно">
  <img src="close.svg" alt="">
</button>
```

## Ссылки «тут» и «подробнее»

Дикторы умеют показывать список всех ссылок страницы. Пять ссылок «тут» подряд ничего не говорят. Текст ссылки должен быть понятен без окружающего предложения: «Тактика боя с Ложем Хаоса».

:::quiz
? Какой alt у декоративного разделителя?
- [ ] alt="разделитель"
- [x] alt=""
- [ ] Атрибут не нужен вообще
> Пустой alt говорит диктору: «пропусти». Без атрибута он прочитает имя файла.

? Кнопка — это только иконка крестика. Как её назвать?
- [ ] title="x"
- [x] aria-label="Закрыть окно"
- [ ] alt="крестик" у кнопки
> aria-label даёт кнопке имя, которое прочитает диктор.

? Какой текст ссылки лучше?
- [ ] Подробнее тут
- [ ] Нажмите здесь
- [x] Тактика боя с Ложем Хаоса
> Ссылка должна быть понятна в списке ссылок без контекста.
:::
