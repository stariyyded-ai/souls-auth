Grid строит сетку сразу в двух направлениях: колонки и строки. Это лучший инструмент для галерей, карточек и раскладки страницы.

## Колонки

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}
```

`1fr` — одна доля свободного места. `repeat(3, 1fr)` — три равные колонки. Запятая обязательна: `repeat(3 1fr)` браузер не поймёт.

## Элемент на несколько колонок

```css
.work.big { grid-column: span 2; }
```

Между `span` и числом нужен пробел.

## Сетка без медиазапросов

```css
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
```

Колонок будет столько, сколько влезет карточек шириной от 200px. На телефоне — одна, на большом экране — четыре.

## Картинки в сетке

Картинка шире своей ячейки распирает колонку. Лечится одной строкой: `img { max-width: 100%; height: auto; }`.

:::quiz
? Что значит `repeat(3, 1fr)`?
- [x] Три колонки равной ширины
- [ ] Одна колонка, повторённая три раза по 1px
- [ ] Три строки
> fr — доля свободного места.

? Как растянуть карточку на две колонки?
- [ ] grid-column: span2
- [x] grid-column: span 2
- [ ] grid-width: 2
> Нужен пробел между span и числом.

? Чем хорош `repeat(auto-fit, minmax(200px, 1fr))`?
- [ ] Делает ровно 200 колонок
- [x] Сам меняет число колонок под ширину экрана
- [ ] Работает только в Firefox
> Сетка подстраивается без медиазапросов.
:::
