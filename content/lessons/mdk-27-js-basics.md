## Что такое JavaScript

**JavaScript** (JS) — язык программирования, который понимает браузер. HTML и CSS только *описывают* страницу. JavaScript *выполняет действия*: считает, сравнивает, принимает решения, реагирует на нажатия.

Где вы встречали JavaScript, даже не зная об этом:

- меню-«бургер» на телефоне открывается и закрывается;
- форма пишет «Введите почту» до отправки;
- корзина магазина сама пересчитывает сумму;
- кнопка «Показать ещё» подгружает новые карточки.

Программа на JavaScript называется **скриптом** (от англ. script — сценарий). Это список команд, которые браузер выполняет по порядку, сверху вниз, как рецепт.

> JavaScript и Java — разные языки. Похожи только названия.

На демоэкзамене от вас ждут «немного JavaScript»: открыть меню, проверить форму, переключить вкладку. Сегодня учим основы языка, на следующем занятии — как с его помощью менять страницу.

## Где писать JavaScript

### Тег script в конце body

Самый простой способ — тег `<script>` прямо в HTML:

```html
<h1>Привет!</h1>
<p>Откройте консоль браузера: клавиша F12, вкладка Console.</p>
<script>
  console.log('Скрипт работает!');
</script>
```

Что увидите: на странице — заголовок и абзац, а в консоли — строку «Скрипт работает!».

Тег `script` ставят **в самом конце `body`**, перед `</body>`. Браузер читает страницу сверху вниз. Если скрипт стоит выше заголовка и пытается с ним что-то сделать, заголовка ещё нет — будет ошибка.

### Отдельный файл script.js

На настоящем сайте скрипт, как и стили, выносят в отдельный файл. Рядом с `style.css` появляется папка `js` и файл `script.js`:

```html
<!-- в конце body -->
<script src="js/script.js"></script>
```

Внутри `script.js` — только код JavaScript, без тегов. Один файл подключается на всех страницах, его удобно править. В заданиях курса для этого есть вкладка **script.js**: всё, что вы там пишете, подключится в конец страницы.

## Консоль и console.log

**Консоль** — окно инструментов разработчика, куда скрипт может писать сообщения и куда браузер пишет ошибки. Открывается клавишей **F12** (или Ctrl+Shift+I), вкладка **Console**.

Команда `console.log(…)` выводит в консоль то, что стоит в скобках:

```js
console.log('Привет, группа!');
console.log(2 + 3);
console.log('Сумма:', 2 + 3);
```

В консоли появится:

```
Привет, группа!
5
Сумма: 5
```

`console.log` — главный инструмент новичка. Не понимаете, что происходит в коде, — выведите значение в консоль и посмотрите.

Каждая команда заканчивается **точкой с запятой** `;`. Иногда JavaScript прощает её отсутствие, но лучше ставить всегда: так код читается проще.

**Комментарии** в JS пишутся так:

```js
// однострочный комментарий
/* комментарий
   на несколько строк */
```

## Переменные: let и const

**Переменная** — именованная «коробка» для значения. Положили число или текст, дали коробке имя — дальше пользуемся именем.

```js
let count = 2;
const price = 150;
console.log(price * count);   // 300
```

- `let` — переменная, значение которой **можно менять**.
- `const` (от constant — постоянная) — значение **нельзя менять** после создания.

```js
let visitors = 10;
visitors = 11;           // можно: let

const cafeName = 'Зерно';
cafeName = 'Бобы';       // ошибка: const нельзя перезаписать
```

Что увидите во втором случае: в консоли красная ошибка `TypeError: Assignment to constant variable.`

Как выбирать: пишите `const` по умолчанию, а `let` — только если значение действительно будет меняться (счётчик, сумма в цикле).

Знак `=` в JavaScript — не «равно», а **присваивание**: «положи значение справа в коробку слева». Запись `count = count + 1` значит: «возьми старое значение, прибавь 1, положи обратно».

### Как называть переменные

- Латиницей, понятно по смыслу: `price`, `userName`, а не `a`, `x1`, `cena`.
- Если слов несколько, следующие начинаются с заглавной: `totalPrice`, `isOpen`. Такой стиль называют **camelCase** («верблюжий»).
- Нельзя начинать с цифры, нельзя пробелы и дефисы: `2price`, `total price`, `total-price` — ошибки.
- Регистр важен: `price` и `Price` — разные переменные.

Частая ошибка: использовать переменную до того, как её создали, или с опечаткой в имени. В консоли будет `ReferenceError: pirce is not defined` — «переменная pirce не найдена».

## Типы данных

У каждого значения есть **тип**. Пока нам нужны три:

| Тип | Пример | Что это |
|---|---|---|
| **Число** (number) | `150`, `3.5`, `-2` | Количество, цена, баллы. Дробная часть — через точку |
| **Строка** (string) | `'Зерно'`, `"кофе"` | Любой текст в кавычках |
| **Логический** (boolean) | `true`, `false` | «Да» или «нет»: открыто ли меню, заполнено ли поле |

Узнать тип помогает `typeof`:

```js
console.log(typeof 150);       // number
console.log(typeof '150');     // string
console.log(typeof true);      // boolean
```

Обратите внимание: `150` и `'150'` — **разные** вещи. Первое — число, с ним можно считать. Второе — текст из трёх символов.

Строки пишут в одинарных `'…'` или двойных `"…"` кавычках. Главное, чтобы открывающая и закрывающая были одинаковыми. Частая ошибка — забыть закрыть кавычку: `'Привет)`. Браузер ответит `SyntaxError: Invalid or unexpected token`.

## Операторы

### Арифметика

```js
console.log(10 + 3);   // 13 — сложение
console.log(10 - 3);   // 7  — вычитание
console.log(10 * 3);   // 30 — умножение
console.log(10 / 4);   // 2.5 — деление
console.log(10 % 3);   // 1  — остаток от деления
```

Остаток `%` удобен, чтобы узнать, чётное ли число: у чётного `n % 2` равно 0.

Порядок действий как в математике: сначала `*` и `/`, потом `+` и `-`. Скобки меняют порядок: `(150 + 60) * 2` — это 420, а `150 + 60 * 2` — 270.

### Плюс для строк

Если хотя бы одно значение — строка, `+` **склеивает** их:

```js
const name = 'Анна';
console.log('Привет, ' + name + '!');   // Привет, Анна!
console.log('2' + 3);                   // 23 — склеилось, а не сложилось!
```

Это самая частая ловушка JavaScript. Число, которое пришло из поля формы, всегда строка. Чтобы превратить строку в число, есть `Number('25')` — получится `25`.

Есть и более удобный способ собрать строку — **шаблонная строка** в обратных кавычках (клавиша Ё). Внутри `${…}` подставляется значение:

```js
const total = 420;
console.log(`Итого: ${total} руб.`);   // Итого: 420 руб.
```

### Сравнение

Сравнение даёт `true` или `false`:

| Оператор | Значит | Пример | Результат |
|---|---|---|---|
| `===` | равно | `5 === 5` | `true` |
| `!==` | не равно | `5 !== 3` | `true` |
| `>`, `<` | больше, меньше | `18 > 16` | `true` |
| `>=`, `<=` | больше или равно, меньше или равно | `60 >= 60` | `true` |

Сравниваем всегда тремя знаками `===`. Есть и `==`, но он сначала пытается привести типы, и `'5' == 5` даёт `true`. Это источник странных ошибок, поэтому `==` не используем.

Частая ошибка: написать в условии одно `=` вместо `===`. Одно `=` — это присваивание, оно не сравнивает, а **меняет** переменную.

### Логические операторы

- `&&` — «и»: истинно, если истинны **обе** части.
- `||` — «или»: истинно, если истинна **хотя бы одна**.
- `!` — «не»: переворачивает `true` в `false` и наоборот.

```js
const age = 17;
const hasTicket = true;
console.log(age >= 14 && hasTicket);   // true: и возраст подходит, и билет есть
console.log(!hasTicket);               // false
```

## Условия: if и else

Программа часто должна выбирать: если пароль верный — пустить, иначе — показать ошибку. Для этого есть **условие** `if`:

```js
const temperature = -5;

if (temperature < 0) {
  console.log('Наденьте шапку');
} else {
  console.log('Можно без шапки');
}
```

Что увидите в консоли: «Наденьте шапку». В круглых скобках — вопрос, ответ на который `true` или `false`. В фигурных — что делать.

Если вариантов больше двух, добавляем `else if`. Проверки идут сверху вниз, срабатывает **первая** подходящая:

```js
const hour = 14;

if (hour < 8) {
  console.log('Кофейня ещё закрыта');
} else if (hour < 12) {
  console.log('Завтраки');
} else if (hour < 16) {
  console.log('Обеды');
} else {
  console.log('Вечернее меню');
}
```

Что увидите: «Обеды». Условие `hour < 8` ложно, `hour < 12` ложно, `hour < 16` истинно — дальше браузер уже не смотрит.

> **Попробуйте сами.** Соберите пример выше в HTML-страницу внутри `<script>` и меняйте `hour`: 7, 9, 15, 20. Каждый раз перезагружайте страницу и смотрите в консоль.

## Функции

Представьте, что один и тот же расчёт нужен в пяти местах: стоимость заказа, цена со скидкой. Копировать код пять раз плохо: найдёте ошибку — придётся чинить пять раз. Поэтому код упаковывают в **функцию** — именованный кусок кода, который можно вызывать сколько угодно раз.

```js
function greet(name) {
  console.log('Привет, ' + name + '!');
}

greet('Анна');    // Привет, Анна!
greet('Олег');    // Привет, Олег!
```

Разберём:

- `function` — слово, которое создаёт функцию;
- `greet` — её имя (тоже camelCase, обычно глагол: что функция делает);
- `name` в скобках — **параметр**: «пустая коробка», в которую при вызове положат значение;
- в фигурных скобках — **тело** функции, код, который выполнится;
- `greet('Анна')` — **вызов**: запускаем функцию, `'Анна'` попадает в `name`.

Частая ошибка: объявить функцию и забыть её вызвать. Код внутри не выполнится, пока вы не напишете имя со скобками.

### return — вернуть результат

Функция может не только печатать, но и **возвращать** результат. Его можно сохранить в переменную или использовать дальше:

```js
function priceWithDiscount(price, percent) {
  return price - price * percent / 100;
}

const coffee = priceWithDiscount(150, 10);
console.log(coffee);                         // 135
console.log(priceWithDiscount(200, 50));     // 100
```

Параметров может быть несколько, они пишутся через запятую. Как только выполнилась строка с `return`, функция заканчивает работу.

Функции и условия часто работают вместе:

```js
function ticketPrice(age) {
  if (age < 7) {
    return 0;
  }
  if (age < 18) {
    return 150;
  }
  return 300;
}

console.log(ticketPrice(5));    // 0
console.log(ticketPrice(16));   // 150
console.log(ticketPrice(30));   // 300
```

## Массивы и цикл for…of

**Массив** — список значений в квадратных скобках через запятую:

```js
const days = ['пн', 'вт', 'ср', 'чт', 'пт'];
const scores = [95, 78, 61];

console.log(days[0]);         // пн — нумерация с нуля!
console.log(scores.length);   // 3 — сколько элементов
```

Номер элемента называют **индексом**, и он начинается с **нуля**: первый элемент — `days[0]`, второй — `days[1]`.

Чтобы сделать что-то с каждым элементом, используют **цикл** `for…of` — «для каждого из»:

```js
const scores = [95, 78, 61];
let sum = 0;

for (const score of scores) {
  console.log('Результат: ' + score);
  sum = sum + score;
}

console.log('Сумма: ' + sum);   // Сумма: 234
```

Что происходит: цикл берёт по очереди каждый элемент массива, кладёт его в переменную `score` и выполняет код в фигурных скобках. Три элемента — три повтора. Переменную `sum` объявили через `let`, потому что она меняется.

Средний балл — сумма, делённая на количество: `sum / scores.length`.

## Ошибки в консоли

Ошибки — нормальная часть работы программиста. Важно уметь их **читать**. Когда что-то не работает, первым делом откройте консоль: там будет красное сообщение с именем ошибки и номером строки.

| Ошибка | Что значит | Типичная причина |
|---|---|---|
| `SyntaxError` | Браузер не понял запись | Опечатка в слове (`cosnt`), не закрыта кавычка или скобка |
| `ReferenceError: x is not defined` | Нет такой переменной | Опечатка в имени, не тот регистр, переменную не объявили |
| `TypeError: … is not a function` | Пытаемся вызвать то, что не функция | `Console.log` с заглавной, опечатка в имени функции |
| `TypeError: Assignment to constant variable` | Меняем `const` | Нужен `let` |

Пример:

```html
<p>Откройте консоль (F12) и прочитайте ошибку.</p>
<script>
  const price = 150;
  console.log(pirce);
</script>
```

Что увидите: `Uncaught ReferenceError: pirce is not defined` и справа ссылку на строку. Нажмите на ссылку — браузер покажет строку с ошибкой.

Важно: **SyntaxError** ломает весь скрипт целиком, не выполнится ни одна строка. Остальные ошибки останавливают скрипт на той строке, где случились, — всё, что выше, успеет выполниться.

Как искать ошибку:

1. Откройте консоль, прочитайте первую красную строку.
2. Нажмите на номер строки справа.
3. Посмотрите на эту строку и на строку выше: часто ошибка в незакрытой скобке ещё раньше.
4. Исправьте **одну** ошибку, сохраните, обновите страницу. Повторяйте, пока консоль не станет чистой.

Бывают и ошибки похитрее — **логические**. Консоль молчит, красных строк нет, но результат неверный: вместо 27 получилось «252», вместо имени группы напечаталось слово «group». Браузер не знает, что вы *хотели*, поэтому подсказать не может. Такие ошибки ищут так: выводят промежуточные значения через `console.log` и сравнивают с тем, что должно быть.

```js
let students = '25';
console.log(students + 2, typeof students);   // 252 string — вот и причина
```

> **Попробуйте сами.** В примере выше исправьте `pirce` на `price` и обновите страницу. Ошибка исчезла, в консоли — `150`. Теперь замените `const` на `cosnt` и посмотрите, какая ошибка появится.

## Главное за занятие

- JavaScript выполняет действия на странице; код пишут в `<script>` в конце `body` или в файле `script.js`.
- `console.log(…)` выводит значения в консоль (F12 → Console) — главный способ понять, что делает код.
- `const` — постоянное значение, `let` — меняющееся; `=` значит «присвоить».
- Типы: число, строка, логический. `'2' + 3` даёт `'23'`, потому что `+` склеивает строки.
- Сравниваем через `===`, условия пишем `if / else if / else`.
- Функция — именованный кусок кода с параметрами; `return` возвращает результат.
- Ошибки читаем в консоли: `SyntaxError` — опечатка в записи, `ReferenceError` — нет такой переменной.

## Словарик

- **Скрипт** — программа на JavaScript.
- **Консоль** — окно инструментов разработчика для сообщений и ошибок.
- **Переменная** — именованное хранилище значения.
- **Тип данных** — вид значения: число, строка, логический.
- **Строка** — текст в кавычках.
- **Оператор** — знак действия: `+`, `===`, `&&`.
- **Условие** — конструкция `if`, которая выбирает, какой код выполнить.
- **Функция** — именованный кусок кода, который можно вызывать много раз.
- **Параметр** — значение, которое функция получает при вызове.
- **Массив** — упорядоченный список значений.
- **Цикл** — повторение кода для каждого элемента или пока выполняется условие.
