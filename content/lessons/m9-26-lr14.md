## Лекция

**Зачем фреймворк, если мы уже умеем сами.** За прошлые работы вы написали свой `style.css`: переменные, кнопки, поля, карточки, бейджи, адаптивную таблицу. Это заняло несколько пар. На экзамене на всё задание даётся ограниченное время, и писать каждую кнопку с нуля — роскошь. **Bootstrap** — это готовая библиотека CSS-классов и небольшого JavaScript: сетка, кнопки, формы, карточки, таблицы, меню, модальные окна. Вы пишете в HTML нужные классы — и элемент уже выглядит прилично и работает на телефоне. Сегодня разбираем Bootstrap 5.3 и учимся «перекрашивать» его под корпоративный стиль, чтобы портал не выглядел как тысячи других сайтов на Bootstrap.

**Подключение.** Два файла: CSS в `<head>` и JS-бандл (включает библиотеку Popper для выпадающих меню) перед `</body>`:

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Вход — ЧистоДом</title>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">
  <link rel="stylesheet" href="css/style.css">   <!-- ваш файл ПОСЛЕ Bootstrap -->
</head>
<body>
  ...
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
```

Порядок важен: ваш `style.css` подключается **после** Bootstrap, чтобы ваши правила могли переопределить его стили. На экзамене интернет может быть недоступен, поэтому заранее скачайте архив Bootstrap с официального сайта getbootstrap.com и положите файлы `bootstrap.min.css` и `bootstrap.bundle.min.js` в папки `css/` и `js/` проекта — так проект откроется и без сети.

**Сетка: container → row → col.** Сетка Bootstrap делит строку на 12 колонок и построена на Flexbox. Три уровня вложенности обязательны:

```html
<div class="container">
  <div class="row g-3">
    <div class="col-12 col-md-6 col-xl-4">Заявка 1</div>
    <div class="col-12 col-md-6 col-xl-4">Заявка 2</div>
    <div class="col-12 col-md-6 col-xl-4">Заявка 3</div>
  </div>
</div>
```

- `container` — центрирует содержимое и даёт боковые поля; на каждом брейкпоинте у него своя максимальная ширина. `container-fluid` — всегда на всю ширину.
- `row` — строка; `g-3` задаёт промежуток (gutter) между колонками.
- `col-12 col-md-6 col-xl-4` читается так: «на телефоне 12 из 12 колонок (вся ширина), от md — 6 из 12 (половина), от xl — 4 из 12 (треть)». Это и есть mobile-first, который вы писали вручную на ПР12, только короче.

Брейкпоинты Bootstrap 5: `sm` ≥576px, `md` ≥768px, `lg` ≥992px, `xl` ≥1200px, `xxl` ≥1400px. Класс без приставки (`col-12`) действует на всех ширинах, пока его не перебьёт класс с брейкпоинтом.

**Утилиты — маленькие классы на одно свойство.** Вместо того чтобы писать CSS ради одного отступа, в Bootstrap есть утилиты:

| Класс | Что делает |
|---|---|
| `mt-3`, `mb-4`, `py-2`, `px-3` | margin/padding: t-верх, b-низ, y-по вертикали, x-по горизонтали; 1–5 — шаг шкалы (3 = 1rem) |
| `d-flex`, `d-grid`, `d-none`, `d-md-block` | display, в том числе на брейкпоинте |
| `justify-content-between`, `align-items-center`, `gap-2` | Flexbox-выравнивание |
| `w-100` | ширина 100% |
| `text-center`, `fw-bold`, `small`, `text-body-secondary` | текст |
| `rounded-3`, `shadow-sm` | скругление, тень |

Не злоупотребляйте: если на элементе десять утилит, лучше сделать свой класс в `style.css`.

**Формы в Bootstrap.** Классы для полей: `form-label` для подписи, `form-control` для `input` и `textarea`, `form-select` для `select`, `form-check` + `form-check-input` + `form-check-label` для radio и checkbox. Ошибка показывается классом `is-invalid` у поля и блоком `invalid-feedback` после него:

```html
<form class="d-grid gap-3" action="#" method="post">
  <div>
    <label class="form-label" for="login">Логин</label>
    <input class="form-control is-invalid" type="text" id="login" name="login"
           required minlength="6" aria-describedby="login-error">
    <div class="invalid-feedback" id="login-error">Логин уже занят</div>
  </div>

  <div>
    <label class="form-label" for="service">Вид услуги</label>
    <select class="form-select" id="service" name="service_id" required>
      <option value="">— Выберите —</option>
      <option value="1">Общий клининг</option>
    </select>
  </div>

  <fieldset>
    <legend class="form-label">Тип оплаты</legend>
    <div class="form-check">
      <input class="form-check-input" type="radio" name="payment" id="cash" value="cash" required>
      <label class="form-check-label" for="cash">Наличными</label>
    </div>
    <div class="form-check">
      <input class="form-check-input" type="radio" name="payment" id="card" value="card">
      <label class="form-check-label" for="card">Банковской картой</label>
    </div>
  </fieldset>

  <button class="btn btn-primary btn-lg w-100" type="submit">Отправить заявку</button>
</form>
```

Блок `invalid-feedback` виден только тогда, когда у предыдущего поля есть `is-invalid` (или у формы класс `was-validated` и поле не прошло проверку). Это удобно для PHP: сервер просто добавит `is-invalid` и текст ошибки.

**Компоненты для портала.**

- **Кнопки:** `btn btn-primary`, `btn btn-outline-secondary`, `btn btn-danger`; размер `btn-lg`, `btn-sm`.
- **Карточка:** `card` → `card-body` → `card-title`, `card-text`.
- **Бейдж:** `badge text-bg-success`, `text-bg-warning`, `text-bg-danger`, `text-bg-primary` — классы `text-bg-*` сами подбирают контрастный цвет текста.
- **Таблица:** `table table-hover align-middle`, обёртка `table-responsive` даёт прокрутку на узких экранах.
- **Сообщение:** `alert alert-danger`, `alert alert-success`.
- **Меню:** `navbar navbar-expand-md` — на телефоне сворачивается в кнопку-«гамбургер», для работы нужен JS-бандл.

Карточка заявки на Bootstrap:

```html
<article class="card shadow-sm">
  <div class="card-body">
    <div class="d-flex justify-content-between align-items-start gap-2 mb-2">
      <h2 class="card-title h5 mb-0">Генеральная уборка</h2>
      <span class="badge text-bg-warning">В работе</span>
    </div>
    <p class="card-text small text-body-secondary mb-0">12.11.2026, 10:00 · ул. Ленина, 5</p>
  </div>
</article>
```

Шапка с меню:

```html
<nav class="navbar navbar-expand-md bg-primary" data-bs-theme="dark">
  <div class="container">
    <a class="navbar-brand" href="requests.html">ЧистоДом</a>
    <button class="navbar-toggler" type="button" data-bs-toggle="collapse"
            data-bs-target="#mainNav" aria-controls="mainNav"
            aria-expanded="false" aria-label="Открыть меню">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="mainNav">
      <ul class="navbar-nav ms-auto">
        <li class="nav-item"><a class="nav-link" href="new-request.html">Новая заявка</a></li>
        <li class="nav-item"><a class="nav-link" href="index.html">Выход</a></li>
      </ul>
    </div>
  </div>
</nav>
```

**Перекрашиваем Bootstrap в фирменный стиль.** Bootstrap 5.3 построен на CSS-переменных с приставкой `--bs-`. Глобальные — в `:root`, у компонентов — свои. Важная тонкость: если поменять только `--bs-primary`, кнопка `btn-primary` **не** перекрасится — у неё собственные переменные. Поэтому переопределяем и то, и другое:

```css
:root {
  --bs-primary: #0f766e;
  --bs-primary-rgb: 15, 118, 110;        /* для bg-primary, text-primary */
  --bs-body-font-family: "Inter", system-ui, sans-serif;
  --bs-border-radius: 12px;
  --bs-link-color-rgb: 15, 118, 110;
}

.btn-primary {
  --bs-btn-bg: #0f766e;
  --bs-btn-border-color: #0f766e;
  --bs-btn-hover-bg: #115e59;
  --bs-btn-hover-border-color: #115e59;
  --bs-btn-active-bg: #134e4a;
  --bs-btn-active-border-color: #134e4a;
}
```

Цвет рамки фокуса у полей (`form-control:focus`) тоже стоит подогнать под фирменный — посмотрите в DevTools, какие свойства у него меняются, и переопределите их в `style.css`. Полная настройка делается через исходники на Sass, но для экзамена хватает переменных.

**Bootstrap или свой CSS?** Не обязательно выбирать одно. Разумная стратегия: сетка, формы, таблицы, меню и модальные окна — из Bootstrap; фирменные цвета, шрифт, бейджи статусов и детали из макета — в своём `style.css`. Главное — результат должен совпадать с **вашим макетом**, а не со стандартным видом Bootstrap.

**Типичные ошибки:**

1. `col-*` без `row` или `row` без `container` — едут отступы, появляется прокрутка вбок.
2. Свой CSS подключён до Bootstrap — ваши стили «не работают».
3. Подключён только `bootstrap.min.css` — меню-гамбургер не открывается (нет JS).
4. Изменили `--bs-primary` и удивляетесь, что кнопка осталась синей.
5. Сайт выглядит как стандартный шаблон: синие кнопки, шрифт по умолчанию — эксперт не увидит фирменного стиля.
6. На экзамене нет интернета, а Bootstrap подключён только с CDN.

## Критерии оценки

| Аспект | 2 балла | 1 балл | 0 баллов |
|---|---|---|---|
| Подключение | Bootstrap CSS и JS подключены локально, порядок файлов верный | подключение только с CDN или без JS | не подключён |
| Сетка | container → row → col, колонки меняются на md и xl, нет прокрутки вбок | сетка с ошибками вложенности | сетка не используется |
| Компоненты | navbar с гамбургером, формы, карточки, таблица, alert/invalid-feedback | использованы не все | компонентов нет |
| Фирменный стиль | цвета, шрифт, радиусы из стайл-гайда через переменные, сайт не похож на шаблон | частично перекрашен | стандартный вид Bootstrap |
| Соответствие макету | 4 страницы узнаваемо совпадают с макетом | расхождения на 1–2 страницах | не похоже |
| Обоснование | таблица выбора Bootstrap/свой CSS заполнена осмысленно | формально | нет |

## Если не успел / для сильных

**Минимум:** Bootstrap подключён, страница `requests.html` на сетке `container/row/col` с карточками и перекрашенной кнопкой `btn-primary`.
**Усложнение:** сделайте на `admin.html` модальное окно Bootstrap «Отмена заявки» с полем причины (компонент Modal, атрибуты `data-bs-toggle="modal"` и `data-bs-target`) — в ЛР36 вы подключите его к серверу через fetch.

:::quiz
? Что означает набор классов `col-12 col-md-6 col-xl-4`?
- [ ] Блок шириной 12px, 6px и 4px на разных экранах
- [ ] Блок занимает 12, потом 6, потом 4 строки
- [x] На телефоне вся ширина, от md — половина, от xl — треть
- [ ] На телефоне треть, от md — половина, от xl — вся ширина
> Сетка Bootstrap делится на 12 колонок: 12 — вся строка, 6 — половина, 4 — треть. Класс с префиксом срабатывает от этой ширины и выше.

? Что перестанет работать, если не подключить `bootstrap.bundle.min.js`?
- [x] Гамбургер-меню и другие интерактивные компоненты
- [ ] Сетка `row` и `col` развалится в одну колонку
- [ ] Все цвета кнопок станут серыми
- [ ] Классы отступов вроде `mt-3` и `p-2`
> Сетка, цвета и отступы — это CSS. JS-файл нужен компонентам, которые реагируют на клики: раскрывающееся меню, модальные окна, выпадающие списки.

? Вы изменили `--bs-primary`, а кнопка `btn-primary` осталась синей. Почему?
- [ ] Свой `style.css` подключён раньше Bootstrap — это единственная причина
- [ ] Bootstrap вообще нельзя перекрашивать переменными
- [ ] Переменные работают только внутри тега `<style>`
- [x] У кнопки свои переменные, их тоже надо переопределить
> У `.btn-primary` собственные переменные (`--bs-btn-bg`, `--bs-btn-border-color` и др.), поэтому кроме `--bs-primary` переопределяют и их.

? Почему на экзамен лучше брать Bootstrap локальными файлами, а не ссылкой на CDN?
- [ ] Локальный Bootstrap новее, чем на CDN
- [ ] С CDN нельзя подключить JS-часть Bootstrap
- [ ] Ссылка на CDN ломает собственный `style.css`
- [x] На экзамене может не быть интернета, и стили не загрузятся
> Без интернета ссылка на CDN не откроется, и страница останется без оформления. Локальные файлы в папке проекта работают всегда.
