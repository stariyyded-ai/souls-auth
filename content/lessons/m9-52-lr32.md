> **Работа 52 из 65 · лабораторная работа ЛР32 · 2 часа · модуль 5 «Серверная часть на PHP».** Прочитайте лекцию, выполните задание по шагам и сдайте работу внизу страницы: преподаватель оценит её по критериям.

## Лекция

Это генеральная репетиция модуля 1 экзамена. Вы получаете от преподавателя **новый вариант** (не тот, что делали весь модуль) и за 90 минут с нуля собираете портал: база, регистрация, вход, заявки, история, админ-панель. Пользоваться можно своими конспектами и документацией php.net — как правило, это соответствует условиям экзамена, но точный регламент на ДЭ сообщают организаторы, уточняйте его заранее.

**Главная мысль: работает лучше, чем красиво.** Баллы ставят за функции и безопасность. Портал, где все пять функций работают на голом Bootstrap, получит больше, чем идеально свёрстанная регистрация без входа. Красоту доводите в последние минуты или в задании по дизайну.

**План на 90 минут.**

| Время | Что делаем | Результат-контрольная точка |
|---|---|---|
| 0–5 | Читаем ТЗ, выписываем поля, роли, статусы, «иное» | Список полей на листе |
| 5–15 | База: таблицы, внешние ключи, справочник, администратор | В phpMyAdmin 3 таблицы и `adminka` |
| 15–25 | Каркас: `config.php`, `db.php`, `auth.php`, `header/footer`, `index.php` | Любая страница открывается без ошибок |
| 25–40 | Регистрация с валидацией | Новый пользователь в базе с хешем |
| 40–50 | Вход, выход, охранники ролей | Вход пользователем и `adminka` |
| 50–62 | Новая заявка | Заявка в базе со статусом `new` |
| 62–70 | Мои заявки | Пользователь видит только свои заявки |
| 70–82 | Админ-панель, смена статуса, причина отмены | Сценарий «отменить с причиной» работает |
| 82–90 | Финальная проверка по чек-листу, дамп БД, коммит | Всё сдано |

Если отстаёте от плана больше чем на 10 минут — **упрощайте**: меньше вёрстки, `field()` вместо ручного HTML, никаких «улучшений». Не застревайте на одной ошибке дольше 5 минут: временно закомментируйте и идите дальше, вернётесь в конце.

**Порядок важен.** Делаем строго «снизу вверх»: база → каркас → регистрация → вход → заявка → история → админка. Каждый следующий шаг опирается на предыдущий: без регистрации не проверить вход, без входа — заявку, без заявки — админку.

**Шпаргалка: итоговые общие файлы.** Их стоит уметь написать по памяти — это 10 минут экзамена. Ниже — финальные версии после всех работ модуля.

`config.php`:

```php
<?php
const DB_HOST  = 'localhost';
const DB_NAME  = 'portal';
const DB_USER  = 'root';
const DB_PASS  = '';
const APP_NAME = 'Портал заявок';
const DEBUG    = true;

error_reporting(E_ALL);
ini_set('display_errors', DEBUG ? '1' : '0');
ini_set('log_errors', '1');
ini_set('error_log', __DIR__ . '/logs/php-errors.log');
date_default_timezone_set('Europe/Moscow');

if (session_status() === PHP_SESSION_NONE) {
    session_set_cookie_params(['httponly' => true, 'samesite' => 'Lax']);
    session_start();
}

const STATUSES = ['new' => 'Новая', 'in_work' => 'В работе', 'done' => 'Выполнена', 'cancelled' => 'Отменена'];
const PAYMENTS = ['cash' => 'Наличные', 'card' => 'Банковская карта'];

function e(mixed $value): string
{
    return htmlspecialchars((string)$value, ENT_QUOTES, 'UTF-8');
}

function redirect(string $url): never
{
    header('Location: ' . $url);
    exit;
}

function post(string $key): string
{
    $value = $_POST[$key] ?? '';
    return is_string($value) ? trim($value) : '';
}

function valid_phone(string $phone): bool
{
    return (bool)preg_match('/^\+7\(\d{3}\)-\d{3}-\d{2}-\d{2}$/', $phone);
}

function valid_fio(string $fio): bool
{
    return (bool)preg_match('/^[А-ЯЁа-яё\s-]+$/u', $fio);
}

function set_flash(string $type, string $text): void
{
    $_SESSION['flash'] = ['type' => $type, 'text' => $text];
}

function get_flash(): ?array
{
    $flash = $_SESSION['flash'] ?? null;
    unset($_SESSION['flash']);
    return $flash;
}

function format_dt(?string $value): string
{
    return $value ? date('d.m.Y H:i', strtotime($value)) : '';
}

function status_badge(string $status): string
{
    $colors = ['new' => 'primary', 'in_work' => 'warning', 'done' => 'success', 'cancelled' => 'danger'];
    return '<span class="badge text-bg-' . ($colors[$status] ?? 'secondary') . '">'
        . e(STATUSES[$status] ?? $status) . '</span>';
}
```

`includes/auth.php`:

```php
<?php
require_once __DIR__ . '/../db.php';

function current_user(): ?array
{
    return $_SESSION['user'] ?? null;
}

function is_admin(): bool
{
    return (current_user()['role'] ?? '') === 'admin';
}

function require_login(): void
{
    if (current_user() === null) {
        redirect('login.php');
    }
}

function require_user(): void
{
    require_login();
    if (is_admin()) {
        redirect('admin.php');
    }
}

function require_admin(): void
{
    require_login();
    if (!is_admin()) {
        http_response_code(403);
        $title = 'Доступ запрещён';
        require __DIR__ . '/header.php';
        echo '<div class="alert alert-danger">Доступ запрещён. Эта страница только для администратора.</div>';
        require __DIR__ . '/footer.php';
        exit;
    }
}

function csrf_token(): string
{
    if (empty($_SESSION['csrf'])) {
        $_SESSION['csrf'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf'];
}

function csrf_field(): string
{
    return '<input type="hidden" name="csrf" value="' . e(csrf_token()) . '">';
}

function check_csrf(): void
{
    $sent = $_POST['csrf'] ?? '';
    if (!is_string($sent) || !hash_equals(csrf_token(), $sent)) {
        http_response_code(400);
        exit('Форма устарела или отправлена с чужого сайта. Обновите страницу и попробуйте снова.');
    }
}
```

Страницы — по образцам ЛР24 (`register.php`), ЛР25 (`login.php`, `logout.php`), ЛР27 (`request_new.php`), ЛР28 (`requests.php`), ЛР29 (`admin.php`), с флеш-сообщениями из ПР20 вместо GET-параметров.

**Как экзаменатор будет проверять (сценарий самопроверки).** Пройдите его сами в последние 8 минут — по сути это чек-лист критериев:

1. Открыть сайт гостем — видна страница входа, меню гостя, ошибок PHP нет.
2. Регистрация: короткий логин, латинское ФИО, неверный телефон, неверный email — ошибки у полей. Занятый логин — ошибка. Верные данные — успех.
3. Вход неверным паролем — сообщение. Вход верным — свои страницы.
4. Новая заявка: пустая форма — ошибки; верная — появилась в «Моих заявках» со статусом «Новая». Проверить «иную услугу».
5. Открыть `admin.php` пользователем — запрет.
6. Выход, вход `adminka` / `password` — панель со всеми заявками и ФИО.
7. Сменить статус на «В работе»; отменить без причины — ошибка; с причиной — успех.
8. Войти пользователем — статус и причина видны.
9. phpMyAdmin: пароли — хеши; сделать экспорт БД в `.sql` и положить в папку проекта.

**Типичные потери баллов.**

- Админ не входит: пароль в базе открытым текстом.
- Проект не запускается у эксперта: нет дампа БД или в `config.php` другое имя базы.
- Проверки только в HTML (`required`, `pattern`), сервер принимает что угодно.
- Пользователь видит чужие заявки.
- Причина отмены не обязательна или не видна пользователю.
- На страницах торчат `Warning` и `Notice`.
- `var_dump` и отладочные файлы (`test.php`, `hash.php`) оставлены в проекте.

**Психология.** На экзамене что-то обязательно сломается. Это нормально. Прочитайте сообщение об ошибке (ПР20), найдите строку, проверьте строку выше. Если не нашли за 5 минут — переходите к следующей функции. Пять функций «на 80 %» почти всегда дают больше баллов, чем одна идеальная.

## Критерии оценки

| Аспект | 2 балла | 1 балл | 0 баллов |
|---|---|---|---|
| Регистрация по ТЗ | Все поля и правила валидации, уникальный логин, хеш пароля | Не работает одно правило | Регистрации нет или пароль открытым текстом |
| Вход и роли | Вход/выход, сообщение о неверных данных, `adminka`/`password` входит, страницы защищены | Нет одного элемента | Вход не работает |
| Создание заявки | Все поля ТЗ, услуги из справочника, иная услуга, оплата, серверная проверка | Нет одного поля или проверки | Заявка не создаётся |
| История заявок | Только свои заявки, русские статусы, причина отмены | Нет причины отмены | Видны чужие заявки или страницы нет |
