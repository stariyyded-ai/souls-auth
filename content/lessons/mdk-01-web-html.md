## Как учиться на этом курсе

Курс «Проектирование и разработка интерфейсов пользователя» (МДК.08.01) состоит из 55 занятий по 2 часа. Занятия бывают двух видов:

- **Лекция** — вы читаете урок, разбираете примеры, проходите квиз и решаете 2–3 задания на закрепление.
- **Практическая работа** — вы по шагам делаете готовый результат: страницу, форму, макет. В уроке есть ход работы и критерии оценки.

Каждое занятие устроено одинаково:

1. **Прочитайте урок сверху вниз.** Примеры кода не пропускайте: под каждым есть кнопка «Попробовать», она открывает код в песочнице, где его можно менять и сразу видеть результат.
2. **Пройдите квиз.** За каждый новый верный ответ дают опыт и души. Ошиблись — прочитайте пояснение и попробуйте ещё раз.
3. **Решите задания.** Кнопка задания открывает редактор: слева код, справа предпросмотр, сверху условие и чек-лист. Нажмите «Проверить», и сайт сам проверит каждое требование.
4. **Урок пройден**, когда он прочитан, квиз решён без ошибок и все задания сданы.

> Застряли в задании? Нажмите «Подсказка»: подсказки открываются по одной. Если и это не помогло, перечитайте нужный раздел урока или спросите преподавателя. Ошибаться нормально: перерешивать задание можно сколько угодно.

В конце курса вас ждёт **демонстрационный экзамен**. На нём нужно будет по заданию сделать дизайн и вёрстку настоящего сайта. Всё, что мы изучаем, потом понадобится там, поэтому задания курса похожи на экзаменационные, только меньше.

## Что происходит, когда вы открываете сайт

Вы набираете в браузере адрес, например `https://example.ru`, и через секунду видите страницу. За эту секунду происходит вот что:

1. **Браузер** (Chrome, Яндекс Браузер, Firefox) — это программа на вашем компьютере. Он находит по адресу нужный компьютер в интернете.
2. Этот компьютер называется **сервер**. На нём лежат файлы сайта.
3. Браузер отправляет серверу **запрос**: «пришли мне главную страницу».
4. Сервер отвечает: присылает **файлы** — HTML, CSS, JavaScript, картинки.
5. Браузер читает эти файлы и **рисует** из них страницу.

| Кто | Что делает | Пример |
|---|---|---|
| Клиент (браузер) | Просит файлы и показывает страницу | Chrome на вашем телефоне |
| Сервер | Хранит файлы и отдаёт их по запросу | Компьютер хостинга |
| Протокол HTTP / HTTPS | Правила, по которым они общаются | `https://` в начале адреса |
| Адрес (URL) | Где лежит страница | `https://example.ru/about.html` |

Буква **s** в `https` значит secure — «защищённый»: данные между браузером и сервером шифруются.

## Три языка веб-страницы

Любая страница в интернете собрана из трёх слоёв. Удобно представить дом:

- **HTML** — стены и комнаты. Он говорит, *что* есть на странице: заголовок, абзац, картинка, кнопка.
- **CSS** — отделка и мебель. Он говорит, *как* это выглядит: цвета, шрифты, размеры, расположение.
- **JavaScript** — электричество и техника. Он делает страницу *живой*: открывает меню, проверяет форму, считает.

Начинаем всегда с HTML: без стен нечего красить.

## Что такое HTML

**HTML** (HyperText Markup Language) — язык гипертекстовой разметки. Это не язык программирования: в нём нет вычислений. Мы просто *размечаем* текст: говорим браузеру, где заголовок, где абзац, где список.

Разметка делается **тегами**. Тег — это слово в угловых скобках:

```html
<h1>Пепельный Пиксель</h1>
<p>Учимся делать сайты с нуля.</p>
```

Здесь два **элемента**:

- `<h1>` — открывающий тег заголовка, `</h1>` — закрывающий (с косой чертой `/`). Между ними — текст заголовка.
- `<p>` — абзац (от слова paragraph). Тоже открывается и закрывается.

Элемент = открывающий тег + содержимое + закрывающий тег.

> **Попробуйте сами.** Нажмите «Попробовать» под примером выше. Поменяйте текст в заголовке и посмотрите на предпросмотр. Потом удалите `</h1>` и посмотрите, что станет с абзацем.

## Заголовки

Заголовков шесть уровней: от `h1` (самый главный) до `h6`:

```html
<h1>Курс веб-разработки</h1>
<h2>Раздел 1. HTML</h2>
<h3>Тема 1. Первые теги</h3>
```

Правила, которые пригодятся на экзамене:

- `h1` на странице **один** — это её название.
- Уровни идут по порядку: после `h2` идёт `h3`, а не сразу `h4`.
- Заголовок выбирают **по смыслу**, а не по размеру шрифта. Размер потом поменяем в CSS.

## Абзацы и переносы строк

Браузер **не видит** переносы строк и лишние пробелы в коде. Сколько ни нажимай Enter, текст склеится в одну строку:

```html
<p>Первая строка
   вторая строка
          третья</p>
```

Чтобы начать новый абзац, нужен новый `<p>`. Чтобы перенести строку внутри абзаца (например, в адресе или стихотворении), используют `<br>`:

```html
<p>г. Москва,<br>ул. Ленина, 1</p>
```

У `<br>` нет закрывающего тега: ему нечего «оборачивать». Такие теги называют **одиночными** (пустыми).

## Выделение текста

| Тег | Что значит | Как выглядит по умолчанию |
|---|---|---|
| `<strong>` | Важное, сильный акцент | **жирный** |
| `<em>` | Логическое ударение | *курсив* |
| `<mark>` | Пометка, найденное слово | жёлтый фон |
| `<small>` | Мелкий шрифт: примечание, копирайт | меньше обычного |

```html
<p>Сдать работу нужно <strong>до пятницы</strong>.</p>
<p>Я <em>правда</em> прочитал урок.</p>
```

Для выделения смысла используйте `strong` и `em`. Старые теги `<b>` и `<i>` тоже работают, но смысла не несут, только внешний вид.

## Вложенность

Теги можно вкладывать друг в друга. Главное правило: **закрываем в обратном порядке**, как матрёшку.

```html
<p>Это <strong>правильно</strong>.</p>
```

А вот так нельзя — теги «перехлёстываются»:

```html
<p>Это <strong>неправильно</p></strong>
```

Браузер попробует угадать, что вы имели в виду, но разные браузеры угадают по-разному. Поэтому в заданиях курса работает **линтер**: он подсвечивает такие ошибки красным прямо в редакторе.

## Комментарии

Комментарий — заметка для человека, браузер её не показывает:

```html
<!-- Здесь будет меню -->
<p>Текст страницы</p>
```

Комментариями удобно отмечать, что где лежит, и временно «выключать» кусок кода.

## Где писать код

На этом курсе код можно писать прямо на сайте, в редакторе заданий. Дома и на экзамене понадобится редактор кода на компьютере, например **Visual Studio Code**. В нём вы создаёте файл `index.html`, пишете код и открываете файл в браузере двойным щелчком.

## Главное за занятие

- Браузер (клиент) просит файлы у сервера и рисует из них страницу.
- Страница — это HTML (что есть), CSS (как выглядит) и JavaScript (как работает).
- HTML размечает текст тегами: `<p>` открывает, `</p>` закрывает.
- `h1`–`h6` — заголовки, `p` — абзац, `br` — перенос строки, `strong` и `em` — выделение.
- Теги закрываются в обратном порядке, как матрёшка.

## Словарик

- **Браузер** — программа для просмотра сайтов.
- **Сервер** — компьютер, который хранит сайт и отдаёт его файлы.
- **URL** — адрес страницы в интернете.
- **HTML** — язык разметки, которым описывают содержимое страницы.
- **Тег** — команда разметки в угловых скобках: `<p>`.
- **Элемент** — открывающий тег, содержимое и закрывающий тег вместе.
