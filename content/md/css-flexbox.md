Flexbox раскладывает элементы в строку или в столбец. Включается одной строкой на родителе: `display: flex`.

## Две оси

- **Главная ось** — по ней идут элементы (по умолчанию слева направо). Выравнивание по ней — `justify-content`.
- **Поперечная ось** — перпендикулярно. Выравнивание — `align-items`.

```css
.goods {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}
.card { flex: 1; }
```

## gap вместо margin

Раньше расстояние между элементами делали через `margin-right` и убирали его у последнего. Теперь есть `gap`: он ставит отступ только между элементами.

## flex: 1

`flex: 1` у детей делит свободное место поровну — карточки станут одной ширины.

> Частая ошибка: `display: flexbox`. Такого значения нет, браузер молча проигнорирует строку. Линтер в заданиях подсветит её красным.
