## Коротко о теории

- **Прототип** — макет, по которому уже понятно, как работает страница: какие блоки, в каком порядке, что нажимать. В отличие от эскиза (занятия 40–41), в прототипе уже применён стайлгайд.
- **Модульная сетка** (занятие 37): на 1440px — 12 колонок, поля по 80px, промежутки (гаттеры) 24px; на 360px — 4 колонки, поля 16px, промежутки 16px.
- **Иерархия** (занятие 44): на первом экране одна главная мысль (`h1`) и одно главное действие (первичная кнопка).
- **Стайлгайд в коде** (занятие 47): значения — только в `:root`, в классах — только `var(--…)`.
- **Mobile first** (занятие 22): сначала стили для телефона, потом `@media (min-width: 768px)` для широких экранов.

## Ход работы

### Шаг 1. Фреймы в Figma

1. Создайте новый файл Figma и назовите его «Читальный зал — прототип».
2. Переименуйте страницу (Page) в «Прототип». Создайте вторую страницу «Стайлгайд» и перенесите туда (или нарисуйте заново) палитру, шрифты и кнопки из таблицы выше. Каждый цвет сделайте стилем цвета (`color/primary` и т. д.), шрифты — стилями текста (`text/h1`, `text/body`).
3. На странице «Прототип» нажмите F (инструмент Frame) и справа выберите Desktop → размер 1440×1024. Назовите фрейм «Главная — 1440».
4. Создайте второй фрейм 360×800 и назовите его «Главная — 360».

### Шаг 2. Модульная сетка

1. Выделите фрейм 1440. На правой панели в разделе Layout guide (Layout grid) нажмите «+».
2. Нажмите на значок сетки и выберите тип Columns: Count — 12, Type — Stretch, Margin — 80, Gutter — 24.
3. Для фрейма 360 сделайте так же: Count — 4, Margin — 16, Gutter — 16.
4. Сетку можно прятать и показывать сочетанием Ctrl+Shift+4 (на Mac — Control+G).

### Шаг 3. Блоки по ТЗ

1. Внутри фрейма 1440 нарисуйте прямоугольники (R) для пяти блоков ТЗ: шапка, первый экран, преимущества, новые поступления, подвал. Каждый блок сделайте фреймом (выделить → Ctrl+Alt+G, Frame selection) и назовите по-русски: «Шапка», «Первый экран»…
2. Края контента ставьте по колонкам сетки: начинается в первой колонке, заканчивается в двенадцатой.
3. Расстояния между блоками берите из шкалы: между разделами 64px (8 × 8), внутри блоков 16–32px.
4. Повторите для 360: те же блоки, но преимущества и карточки — друг под другом, на всю ширину четырёх колонок.

### Шаг 4. Стайлгайд и компоненты в макете

1. Заполните блоки текстом из ТЗ. Заголовкам назначьте стиль `text/h1` или `text/h2`, тексту — `text/body`.
2. Нарисуйте кнопку один раз, включите Auto Layout (Shift+A): padding 0 24, высота 44. Сделайте её компонентом (Ctrl+Alt+K). Если на прошлом занятии вы собрали варианты (Primary / Secondary), используйте их.
3. Карточку книги тоже сделайте компонентом: обложка, название, автор, бейдж, кнопка. На макете — три экземпляра с разным текстом.
4. Сделайте «тест трёх секунд»: что бросается в глаза первым? Должны быть заголовок первого экрана и кнопка «Найти книгу».

Эти шаги вы показываете преподавателю в Figma. Дальше — то же самое в коде: задания на сайте.

### Шаг 5. Шапка и первый экран (задание 1 на сайте)

В шаблоне уже есть `:root` со стайлгайдом и классы кнопок `.btn`, `.btn-primary`, `.btn-secondary`. Вам нужно написать HTML шапки и первого экрана и стили для них.

Шапка — `header` с классом `header`: логотип и `nav` со списком ссылок. Чтобы логотип был слева, а меню справа, подойдёт Flexbox:

```css
.header {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
  align-items: center;
  gap: var(--space-2);
  padding: var(--space-2) var(--space-3);
  background: var(--color-primary);
}
```

`flex-wrap: wrap` нужен для телефона: если меню не помещается рядом с логотипом, оно переносится на новую строку, а не вылезает за экран.

Первый экран — `section` с классом `hero`: `h1`, абзац и блок с двумя кнопками-ссылками:

```html
<div class="hero-actions">
  <a class="btn btn-primary" href="#catalog">Найти книгу</a>
  <a class="btn btn-secondary" href="#booking">Забронировать место</a>
</div>
```

Частая ошибка: написать цвет шапки HEX-кодом «на минутку». Проверка задания это заметит: вне `:root` цвета только через `var()`.

### Шаг 6. Блок преимуществ (задание 2 на сайте)

Три преимущества — три одинаковые по строению карточки `article.feature`: иконка (`alt=""` — она украшение, рядом есть заголовок), `h3` и абзац. Их обёртка `.features-list` на телефоне выстраивает карточки в колонку, а с 768px — в три колонки:

```css
.features-list {
  display: grid;
  gap: var(--space-3);
}
@media (min-width: 768px) {
  .features-list { grid-template-columns: repeat(3, 1fr); }
}
```

Это mobile first: базовые стили — для телефона, медиазапрос добавляет колонки на широком экране.

### Шаг 7. Новые поступления и подвал (задание 3 на сайте)

Карточки книг — список `ul.cards` из трёх `li.card`. Внутри: обложка `img` с осмысленным `alt`, `h3` с названием, `p.author`, бейдж `span.badge` «Новинка» и кнопка-ссылка «Забронировать» (`.btn .btn-secondary`). Сетка — та же схема, что в шаге 6.

Чтобы обложка не вылезала из карточки на телефоне:

```css
.card img { display: block; width: 100%; height: auto; border-radius: var(--radius); }
```

Подвал — `footer.footer` с тёмным фоном `var(--color-text)` и светлым текстом `var(--color-on-primary)`. Телефон и почта — ссылки:

```html
<a href="tel:+78001234567">8 800 123-45-67</a>
<a href="mailto:library@college.ru">library@college.ru</a>
```
