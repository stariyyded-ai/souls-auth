## Лекция

**Что такое PHP и где он работает.** HTML, который вы верстали в модуле 3, — это статичная страница: что написали, то браузер и показал. Но на экзамене нужно, чтобы страница «знала», кто вошёл, показывала именно его заявки и сохраняла данные из формы. Для этого нужен язык, который работает **на сервере**. PHP — такой язык.

Схема простая:

1. Браузер просит страницу `http://localhost/portal/requests.php`.
2. Apache (из XAMPP) видит расширение `.php` и отдаёт файл интерпретатору PHP.
3. PHP выполняет код, ходит в базу данных и **собирает HTML**.
4. В браузер уходит уже готовый HTML. Кода PHP пользователь никогда не видит (проверьте: «Просмотр кода страницы» покажет только HTML).

Отсюда главное правило: PHP-файлы открываются **только через `http://localhost/...`**, а не двойным кликом. Если в адресной строке `file:///C:/...` — PHP не работает, и вы увидите свой код как текст.

**Первый файл.** Создайте папку `C:\xampp\htdocs\practice\` и файл `hello.php`:

```php
<?php
$name = 'Аня';           // переменная: имя начинается с $
$year = 2027;            // целое число
$price = 1500.50;        // дробное число
$isAdmin = false;        // логическое: true или false

echo "Привет, $name! Экзамен в $year году.<br>";
echo 'Цена услуги: ' . $price . ' руб.<br>';   // точка склеивает строки
echo 'Тип переменной $year: ' . gettype($year);
```

Обратите внимание на три вещи. Каждая команда заканчивается **точкой с запятой** — забыли её, получили `Parse error`. В **двойных кавычках** переменные подставляются (`"Привет, $name"`), в одинарных — нет (`'$name'` выведется буквально). Строки склеиваются **точкой**, а не плюсом, как в JavaScript.

**PHP внутри HTML.** PHP можно «вставлять» в HTML. Для вывода значения есть короткая запись `<?= ... ?>` — это то же самое, что `<?php echo ... ?>`:

```php
<?php $title = 'Мои заявки'; ?>
<!doctype html>
<html lang="ru">
<head><meta charset="utf-8"><title><?= $title ?></title></head>
<body>
  <h1><?= $title ?></h1>
  <p>Сегодня: <?= date('d.m.Y') ?></p>
</body>
</html>
```

**Массивы.** Массив — это «коробка с ячейками». Бывает два вида.

```php
<?php
// Индексный массив: ключи 0, 1, 2...
$services = ['Генеральная уборка', 'Мойка окон', 'Химчистка мебели'];
echo $services[0];            // Генеральная уборка
$services[] = 'Иная услуга';  // добавить в конец
echo count($services);        // 4

// Ассоциативный массив: ключи — строки. Так выглядит строка из БД!
$request = [
    'id'      => 7,
    'address' => 'ул. Ленина, 5',
    'status'  => 'new',
    'payment' => 'card',
];
echo $request['address'];     // ул. Ленина, 5
```

Запомните ассоциативный массив особенно хорошо: когда в ЛР мы будем доставать заявку из базы, PHP вернёт именно такой массив, где ключи — названия столбцов.

**Условия.**

```php
<?php
$status = 'cancelled';
$reason = 'Клиент передумал';

if ($status === 'new') {
    echo 'Новая заявка';
} elseif ($status === 'cancelled') {
    echo 'Отменена. Причина: ' . $reason;
} else {
    echo 'Заявка в работе или выполнена';
}

// Логические операторы: && (и), || (или), ! (не)
$login = 'ivan';
if (strlen($login) < 6 || $login === '') {
    echo '<br>Логин должен быть не короче 6 символов';
}
```

Используйте строгое сравнение `===` (сравнивает и значение, и тип). Обычное `==` иногда даёт сюрпризы: например, `'abc' == 0` в старом PHP было истиной. Ещё ошибка новичков — `if ($a = 5)`: одно `=` — это присваивание, условие всегда будет истинным.

**Циклы.** Чаще всего на экзамене нужен `foreach` — перебор массива. Именно им мы будем выводить список заявок.

```php
<?php
$requests = [
    ['id' => 1, 'address' => 'ул. Мира, 1',   'status' => 'new'],
    ['id' => 2, 'address' => 'пр. Победы, 12', 'status' => 'done'],
    ['id' => 3, 'address' => 'ул. Садовая, 3', 'status' => 'cancelled'],
];
?>
<table border="1">
  <tr><th>№</th><th>Адрес</th><th>Статус</th></tr>
  <?php foreach ($requests as $r): ?>
    <tr>
      <td><?= $r['id'] ?></td>
      <td><?= $r['address'] ?></td>
      <td><?= $r['status'] ?></td>
    </tr>
  <?php endforeach; ?>
</table>
<?php
// Обычный цикл for — когда нужно «повторить N раз», например номера страниц
for ($i = 1; $i <= 5; $i++) {
    echo "<a href=\"?page=$i\">$i</a> ";
}
```

Запись `foreach (...): ... endforeach;` с двоеточием удобна внутри HTML — так не путаешься в фигурных скобках. Внутри «чистого» PHP пишем с фигурными скобками.

**Функции.** Функция — именованный кусок кода, который можно вызывать много раз. Правило DRY (Don't Repeat Yourself): если вы копируете один и тот же код второй раз — сделайте функцию.

```php
<?php
function statusLabel(string $status): string
{
    $labels = [
        'new'       => 'Новая',
        'in_work'   => 'В работе',
        'done'      => 'Выполнена',
        'cancelled' => 'Отменена',
    ];
    return $labels[$status] ?? 'Неизвестно';   // ?? — «если ключа нет, то...»
}

echo statusLabel('done');      // Выполнена
echo statusLabel('xxx');       // Неизвестно
```

`string $status` — тип параметра, `: string` — тип результата. Их можно не писать, но с ними PHP сам подскажет, если вы передали не то. Оператор `??` вы встретите везде: `$_POST['login'] ?? ''` значит «возьми логин из формы, а если его нет — пустую строку».

**include и require: собираем страницу из кусков.** Шапка с меню нужна на каждой странице. Копировать её в 8 файлов — плохо: поменяли пункт меню, правьте 8 мест. Решение — вынести её в отдельный файл и подключать:

```php
<?php
// practice/page.php
$title = 'Главная';
require __DIR__ . '/header.php';   // вставит сюда содержимое header.php
?>
<p>Содержимое страницы</p>
<?php require __DIR__ . '/footer.php'; ?>
```

Разница: `include` при отсутствии файла выдаст предупреждение и продолжит работу, `require` — остановит скрипт. Для важных файлов (настройки, подключение к БД) всегда `require_once` — «подключи, и только один раз». `__DIR__` — папка текущего файла; с ним пути не ломаются, откуда бы файл ни подключили.

**Типичные ошибки на старте.**

| Что видите | Причина |
|---|---|
| Код PHP показывается как текст | Открыли файл не через `localhost` или не запущен Apache |
| `Parse error: syntax error, unexpected ...` | Пропущена `;`, скобка или кавычка — смотрите строку **выше** указанной |
| `Warning: Undefined variable $nme` | Опечатка в имени переменной |
| `Warning: Undefined array key "fio"` | В массиве нет такого ключа — проверьте написание |
| Белый экран | Ошибки скрыты; включим их показ в ЛР23 |

**Безопасность уже сейчас.** Мы пока выводим данные «как есть» (`<?= $r['address'] ?>`). С массивом из кода это безопасно, но как только данные придут от пользователя, такой вывод станет дырой (XSS). Начиная с ЛР23 весь вывод будет идти через функцию `e()`. Запомните: **всё, что пришло от пользователя, перед выводом экранируем**.

**Связь с экзаменом.** На демоэкзамене нет времени вспоминать синтаксис. Переменные, ассоциативные массивы, `if`, `foreach` и `require` — это 90 % PHP, который вы напишете в задании 1. Сегодня цель — чтобы эти конструкции стали «руками», а не «головой».
