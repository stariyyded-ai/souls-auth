## Что такое визуальная иерархия

Представьте объявление на двери деканата. Если весь текст написан одинаковым шрифтом одного размера, вы читаете его целиком, чтобы понять, о чём оно. А если сверху крупно «Перенос пары», ниже обычным шрифтом подробности и мелко — подпись, суть ясна за секунду.

**Визуальная иерархия** — это порядок, в котором человек замечает элементы на экране. Дизайнер решает заранее: что пользователь увидит первым, что вторым, а что прочитает, только если захочет.

На любой странице обычно три уровня:

| Уровень | Что это | Пример на странице кафе |
|---|---|---|
| Первый | Главная мысль, то, ради чего пришли | «Кофе с собой за 5 минут» |
| Второй | Пояснения и разделы | «Меню», «Как нас найти» |
| Третий | Детали, мелкий текст | Время работы, сноски, копирайт |

Иерархию создают шесть инструментов:

1. **Размер.** Крупное замечают первым.
2. **Насыщенность шрифта** (жирность). Жирное «весит» больше обычного.
3. **Цвет и контраст.** Яркий акцент на спокойном фоне притягивает взгляд.
4. **Положение.** Верх и левая часть экрана читаются раньше (вспомните F- и Z-паттерны из занятия 42).
5. **Отступы.** Элемент, вокруг которого много свободного места, кажется важнее.
6. **Форма и рамка.** Кнопка или карточка выделяется среди простого текста.

Сравните две карточки. В первой всё одинаковое, во второй есть иерархия:

```html
<style>
  .card { max-width: 320px; padding: 16px; margin-bottom: 16px; border: 1px solid #cccccc; font-family: Arial, sans-serif; }
  .flat p { margin: 4px 0; font-size: 16px; }
  .good .date { margin: 0; font-size: 14px; color: #5a6475; }
  .good h2 { margin: 4px 0 8px; font-size: 26px; }
  .good .text { margin: 0 0 16px; line-height: 1.5; }
  .good a { display: inline-block; padding: 10px 16px; border-radius: 8px; background: #1f5fa8; color: #ffffff; text-decoration: none; }
</style>
<div class="card flat">
  <p>12 ноября, 15:00</p>
  <p>День открытых дверей</p>
  <p>Покажем мастерские и расскажем о специальностях.</p>
  <p><a href="#">Записаться</a></p>
</div>
<div class="card good">
  <p class="date">12 ноября, 15:00</p>
  <h2>День открытых дверей</h2>
  <p class="text">Покажем мастерские и расскажем о специальностях.</p>
  <a href="#">Записаться</a>
</div>
```

Что увидите: в первой карточке взгляду не за что зацепиться, строки одинаковые. Во второй сразу видно название события, дата стала мелкой серой подсказкой, а кнопка «Записаться» — заметное действие.

**Тест трёх секунд.** Посмотрите на свой макет три секунды и отвернитесь. Что вы запомнили? Если не главное, а, например, яркую иконку в углу, иерархия сломана.

Частая ошибка: выделить всё. Когда на странице пять жирных красных надписей, ни одна не выделяется. Правило простое: **на экране одна главная вещь**, остальное ей подчиняется.

> **Попробуйте сами.** Откройте пример выше в песочнице. Сделайте во второй карточке дату такого же размера и цвета, как заголовок. Посмотрите, как сразу стало труднее понять, что главное.

## Принципы гештальта

**Гештальт** (от немецкого Gestalt — «форма, целое») — это наблюдения психологов о том, как мозг объединяет отдельные предметы в группы. Мы не видим пять точек — мы видим «две пары и ещё одну». Дизайнеры используют эти законы, чтобы страница сама подсказывала, что с чем связано.

### Близость

Элементы, которые стоят **близко**, мозг считает одной группой. Это самый сильный принцип.

На практике это значит: подпись поля ближе к своему полю, чем к соседнему. Заголовок раздела ближе к своему тексту, чем к предыдущему разделу.

```html
<style>
  body { font-family: Arial, sans-serif; }
  .bad h2 { margin: 24px 0 24px; }
  .good h2 { margin: 32px 0 8px; }
  p { margin: 0; }
</style>
<div class="bad">
  <h2>Расписание</h2>
  <p>Пары начинаются в 8:30.</p>
  <h2>Столовая</h2>
  <p>Работает с 9:00 до 16:00.</p>
</div>
<hr>
<div class="good">
  <h2>Расписание</h2>
  <p>Пары начинаются в 8:30.</p>
  <h2>Столовая</h2>
  <p>Работает с 9:00 до 16:00.</p>
</div>
```

Что увидите: в верхнем блоке заголовок «Столовая» висит посередине, и непонятно, к какому тексту он относится. В нижнем блоке заголовок прижат к своему абзацу, а от предыдущего раздела его отделяет большой отступ.

Правило для CSS: у заголовка **отступ сверху больше, чем снизу**. Например, `margin: 32px 0 8px`. Частая ошибка новичков — одинаковый `margin` со всех сторон у всех элементов.

### Сходство

Элементы, которые **выглядят одинаково**, мозг считает однотипными. Все ссылки одного цвета — значит, всё синее подчёркнутое можно нажать. Все цены оформлены одинаково — значит, это цены.

Отсюда обратное правило: если два элемента делают разное, они должны выглядеть по-разному. Частая ошибка: подчёркивать обычный текст для красоты. Пользователь будет нажимать на него, думая, что это ссылка.

В CSS сходство достигается **классами**: одинаковые элементы получают один класс и один набор стилей.

```css
/* Плохо: три цены — три разных оформления */
.price { font-weight: bold; }
.cost { font-style: italic; color: #1f5fa8; }

/* Хорошо: один класс для всех цен */
.price { font-weight: bold; color: #8a3b12; }
```

### Выравнивание

Глаз ведёт невидимые линии по краям элементов. Если края совпадают, страница выглядит аккуратной, даже если на ней много всего. Если каждый блок начинается в своём месте, кажется, что страница «разъехалась».

Практические правила:

- Выберите одну линию выравнивания для текста — обычно левый край.
- Не смешивайте в одном блоке текст по центру и текст по левому краю.
- Цены, суммы, числа в таблице выравнивайте по **правому** краю, чтобы разряды стояли друг под другом.

```html
<style>
  body { font-family: Arial, sans-serif; }
  ul { max-width: 280px; padding: 0; list-style: none; }
  li { display: flex; justify-content: space-between; padding: 6px 0; border-bottom: 1px solid #dddddd; }
</style>
<ul>
  <li><span>Американо</span><span>120 ₽</span></li>
  <li><span>Капучино</span><span>160 ₽</span></li>
  <li><span>Раф</span><span>1 290 ₽</span></li>
</ul>
```

Что увидите: названия напитков стоят по левому краю, цены — по правому, и их легко сравнивать. Это сделал `justify-content: space-between` из занятия про Flexbox: он разносит два элемента по краям строки.

### Общая область

Ещё один полезный принцип: элементы внутри одной **рамки или фона** воспринимаются как группа. Карточка товара — это и есть общая область: картинка, название и цена в одной рамке относятся к одному товару. Иногда рамка не нужна: хватает близости. Не обводите рамкой всё подряд.

## Типографика: шрифты и пары

**Типографика** — это искусство оформлять текст так, чтобы его было легко и приятно читать. На сайте 80–90% интерфейса — текст, поэтому типографика решает больше, чем картинки.

Шрифты делятся на группы:

| Группа | Как выглядит | Где хороша | Пример в CSS |
|---|---|---|---|
| С засечками (serif) | Маленькие «полочки» на концах букв | Заголовки, длинное чтение, «солидный» стиль | `Georgia, serif` |
| Без засечек (sans-serif) | Ровные концы букв | Интерфейс, кнопки, основной текст | `Arial, sans-serif` |
| Моноширинный (monospace) | Все буквы одной ширины | Код, номера заказов | `"Courier New", monospace` |

**Шрифтовая пара** — два шрифта, которые хорошо смотрятся вместе: один для заголовков, второй для текста. Хорошая пара — это контраст: например, заголовки с засечками и текст без засечек. Плохая пара — два похожих, но разных шрифта без засечек: выглядит как ошибка.

Правила, которые пригодятся на экзамене:

- На странице **не больше двух шрифтов**. Третий почти всегда лишний.
- Разницу внутри одного шрифта создают размер и жирность, а не новый шрифт.
- Всегда пишите запасной шрифт и общее семейство в конце: `font-family: Georgia, "Times New Roman", serif;`. Если первого шрифта нет у пользователя, браузер возьмёт следующий.
- Декоративные и рукописные шрифты — только для коротких надписей вроде логотипа.

```html
<style>
  body { font-family: Arial, sans-serif; font-size: 18px; line-height: 1.6; color: #222222; }
  h1, h2 { font-family: Georgia, "Times New Roman", serif; line-height: 1.2; }
</style>
<h1>Библиотека колледжа</h1>
<p>Здесь можно взять учебник, посидеть в тишине и распечатать курсовую.</p>
<h2>Часы работы</h2>
<p>Понедельник–пятница, с 9:00 до 18:00.</p>
```

Что увидите: заголовки с засечками выглядят «книжно» и отличаются от спокойного текста без засечек. Это и есть шрифтовая пара.

На экзамене шрифты задаёт ваш собственный стайлгайд (о нём — на занятии 47): вы выбираете пару и потом везде используете только её.

## Кегль и шкала размеров

**Кегль** — это размер шрифта. В CSS его задаёт `font-size`.

- Основной текст на сайте: **16–18px**. Меньше 16px читать с телефона тяжело.
- Мелкий текст (подписи, сноски): 13–14px, не меньше.
- Заголовки — крупнее текста заметно, а не на 1–2 пикселя. Если `h2` 18px, а текст 16px, разницу никто не увидит.

Чтобы размеры не выбирать «на глаз», дизайнеры берут **шкалу**: каждый следующий размер больше предыдущего в одно и то же число раз. Например, в 1,25 раза:

| Элемент | Размер | Как получили |
|---|---|---|
| Мелкий текст | 14px | 18 ÷ 1,25 |
| Основной текст | 18px | основа |
| `h3` | 22px | 18 × 1,25 |
| `h2` | 28px | 22 × 1,25 |
| `h1` | 36–44px | 28 × 1,25 и ещё раз |

Хорошее правило проверки: главный заголовок **хотя бы в два раза** крупнее основного текста.

```css
body { font-size: 18px; }
h1 { font-size: 40px; }
h2 { font-size: 28px; }
.note { font-size: 14px; }
```

Частая ошибка: выбирать уровень заголовка по размеру. Если нужен мелкий заголовок, это всё равно `h2` — размер меняется в CSS.

## Интерлиньяж

**Интерлиньяж** — расстояние между строками. В CSS это `line-height`. Удобнее всего писать его числом без единиц: `line-height: 1.5` значит «полтора размера шрифта».

- Основной текст: **1,4–1,7**. Строкам нужен воздух, иначе глаз «перескакивает» на соседнюю строку.
- Заголовки: **1,1–1,3**. Крупные строки с большим интерлиньяжем разваливаются.

```html
<style>
  body { font-family: Arial, sans-serif; font-size: 18px; max-width: 520px; }
  .tight { line-height: 1.0; }
  .good { line-height: 1.6; }
</style>
<p class="tight">Студенческий совет приглашает всех на субботник. Сбор у главного входа в 10:00. Перчатки и мешки выдадим на месте, чай после уборки — в столовой.</p>
<p class="good">Студенческий совет приглашает всех на субботник. Сбор у главного входа в 10:00. Перчатки и мешки выдадим на месте, чай после уборки — в столовой.</p>
```

Что увидите: первый абзац выглядит как сплошной серый кирпич, строки почти касаются друг друга. Второй читается спокойно.

> **Попробуйте сами.** В примере выше поставьте второму абзацу `line-height: 2.5`. Строки «развалятся» — текст перестанет восприниматься как абзац. Найдите значение, при котором читать удобнее всего.

## Длина строки

Если строка слишком длинная, глаз, дойдя до конца, теряет начало следующей. Если слишком короткая, приходится постоянно «прыгать» взглядом, и текст рвётся на куски. Удобная длина строки — **45–75 знаков** (букв, пробелов и знаков препинания), идеал около 65.

На широком мониторе абзац без ограничения растягивается на 200 знаков. Поэтому текстовому блоку задают `max-width`. Удобная единица — `ch`: **1ch** — это ширина цифры «0» в текущем шрифте, то есть примерно ширина одного знака.

```html
<style>
  body { font-family: Arial, sans-serif; font-size: 18px; line-height: 1.6; }
  article { max-width: 65ch; margin: 0 auto; }
</style>
<article>
  <h1>Как готовиться к сессии</h1>
  <p>Начните за месяц, а не за ночь. Составьте список предметов и отметьте, какие темы вы уже знаете. Каждый день повторяйте одну тему и решайте по пять задач. Так к экзамену вы подойдёте спокойным и выспавшимся.</p>
</article>
```

Что увидите: даже на широком экране абзац остаётся узким — около 65 знаков в строке — и стоит по центру страницы, потому что `margin: 0 auto` делит свободное место поровну слева и справа.

Частая ошибка: задать `width: 800px` текстовому блоку. На телефоне шириной 360px такой блок вылезет за экран. `max-width` ограничивает ширину сверху, но позволяет блоку сжиматься.

## Отступы и «воздух»

Пустое место на странице — не пустая трата места. Дизайнеры называют его **воздухом** (или негативным пространством). Воздух группирует элементы (принцип близости), выделяет главное и делает страницу спокойнее.

Чтобы отступы не были случайными (13px тут, 17px там), берут **шкалу отступов**, кратную 8: 4, 8, 16, 24, 32, 48, 64. Вы уже встречали её на занятии 37 про модульную сетку.

| Отступ | Где использовать |
|---|---|
| 4–8px | Внутри маленького элемента: иконка и подпись, заголовок и его текст |
| 16–24px | Между абзацами, внутри карточки, между полями формы |
| 32–48px | Между разделами страницы |
| 64px и больше | Между крупными блоками лендинга |

Главный принцип: **чем теснее связь, тем меньше отступ**. Внутри группы — маленький, между группами — большой. Если отступы везде одинаковые, группы пропадают.

```css
.section { margin-bottom: 48px; }    /* между разделами */
.section h2 { margin: 0 0 8px; }     /* заголовок прижат к тексту */
.section p { margin: 0 0 16px; }     /* между абзацами */
```

## Выравнивание текста

Выравнивание задаёт `text-align`:

- `left` (по левому краю) — для всего, что больше двух строк. Каждая строка начинается в одном месте, глазу легко найти начало.
- `center` — для коротких надписей: заголовок первого экрана, текст на кнопке, подпись под иконкой. Длинный текст по центру читать тяжело: у каждой строки своё начало.
- `right` — для чисел в таблицах и цен.
- `justify` (по ширине) — в вебе лучше не использовать: браузер растягивает пробелы, и в тексте появляются «дыры», особенно на узком экране телефона.

Частая ошибка: выровнять по центру весь сайт «для красоты». Абзац по центру из пяти строк выглядит как стихотворение и читается медленно.

> **Попробуйте сами.** Возьмите пример со статьёй «Как готовиться к сессии» и добавьте абзацу `text-align: center`, потом `text-align: justify`. Сузьте окно песочницы и сравните, какой вариант читать легче всего.

## Чек-лист типографики

Перед тем как сдавать макет или вёрстку, пройдитесь по списку:

1. Главное на экране замечается за 3 секунды.
2. Шрифтов не больше двух, у каждого есть запасной и общее семейство.
3. Основной текст 16–18px, `h1` хотя бы в два раза крупнее.
4. `line-height` текста 1,4–1,7, заголовков 1,1–1,3.
5. Текстовые блоки ограничены `max-width` около 65ch.
6. У заголовков отступ сверху больше, чем снизу.
7. Отступы из шкалы 8: внутри группы меньше, между группами больше.
8. Длинный текст выровнен по левому краю.
9. Контраст текста не ниже 4,5:1 (это вы проверяли на занятии 39).

Этот список почти дословно совпадает с тем, что эксперты смотрят на демоэкзамене в критерии «типографика и композиция».

## Главное за занятие

- Визуальная иерархия — порядок, в котором замечают элементы. На экране одна главная вещь.
- Иерархию создают размер, жирность, цвет, положение, отступы и форма.
- Гештальт: близкое — одна группа, похожее — одного типа, выровненное — аккуратно.
- Не больше двух шрифтов; пара строится на контрасте (с засечками + без засечек).
- Текст 16–18px, интерлиньяж 1,4–1,7, строка 45–75 знаков (`max-width: 65ch`).
- Отступы из шкалы 8: внутри группы меньше, между группами больше; у заголовка сверху больше, чем снизу.

## Словарик

- **Визуальная иерархия** — порядок важности элементов на экране, который видит пользователь.
- **Гештальт** — законы, по которым мозг объединяет элементы в группы.
- **Типографика** — оформление текста для удобного чтения.
- **Шрифтовая пара** — два шрифта, которые используют вместе: для заголовков и для текста.
- **Кегль** — размер шрифта (`font-size`).
- **Интерлиньяж** — расстояние между строками (`line-height`).
- **ch** — единица CSS, ширина цифры «0» в текущем шрифте; примерно один знак.
- **Воздух** — свободное пространство вокруг элементов.
