На телефоне меню нажимают пальцем, а не курсором. Палец толще курсора, поэтому цели должны быть крупнее.

## Размер цели

WCAG рекомендует цели не меньше 44 × 44px. Маленькие ссылки увеличивай через `padding`, а не через размер шрифта:

```css
.menu a {
  display: block;
  padding: 14px 16px; /* высота станет больше 44px */
}
```

## Меню в строку и в столбец

```css
.menu { display: flex; flex-wrap: wrap; gap: 8px 24px; }
```

`flex-wrap: wrap` переносит пункты на новую строку, если они не помещаются, вместо того чтобы вылезать за экран.

## Активный пункт

Подсвечивай текущую страницу не только цветом: добавь подчёркивание или рамку и атрибут `aria-current="page"`, чтобы диктор сказал «текущая страница».
