## Flexbox или Grid

На прошлом занятии вы ставили элементы в ряд через Flexbox. Он думает **одной линией**: ряд или столбик. Если элементы переносятся, каждая новая строка живёт своей жизнью, и колонки между строками не выравниваются.

**Grid** (по-английски «решётка», «сетка») думает **сразу двумя направлениями**: строками и колонками. Вы рисуете сетку, а элементы раскладываются по её ячейкам.

| Задача | Чем удобнее |
|---|---|
| Пункты меню в шапке | Flexbox |
| Иконка рядом с текстом | Flexbox |
| Центрирование одного блока | Flexbox |
| Каталог карточек ровными колонками | Grid |
| Раскладка страницы: шапка, меню, контент, боковая колонка, подвал | Grid |
| Галерея фотографий | Grid |

Это не соревнование: на одной странице обычно работают оба. Шапка на Flexbox, каталог на Grid, а внутри карточки — снова Flexbox.

## Первая сетка

Grid, как и Flexbox, включается у **родителя**:

```html
<style>
  .grid {
    display: grid;
    grid-template-columns: 200px 200px 200px;
    gap: 16px;
  }
  .cell { padding: 16px; background-color: #f2d58a; }
</style>
<div class="grid">
  <div class="cell">1</div>
  <div class="cell">2</div>
  <div class="cell">3</div>
  <div class="cell">4</div>
  <div class="cell">5</div>
</div>
```

Что вы увидите: три колонки по 200px. Блоки 1, 2, 3 — в первой строке, 4 и 5 — во второй, ровно под 1 и 2.

- **Grid-контейнер** — элемент с `display: grid`.
- **Grid-элементы** — его прямые дети.
- `grid-template-columns` — сколько колонок и какой ширины. Каждое значение через пробел — отдельная колонка.
- `gap` — промежутки между ячейками, как во Flexbox.

Строки браузер создаёт сам, сколько понадобится. Их высоту можно задать через `grid-template-rows`, но обычно она подстраивается под содержимое.

## Единица fr

Колонки по 200px не растягиваются: на широком экране справа останется пустота, на узком — сетка вылезет за край. Для гибких колонок есть единица **`fr`** (от fraction — «доля»): доля свободного места.

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr; /* три равные колонки */
  gap: 16px;
}
```

`1fr 2fr` — вторая колонка вдвое шире первой. `250px 1fr` — левая колонка ровно 250px, правая забирает всё остальное. Так делают страницу с боковым меню.

Частая ошибка: колонки в процентах вместе с `gap`: `33.3% 33.3% 33.3%` плюс промежутки — это больше 100%, и сетка вылезает за край. С `fr` такого не бывает: `fr` делит место, которое **осталось** после промежутков.

## repeat и minmax

Писать `1fr 1fr 1fr 1fr` долго. Функция `repeat` повторяет колонки:

```css
grid-template-columns: repeat(4, 1fr); /* то же, что 1fr 1fr 1fr 1fr */
```

Функция `minmax(мин, макс)` задаёт колонке **границы**: не уже и не шире.

```css
grid-template-columns: minmax(200px, 300px) 1fr;
```

Первая колонка будет от 200 до 300px, вторая — всё остальное.

## auto-fit: сетка, которая считает сама

А теперь главный приём для каталогов и галерей. Вместо числа колонок в `repeat` пишем слово `auto-fit`:

```html
<style>
  .catalog {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
    gap: 16px;
  }
  .item { padding: 16px; border-radius: 12px; background-color: #f2d58a; }
</style>
<div class="catalog">
  <div class="item">Книга 1</div>
  <div class="item">Книга 2</div>
  <div class="item">Книга 3</div>
  <div class="item">Книга 4</div>
  <div class="item">Книга 5</div>
  <div class="item">Книга 6</div>
</div>
```

Что вы увидите: столько колонок, сколько помещается, если каждая не уже 180px. Все колонки одинаковые и вместе занимают всю ширину.

Как это читать: «сделай столько колонок, сколько **влезет** (`auto-fit`), каждая — **не меньше 180px и не больше одной доли** (`minmax(180px, 1fr)`)». На компьютере получится пять-шесть колонок, на планшете три, на телефоне одна. И ни одного медиазапроса.

Есть похожее слово `auto-fill`. Разница видна, только когда элементов мало: `auto-fill` оставляет пустые колонки, `auto-fit` растягивает имеющиеся элементы на всю ширину.

> **Попробуйте сами.** Нажмите «Попробовать» под примером с книгами и меняйте ширину окна предпросмотра. Потом замените `180px` на `300px` — сколько колонок осталось?

## Элемент на несколько ячеек

Иногда карточка должна занять две колонки — например, главная новость. Для этого у **элемента** пишут `grid-column: span 2`:

```css
.news--main {
  grid-column: span 2; /* занять две колонки */
}
```

Так же работает `grid-row: span 2` — две строки в высоту.

## Области: grid-template-areas

Самый наглядный способ разметить страницу — нарисовать её словами. Каждая строка в кавычках — строка сетки, каждое слово — ячейка:

```html
<style>
  .page {
    display: grid;
    grid-template-columns: 160px 1fr;
    grid-template-areas:
      "header header"
      "nav    main"
      "footer footer";
    gap: 8px;
  }
  .page__header { grid-area: header; background-color: #f2d58a; }
  .page__nav    { grid-area: nav;    background-color: #e8f0fe; }
  .page__main   { grid-area: main;   background-color: #eeeeee; }
  .page__footer { grid-area: footer; background-color: #f2d58a; }
  .page > * { padding: 16px; }
</style>
<div class="page">
  <header class="page__header">Шапка</header>
  <nav class="page__nav">Меню</nav>
  <main class="page__main">Основное содержимое</main>
  <footer class="page__footer">Подвал</footer>
</div>
```

Что вы увидите: шапка во всю ширину, ниже слева узкое меню и справа содержимое, внизу подвал во всю ширину.

Как это работает:

1. В `grid-template-areas` мы нарисовали схему. Одно и то же имя в соседних ячейках склеивает их в одну область: `header header` — шапка на две колонки.
2. Каждому элементу свойство `grid-area` говорит, в какую область встать.

Имена областей придумываете вы сами. Главное — чтобы область была прямоугольником, и в каждой строке схемы было одинаковое число слов.

Это удобно ещё и тем, что раскладку потом легко поменять для телефона: достаточно перерисовать схему. Сейчас увидим как.

## Адаптивность

Откройте любой сайт на телефоне и на компьютере. Это одна и та же страница, но выглядит она по-разному: на телефоне меню спрятано или стало столбиком, карточки идут по одной, шрифт крупнее относительно экрана. **Адаптивная вёрстка** — это вёрстка, которая подстраивается под ширину экрана.

На демоэкзамене адаптивность проверяют обязательно: страницу открывают на разных ширинах и смотрят, не развалилась ли она и нет ли горизонтальной прокрутки.

### meta viewport

Первое условие адаптивности вы уже знаете с занятия про структуру документа. В `<head>` должна быть строка:

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

Без неё телефон делает вид, что у него экран 980px, и показывает уменьшенную копию компьютерной версии с крошечным текстом. Все ваши медиазапросы при этом не сработают. В редакторе заданий курса эта строка добавляется автоматически, но в своих файлах не забывайте её.

### Медиазапросы

На занятии про свойства CSS3 вы уже видели медиазапрос `prefers-reduced-motion`. Теперь главный вид — по **ширине экрана**:

```css
.cards {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

@media (min-width: 768px) {
  .cards {
    grid-template-columns: repeat(2, 1fr);
  }
}
```

Читается так: «по умолчанию одна колонка. **Если ширина экрана 768px и больше** — две колонки». Правила внутри `@media` добавляются к обычным и перекрывают их, когда условие выполнено. Всё, что не перечислено внутри, остаётся как было.

- `min-width: 768px` — «от 768px и шире».
- `max-width: 767px` — «до 767px включительно».

### Mobile first

Можно идти двумя путями:

- сначала сверстать компьютерную версию, а потом через `max-width` «чинить» её для телефона;
- сначала сверстать **телефон**, а потом через `min-width` **добавлять** колонки для широких экранов.

Второй путь называется **mobile first** («сначала мобильные»), и его считают правильным. Почему:

- телефонная версия проще (обычно всё в одну колонку), её CSS короткий;
- на большой экран мы только **добавляем** возможности, а не ломаем и чиним;
- больше половины людей открывает сайты с телефона.

Частая ошибка: смешивать `min-width` и `max-width` в одном проекте как попало. Правила начинают перекрывать друг друга, и уже не понять, что сработает. Выберите mobile first и пишите только `min-width`.

### Точки перелома

**Точка перелома** (breakpoint) — ширина, на которой раскладка меняется. В этом курсе и на экзамене ориентируемся на три ширины макетов:

| Ширина | Устройство | Что обычно меняется |
|---|---|---|
| 360px | телефон | всё в одну колонку, меню столбиком |
| 768px | планшет | две колонки, меню в строку |
| 1280px | компьютер | три-четыре колонки, боковая колонка |

```css
/* Телефон: базовые стили без медиазапроса */
.catalog { display: grid; grid-template-columns: 1fr; gap: 16px; }

/* Планшет */
@media (min-width: 768px) {
  .catalog { grid-template-columns: repeat(2, 1fr); }
}

/* Компьютер */
@media (min-width: 1280px) {
  .catalog { grid-template-columns: repeat(3, 1fr); }
}
```

Медиазапросы идут по возрастанию: сначала 768, потом 1280. Если поставить их наоборот, более узкое правило окажется ниже и перекроет широкое.

### Перестраиваем области

Вот где пригождаются области: на телефоне — одна колонка, на компьютере — три. Меняем только схему:

```css
.page {
  display: grid;
  gap: 16px;
  grid-template-areas:
    "header"
    "main"
    "aside"
    "footer";
}

@media (min-width: 768px) {
  .page {
    grid-template-columns: 1fr 240px;
    grid-template-areas:
      "header header"
      "main   aside"
      "footer footer";
  }
}
```

HTML при этом не меняется ни на символ.

## Резиновые картинки

Картинка шириной 600px на экране в 360px вылезет за край и даст горизонтальную прокрутку. Лекарство — две строки, которые пишут почти в каждом проекте:

```css
img {
  max-width: 100%;
  height: auto;
}
```

- `max-width: 100%` — картинка **не шире своего родителя**. Если места много, она остаётся своего настоящего размера, если мало — уменьшается.
- `height: auto` — высота меняется вместе с шириной, пропорции сохраняются. Без этой строки картинка с атрибутом `height` сплющится.

```html
<style>
  .box { width: 200px; padding: 8px; border: 2px dashed #8a3b12; }
  .fluid { max-width: 100%; height: auto; }
</style>
<div class="box">
  <img src="img/art.svg" width="600" height="300" alt="Пейзаж, обычная картинка">
</div>
<div class="box">
  <img class="fluid" src="img/art.svg" width="600" height="300" alt="Пейзаж, резиновая картинка">
</div>
```

Что вы увидите: первая картинка вылезла далеко за пунктирную рамку, вторая уменьшилась и аккуратно вписалась.

Частая ошибка: `width: 100%` вместо `max-width: 100%`. Тогда маленькую иконку растянет на всю колонку, и она станет мутной.

## Как проверять адаптивность

В браузере откройте инструменты разработчика (F12 или Ctrl+Shift+I) и нажмите значок телефона с планшетом — **режим устройства**. Сверху появится поле ширины: впишите 360, потом 768, потом 1280 и посмотрите на страницу. Признаки беды:

- внизу появилась горизонтальная полоса прокрутки;
- текст или картинка обрезаны справа;
- кнопки налезли друг на друга.

В заданиях курса сайт сам проверяет страницу на ширине 1024px и 360px. Проверки с пометкой «телефон 360px» — как раз об этом.

> **Попробуйте сами.** Откройте в песочнице пример со схемой областей (`.page` с шапкой, меню и подвалом). Перенесите `grid-template-columns` и `grid-template-areas` внутрь `@media (min-width: 600px) { … }`, а снаружи оставьте только `display: grid`. Меняйте ширину окна предпросмотра и смотрите, как раскладка перестраивается.

## Главное за занятие

- Grid раскладывает элементы сразу по строкам и колонкам: `display: grid` у родителя, колонки — `grid-template-columns`.
- `fr` — доля свободного места; `repeat(3, 1fr)` — три равные колонки.
- `repeat(auto-fit, minmax(200px, 1fr))` — сетка сама решает, сколько колонок поместится.
- `grid-template-areas` рисует схему страницы словами, `grid-area` ставит элемент в область.
- Адаптивность: `meta viewport` в `head`, медиазапросы `@media (min-width: …)`, подход mobile first, точки 360 / 768 / 1280.
- Резиновые картинки: `max-width: 100%; height: auto;`.

## Словарик

- **Grid-контейнер** — элемент с `display: grid`; его прямые дети — grid-элементы.
- **fr** — единица Grid: доля свободного места в сетке.
- **Область (grid area)** — именованный прямоугольник из ячеек сетки.
- **Адаптивная вёрстка** — вёрстка, которая подстраивается под ширину экрана.
- **Медиазапрос** — блок `@media`, правила которого работают только при выполнении условия.
- **Mobile first** — подход, при котором сначала верстают телефон, а широкие экраны добавляют через `min-width`.
- **Точка перелома** — ширина экрана, на которой меняется раскладка.
