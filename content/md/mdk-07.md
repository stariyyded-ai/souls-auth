## Коротко о теории

**Страница-визитка** — одна страница, которая коротко рассказывает о человеке или компании: кто это, что умеет, как связаться. Такие страницы делают фрилансеры, мастера маникюра, репетиторы. Это и первое портфолио начинающего веб-разработчика.

Шпаргалка по тегам, которые понадобятся сегодня:

| Раздел визитки | Теги | Занятие |
|---|---|---|
| Имя | `h1` — один на странице | 1 |
| Фото | `img` с `src`, `alt`, `width`, `height` | 4 |
| Подзаголовки разделов | `h2` | 1 |
| Текст о себе | `p`, `strong`, `em` | 1 |
| Навыки | `ul`, `li`, вложенный `ul` | 5 |
| Расписание | `table`, `caption`, `thead`, `tbody`, `th scope`, `td` | 5 |
| Контакты | `a href="mailto:…"`, `a href="tel:…"`, `target` и `rel` | 3 |
| Подвал | `hr`, `&copy;` | 2, 4 |

Три правила, которые проверяет автопроверка и преподаватель на экзамене:

1. **Заголовки по порядку**: один `h1`, разделы — `h2`, без пропусков уровней.
2. **У картинки есть alt**, который описывает, что на ней.
3. **Теги по смыслу**: список — это список, таблица — только для данных, оформление — в CSS.

## Ход работы

### Шаг 1. Спланируйте страницу

Прежде чем писать код, набросайте на листке **план визитки** сверху вниз. Это маленький макет:

```
┌──────────────────────────────┐
│ ИМЯ ФАМИЛИЯ          (h1)    │
│ [фото]                (img)  │
│ Студент группы …      (p)    │
├──────────────────────────────┤
│ Обо мне               (h2)   │
│ два абзаца            (p, p) │
├──────────────────────────────┤
│ Навыки                (h2)   │
│ • список              (ul)   │
├──────────────────────────────┤
│ Моё расписание        (h2)   │
│ таблица               (table)│
├──────────────────────────────┤
│ Контакты              (h2)   │
│ почта, телефон, сайт  (ul, a)│
│ ─────────            (hr)    │
│ © 2026 Имя            (p)    │
└──────────────────────────────┘
```

Напротив каждого блока подпишите тег, как на схеме. Так вы заранее решите, что будет списком, а что таблицей.

### Шаг 2. Подготовьте текст

Напишите в заметках:

- два-три предложения о себе: где учитесь, чем увлекаетесь, почему выбрали эту профессию;
- 4–6 навыков. Подумайте, какие можно сгруппировать: например, «Программы» → VS Code, Figma;
- своё расписание на неделю: день, пары, кружки или тренировки.

Если не хочется писать о себе, придумайте персонажа: студента-дизайнера, бариста, тренера. Личные данные (настоящий телефон, адрес) на учебной странице писать не нужно: используйте выдуманные `student@example.ru` и `+7 900 000-00-00`.

### Шаг 3. Шапка и «Обо мне» — **задание 1 на сайте**

Откройте задание «Визитка: шапка и обо мне».

1. Напишите `h1` с именем и фамилией.
2. Под ним вставьте фото: `<img src="img/course/k07-avatar.svg" alt="…" width="160" height="160">`. В alt — кто на фото: «Анна Смирнова, студентка колледжа», а не «фото» и не «аватар».
3. Под фото — абзац-подпись: группа или специальность.
4. Раздел `h2` «Обо мне» и два абзаца. Одно важное слово выделите `strong` или `em`.

```html
<h1>Анна Смирнова</h1>
<img src="img/course/k07-avatar.svg" alt="Анна Смирнова, студентка колледжа" width="160" height="160">
<p>Студентка группы ИСП-11, будущий веб-разработчик</p>
```

Что увидите: имя крупным заголовком, под ним круглую картинку-заглушку и строку о группе. Круглой картинку делает CSS — он уже есть в задании.

Частая ошибка: поставить фото выше `h1`. Так можно, но тогда диктор начнёт страницу с картинки, а не с имени. Начинаем с заголовка.

### Шаг 4. Навыки и расписание — **задание 2 на сайте**

Откройте задание «Визитка: навыки и расписание». В шаблоне уже есть результат шага 3 — продолжайте ниже.

1. Раздел `h2` «Навыки» и список `ul` минимум из четырёх пунктов. Один пункт — группа со вложенным списком: «Программы» → VS Code, Figma.
2. Раздел `h2` «Моё расписание» и таблица: `caption`, шапка в `thead` с `th scope="col"`, строки в `tbody`, первая ячейка строки — `th scope="row"` с днём недели.

```html
<tr>
  <th scope="row">Понедельник</th>
  <td>4 пары</td>
  <td>Волейбол, 17:00</td>
</tr>
```

Что увидите: строку таблицы — день недели жирным, дальше пары и кружки.

Частая ошибка: разное число ячеек в строках. Если в шапке три столбца, в каждой строке тоже три ячейки (или меньше, но с `colspan`).

### Шаг 5. Контакты и подвал — **задание 3 на сайте**

Откройте задание «Визитка: контакты и подвал».

1. Раздел `h2` «Контакты» и список `ul` из трёх ссылок: почта (`mailto:`), телефон (`tel:` — только `+` и цифры), страница-портфолио или профиль на внешнем сайте (`target="_blank"` и `rel="noopener"`).
2. Под списком разделитель `hr` и абзац-подвал: `&copy;`, год и имя.

```html
<li><a href="tel:+79000000000">+7 900 000-00-00</a></li>
```

Что увидите: номер телефона ссылкой. На телефоне по нажатию откроется звонилка.

### Шаг 6. Соберите визитку в VS Code и проверьте

1. Создайте папку `vizitka`, внутри — папку `img` и файл `index.html`.
2. Наберите `!` и Tab, поменяйте `lang` на `ru`, `title` — на «Ваше Имя — визитка».
3. Скопируйте в `body` код из задания 3 (в нём уже вся страница).
4. Положите в `img` своё фото или скачайте картинку-заглушку и поправьте путь в `src`.
5. Оформления пока не будет: картинка квадратная, заголовки чёрные. Это нормально — как подключить к странице свой файл стилей, разберём на занятии 12.
6. Запустите Live Server и проверьте страницу в валидаторе W3C. Исправьте ошибки, если есть.

Эта папка понадобится на следующем занятии: из визитки вырастет сайт из нескольких страниц.

## Контрольные вопросы

1. Почему на странице один `h1`, а разделы — `h2`?
2. Как вы написали alt для фото? Что услышит человек с экранным диктором?
3. Зачем у картинки атрибуты `width` и `height`?
4. Где должен стоять вложенный список навыков?
5. Как диктор прочитает ячейку таблицы, если у заголовков есть `scope`?
6. Чем отличаются записи номера в `href="tel:…"` и в тексте ссылки?
