- **Пустое состояние** (занятие 43): если ничего не нашлось, честно говорим об этом и подсказываем, что сделать.

### Шаг 4. Форма-фильтр (задание 1 на сайте)

Каждое поле — в своей обёртке `div.filter-field`, чтобы подпись и поле держались вместе (принцип близости):

```html
<div class="filter-field">
  <label for="q">Название или автор</label>
  <input id="q" name="q" type="search">
</div>
```

Флажок — исключение: подпись **справа** от квадратика, и `label` оборачивает и поле, и текст, чтобы область нажатия была больше:

```html
<div class="filter-field">
  <label class="check"><input id="available" name="available" type="checkbox"> Только в наличии</label>
</div>
```

Раскладка mobile first: на телефоне обёртки идут друг под другом, с 768px — в строку. Это удобно сделать через Flexbox:

```css
.filter { display: flex; flex-direction: column; gap: var(--space-2); }
@media (min-width: 768px) {
  .filter { flex-direction: row; align-items: flex-end; }
}
```

`align-items: flex-end` выравнивает поля и кнопку по нижнему краю: подписи над полями сверху, а сами поля и кнопка — на одной линии.

### Шаг 5. Крошки и сетка карточек (задание 2 на сайте)

Карточки в шаблоне уже есть — с атрибутами `data-genre` и `data-available`. Они понадобятся в шаге 6. Ваша часть: хлебные крошки перед `h1` и стили.

Для сетки, которая сама решает, сколько колонок поместится, используйте `auto-fit` и `minmax` (занятие 22):

```css
.catalog {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: var(--space-3);
}
```

Что это значит: «колонок столько, сколько поместится, каждая не уже 220px». На 1024px поместятся четыре колонки, на 360px — одна. Медиазапрос не нужен.

Бейджи двух видов — два класса-модификатора поверх общего `.badge`:

```css
.badge-yes { background: var(--color-success); color: var(--color-on-primary); }
.badge-no { background: var(--color-surface); color: var(--color-muted); }
```

### Шаг 6. Фильтр на JavaScript (задание 3 на сайте)

Здесь пригодятся две вещи, которых ещё не было.

**`document.querySelectorAll('.book')`** — находит **все** элементы по селектору (а `querySelector` — только первый). Результат — список, который перебирают циклом `for…of`, как массив:

```js
const books = document.querySelectorAll('.book');
for (const book of books) {
  console.log(book.textContent);
}
```

**`book.dataset.genre`** — читает атрибут `data-genre` элемента (data-атрибуты вы встречали на занятии 18). Для `data-available="yes"` это `book.dataset.available`.

Алгоритм фильтра:

1. Слушаем событие `submit` формы и сразу вызываем `event.preventDefault()`, чтобы страница не перезагружалась.
2. Читаем значения: жанр — `genre.value`, флажок — `available.checked` (`true` или `false`), поиск — `q.value.trim().toLowerCase()`.
3. Для каждой книги решаем, подходит ли она: жанр «все» или совпадает с `dataset.genre`; флажок снят или `dataset.available === 'yes'`; текст названия (тоже в нижнем регистре) содержит поисковую строку — это проверяет `title.includes(text)`.
4. Подходящей книге ставим `book.hidden = false`, остальным — `true`, и считаем подходящие.
5. Пишем «Найдено: N» и показываем пустое состояние, если N равно нулю.

Частая ошибка: сравнивать текст без `toLowerCase()`. Тогда поиск «css» не найдёт книгу «HTML и CSS», потому что «css» и «CSS» для компьютера — разные строки.

Ещё одна частая ошибка: если у карточки в CSS стоит `display: flex`, атрибут `hidden` перестаёт её прятать — правило из CSS сильнее. Поэтому в шаблоне есть правило `[hidden] { display: none; }`.
