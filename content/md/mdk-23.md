## Коротко о теории

- **Лендинг** (landing page, «посадочная страница») — одностраничный сайт об одном товаре или услуге. Его задача — подвести человека к одному действию: заказать, записаться, позвонить.
- **Первый экран** — то, что человек видит, не прокручивая страницу. Здесь главный заголовок `h1`, одно-два предложения и **призыв к действию** — кнопка.
- **Flexbox** раскладывает элементы в одну линию: шапка, ряд преимуществ, подвал, содержимое карточки.
- **Grid** раскладывает по строкам и колонкам: каталог, галерея, раскладка страницы.
- Ссылка, которая выглядит как кнопка, остаётся ссылкой `a`, если она ведёт на другую страницу или к якорю. Тег `button` — для действий на странице (отправить форму, открыть окно).
- Цвета макета удобно сразу записать в **CSS-переменные** (вы делали это на занятии про стили сайта): поменяли цвет в одном месте — он поменялся везде.

## Ход работы

### Шаг 0. Читаем макет

Дизайнер прислал макет главной страницы кофейни «Зерно» для компьютера. Вот его схема:

![Схема макета лендинга: шапка, тёмный первый экран с кнопкой, три преимущества в ряд, сетка из шести карточек меню, тёмный подвал](img/course/k23-landing.svg)

Прежде чем писать код, разберите макет по блокам. Это главный навык верстальщика: смотреть на картинку и видеть в ней прямоугольники.

| Блок | Что внутри | Раскладка | HTML-тег |
|---|---|---|---|
| Шапка | логотип, меню из трёх ссылок | Flexbox: края, по центру по высоте | `header`, `nav`, `ul` |
| Первый экран | `h1`, абзац, кнопка | обычный поток, тёмный градиент | `section` |
| Преимущества | три карточки: иконка, заголовок, текст | Flexbox: три в ряд, равной ширины | `section`, `ul` |
| Меню | шесть карточек: фото, название, описание, цена, кнопка | Grid: три колонки | `section`, `article` |
| Подвал | название, адрес, телефон | Flexbox: края | `footer` |

Цвета из стайлгайда дизайнера:

| Переменная | Цвет | Где |
|---|---|---|
| `--coffee` | `#3b2416` | тёмный: текст заголовков, первый экран, подвал |
| `--accent` | `#a4541c` | акцент: кнопки |
| `--cream` | `#fdf6ee` | светлый фон карточек преимуществ |

Размеры: скругление карточек 12px, кнопок 8px; промежутки между карточками 24px; заголовок первого экрана не меньше 40px.

> Обратите внимание: белый текст на `--accent` даёт контраст около 5,4:1 — проходит WCAG AA. Если бы дизайнер выбрал светлее, например `#c8702a`, контраст упал бы до 3,6:1, и верстальщику пришлось бы сказать об этом дизайнеру.

### Шаг 1. Шапка (задание 1)

Откройте задание «Лендинг: шапка и первый экран». HTML шапки уже есть. В шапке два прямых ребёнка — ссылка-логотип и `nav`. Значит, шапка — flex-контейнер:

```css
.header {
  display: flex;
  justify-content: space-between; /* логотип влево, меню вправо */
  align-items: center;            /* по одной линии по высоте */
}
```

Пункты меню — дети `ul.menu`, это второй flex-контейнер: `display: flex; gap: 24px;`. Маркеры и отступы у списка уже убраны.

Проверьте себя: в предпросмотре логотип у левого края, три пункта меню в строку у правого.

### Шаг 2. Первый экран (задание 1)

Внутри `section.hero` напишите заголовок, абзац и кнопку:

```html
<section class="hero">
  <h1>Кофе, который ждёт вас между парами</h1>
  <p>Свежая обжарка, выпечка каждое утро и скидка по студенческому билету.</p>
  <a class="btn" href="#menu">Посмотреть меню</a>
</section>
```

Оформите первый экран: тёмный градиент, белый текст, большие отступы. Градиент — это картинка, поэтому он идёт в `background-image`, а сплошной `background-color` рядом — на случай, если градиент не отрисуется:

```css
.hero {
  padding: 64px 32px;
  border-radius: 16px;
  background-color: #3b2416;
  background-image: linear-gradient(135deg, #3b2416, #6b3d1f);
  color: #ffffff;
}
```

Потом кнопка: `display: inline-block`, отступы, скругление 8px, фон `var(--accent)`, белый текст, без подчёркивания. И плавное наведение: `transition` у `.btn` и правило `.btn:hover` с более тёмным фоном. Нажмите «Проверить» и добейтесь, чтобы все пункты чек-листа стали зелёными.

### Шаг 3. Преимущества на Flexbox (задание 2)

Откройте задание «Лендинг: преимущества на Flexbox». Два преимущества уже размечены, третье — «Есть розетки» — допишите сами, скопировав `li.feature` целиком. Иконки здесь — украшение (рядом есть заголовок), поэтому `alt=""`.

Дальше раскладка:

1. Список `.features__list`: убрать маркеры и отступ слева, `display: flex`, `gap: 24px`.
2. Карточки `.feature`: `flex: 1` — все три одинаковой ширины, сколько бы текста в них ни было.
3. Иконка 48×48px, `display: block` — чтобы под ней не было лишней щели от строки текста.
4. Фон карточки `var(--cream)`, отступы, скругление 12px.

Частая ошибка: написать `display: flex` у `li.feature`. Тогда иконка, заголовок и текст внутри карточки встанут в строку, а сами карточки — всё так же друг под другом.

### Шаг 4. Меню на Grid (задание 3)

Откройте задание «Лендинг: меню на Grid и подвал». Две карточки уже есть, добавьте ещё четыре: Американо 120 ₽, Какао 140 ₽, Чай с чабрецом 90 ₽, Сырник 110 ₽. Не забудьте осмысленный `alt` у каждой картинки: это фото товара, оно несёт смысл.

Сетка — три равные колонки:

```css
.catalog__grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}
```

Карточка: белый фон, скругление 12px, мягкая тень. Картинка — во всю ширину карточки (`width: 100%`), а чтобы её верхние углы тоже скруглились, у карточки `overflow: hidden` — всё, что выходит за скруглённые края, обрезается.

Теперь самое интересное. У «Рафа» описание длинное, у «Капучино» — короткое, и кнопки «В заказ» стоят на разной высоте. Grid уже сделал все карточки в ряду одинаковой высоты, осталось прижать кнопку к низу:

```css
.product {
  display: flex;
  flex-direction: column;
}
.product__body {
  display: flex;
  flex: 1;               /* тело карточки забирает всю высоту под картинкой */
  flex-direction: column;
}
.product__btn {
  margin-top: auto;      /* всё свободное место — над кнопкой */
}
```

Это тот самый приём «карточка с кнопкой внизу» из урока про Flexbox, только в два уровня: карточка → тело → кнопка.

### Шаг 5. Подвал (задание 3)

Подвал — ещё один flex-контейнер: три элемента, крайние прижаты к краям, по центру по высоте. Фон `var(--coffee)`, текст `var(--cream)`. Ссылке на телефон задайте тот же светлый цвет, иначе останется стандартный синий, и сайт подсветит слабый контраст.

### Шаг 6. Собираем страницу в VS Code

Каждое задание на сайте — кусок страницы. Соберите их в один файл:

1. Создайте папку `zerno`, в ней `index.html`, `css/style.css`, папку `img` (положите туда любую картинку для карточек и иконку).
2. В `index.html` — полная структура документа: `<!DOCTYPE html>`, `<html lang="ru">`, в `head` — `meta charset`, `meta viewport`, `title` и `<link rel="stylesheet" href="css/style.css">`.
3. В `body` по порядку: шапка, затем `<main>` с первым экраном, преимуществами и меню, затем подвал.
4. В `style.css` вставьте CSS из трёх заданий. Переменные `:root` и правило `body` оставьте по одному разу, повторы удалите.
5. Откройте страницу через Live Server, проверьте, что все блоки на месте, и покажите преподавателю.

Сохраните папку `zerno`: на следующем занятии вы сделаете эту страницу адаптивной.

Добавьте карточкам меню эффект наведения из урока 20: при наведении карточка приподнимается на 4px (`transform: translateY(-4px)`), а тень становится больше. Не забудьте `transition` у обычного состояния и `@media (prefers-reduced-motion: reduce)`, где переход выключен.
