## Лекция

**От картинки к коду.** У вас есть мобильный макет из модуля 2: пять экранов 390×844 в фирменном стиле заказчика. Первая мысль новичка — открыть экран «Вход» и начать верстать его сверху вниз, потом так же «Регистрацию», потом «Заявки». Через час выясняется, что синий цвет кнопки на трёх страницах получился тремя разными оттенками, отступы гуляют, а шрифт поменять можно только в пяти местах сразу. Профессионалы делают наоборот: сначала **выносят из макета всё общее** — цвета, шрифты, отступы, кнопки, поля, шапку — в один файл стилей, а уже потом собирают из этих деталей страницы, как из конструктора.

**Шаг 1. Инвентаризация макета.** Откройте Figma и выпишите (прямо в комментарий в CSS):

- **цвета**: основной (кнопки, ссылки), акцентный, фон, цвет текста, вторичный текст, цвета статусов («Новая», «В работе», «Выполнена», «Отменена»), цвет ошибки;
- **шрифты**: семейство, размеры заголовков и обычного текста, начертания;
- **отступы**: шаг сетки (у нас 8pt), боковые поля страницы (обычно 16px или 24px);
- **радиусы и тени**: скругления кнопок, полей, карточек;
- **повторяющиеся элементы**: шапка, кнопка, поле ввода, карточка, бейдж статуса.

Где всё это взять: выделите элемент в Figma, справа на панели видны его размеры, цвет заливки, шрифт и скругление. Для блока можно скопировать CSS через контекстное меню (Copy/Paste as → Copy as code → CSS; в разных версиях Figma пункт называется чуть по-разному). Но не вставляйте этот код бездумно: Figma выдаёт абсолютные размеры вроде `width: 358px; height: 48px; position: absolute; left: 16px;`, а нам нужна «резиновая» вёрстка. Берите из него **значения** (цвет, радиус, размер шрифта), а не раскладку.

**Шаг 2. CSS-переменные (custom properties).** Чтобы цвет кнопки жил в одном месте, его кладут в переменную. Переменные объявляют в `:root` (это корень документа, то есть `<html>`), а используют через `var()`:

```css
:root {
  /* Цвета из стайл-гайда */
  --color-primary: #0f766e;       /* бирюзовый — кнопки, шапка */
  --color-primary-dark: #115e59;  /* наведение на кнопку */
  --color-accent: #f59e0b;        /* акцент — 10% по правилу 60-30-10 */
  --color-bg: #f8fafc;            /* фон страницы */
  --color-surface: #ffffff;       /* фон карточек и полей */
  --color-text: #0f172a;
  --color-muted: #64748b;
  --color-border: #cbd5e1;
  --color-error: #dc2626;

  /* Статусы заявок */
  --status-new: #2563eb;
  --status-work: #f59e0b;
  --status-done: #16a34a;
  --status-cancel: #dc2626;

  /* Типографика */
  --font-main: "Inter", system-ui, sans-serif;
  --fs-h1: 1.75rem;   /* 28px */
  --fs-h2: 1.25rem;   /* 20px */
  --fs-body: 1rem;    /* 16px */
  --fs-small: 0.875rem;

  /* Отступы по шагу 8 */
  --space-1: 8px;
  --space-2: 16px;
  --space-3: 24px;
  --space-4: 32px;

  --radius: 12px;
  --shadow: 0 2px 8px rgb(15 23 42 / 0.08);
}

.btn {
  background: var(--color-primary);
  border-radius: var(--radius);
}
```

Если заказчик скажет «сделайте зелёный посветлее», вы меняете одну строку, а не ищете цвет по всем файлам. На экзамене это ещё и прямое доказательство того, что вы выдержали **корпоративный стиль**: все цвета взяты из одного источника.

**Шаг 3. Подключение шрифта.** Если в стайл-гайде шрифт из Google Fonts, подключите его в `<head>` *до* своего CSS:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap" rel="stylesheet">
<link rel="stylesheet" href="css/style.css">
```

Подключайте только нужные начертания (здесь 400, 600, 700): каждое лишнее — это лишние килобайты. И всегда оставляйте запасной шрифт (`system-ui, sans-serif`): если интернета на экзамене нет, страница не развалится. Учтите, что на экзаменационной площадке доступ в интернет может быть ограничен — поэтому полезно уметь скачать шрифт и подключить его локально через `@font-face`.

**Шаг 4. Базовые стили и «компоненты».** После переменных идёт сброс и базовая типографика, затем повторяющиеся элементы. Каждый компонент — это класс, который можно применить на любой странице:

```css
*, *::before, *::after { box-sizing: border-box; }

body {
  margin: 0;
  font-family: var(--font-main);
  font-size: var(--fs-body);
  line-height: 1.5;
  color: var(--color-text);
  background: var(--color-bg);
}

h1, h2, h3 { margin: 0 0 var(--space-2); line-height: 1.2; }
h1 { font-size: var(--fs-h1); }
h2 { font-size: var(--fs-h2); }

img { max-width: 100%; display: block; }

/* Контейнер страницы: на телефоне — поля 16px, на большом экране — по центру */
.page {
  width: 100%;
  max-width: 480px;
  margin: 0 auto;
  padding: var(--space-3) var(--space-2);
}

/* Кнопка */
.btn {
  display: inline-flex;
  justify-content: center;
  align-items: center;
  min-height: 48px;                 /* удобно попасть пальцем */
  padding: 0 var(--space-3);
  border: none;
  border-radius: var(--radius);
  background: var(--color-primary);
  color: #fff;
  font: inherit;
  font-weight: 600;
  text-decoration: none;
  cursor: pointer;
}
.btn:hover { background: var(--color-primary-dark); }
.btn--block { width: 100%; }        /* модификатор: кнопка на всю ширину */
.btn--outline {
  background: transparent;
  color: var(--color-primary);
  border: 2px solid var(--color-primary);
}

/* Карточка */
.card {
  background: var(--color-surface);
  border-radius: var(--radius);
  box-shadow: var(--shadow);
  padding: var(--space-2);
}
```

Заметьте запись `.btn--block`. Это приём именования в духе БЭМ: базовый класс `.btn` описывает кнопку, а модификатор через двойной дефис — её вариант. В разметке пишем оба: `<button class="btn btn--block">Войти</button>`. Так стили не дублируются.

**Шаг 5. Шаблон страницы.** Все страницы портала, кроме входа и регистрации, имеют одинаковые шапку и подвал. Сделаем файл-шаблон `_template.html` и будем копировать его при создании новой страницы:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Название страницы — ЧистоДом</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <header class="header">
    <a href="requests.html" class="header__logo">
      <img src="img/logo.svg" alt="ЧистоДом" width="120" height="32">
    </a>
    <nav class="header__nav">
      <a href="new-request.html">Новая заявка</a>
      <a href="index.html">Выход</a>
    </nav>
  </header>

  <main class="page">
    <h1>Заголовок</h1>
    <!-- содержимое страницы -->
  </main>
</body>
</html>
```

Копировать шапку руками в пять файлов — временное решение. В модуле 5 вы вынесете её в `header.php` и будете подключать через `include`, а сейчас главное, чтобы разметка шапки была одинаковой везде.

**Шаг 6. Сверка с макетом.** Готовую страницу сравнивают с макетом в одинаковом размере. В DevTools включите режим устройства, задайте 390×844 (или выберите iPhone 12 Pro), сделайте скриншот (меню «три точки» в панели устройства → Capture screenshot) и положите рядом с PNG из Figma. Ищите расхождения: цвет, размер шрифта, отступ, скругление. Идеальное совпадение до пикселя не требуется, но эксперт должен узнать ваш макет с первого взгляда.

**Типичные ошибки:**

1. Стили в атрибутах `style="..."` прямо в HTML. Повторить их на другой странице невозможно, поменять — мучение.
2. Скопировали из Figma `position: absolute` с координатами — на другой ширине экрана всё «поехало».
3. Цвета вписаны напрямую (`#0f766e`) в двадцать мест вместо переменной.
4. Фиксированная ширина `width: 390px` у контейнера. Телефоны бывают 360, 375, 412px — используйте `width: 100%` и `max-width`.
5. Картинки без `alt` и без `max-width: 100%`.
6. Шапка на каждой странице свёрстана по-своему — эксперт сразу видит несогласованность.

**Связь с экзаменом.** Аспект «интеграция дизайна» проверяет, что страницы приложения соответствуют макету. Если ваш `style.css` построен на переменных из стайл-гайда, интеграция сводится к аккуратной сборке страниц из готовых деталей — это экономит десятки минут из 210 экзаменационных.

## Критерии оценки

| Аспект | 2 балла | 1 балл | 0 баллов |
|---|---|---|---|
| CSS-переменные | все цвета, шрифты, отступы из стайл-гайда в `:root`, в правилах только `var()` | переменные есть, но часть значений вписана напрямую | переменных нет |
| Соответствие стилю | цвета, шрифт, радиусы совпадают с макетом | 1–2 заметных расхождения | стиль не узнаётся |
| Компоненты | кнопка с модификаторами, карточка, шапка переиспользуемы | есть не все компоненты | стили в атрибутах style |
| Шаблон страницы | viewport, lang, подключение CSS и шрифта, семантическая шапка | один из элементов отсутствует | шаблона нет |
| Резиновость | нет фиксированной ширины 390px, нет горизонтальной прокрутки | есть мелкие переполнения | вёрстка абсолютными координатами |

## Если не успел / для сильных

**Минимум:** `style.css` с переменными цветов и шрифта, кнопка `.btn` и `_template.html` с шапкой.
**Усложнение:** добавьте тёмную тему через `@media (prefers-color-scheme: dark)`, переопределив только значения переменных в `:root`.
