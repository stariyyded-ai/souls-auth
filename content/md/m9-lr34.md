**Шаг 1. Дизайн-токены в CSS-переменных.** Самый надёжный способ не расползтись — вынести цвета, шрифты, радиусы и отступы из стайл-гайда (ЛР6) в переменные. Тогда цвет кнопки задаётся в одном месте, а не в двадцати.

```css
/* css/tokens.css — значения возьми из своего стайл-гайда в Figma */
:root {
  --color-primary: #2f6fed;
  --color-primary-dark: #1f4fb8;
  --color-text: #1d1f24;
  --color-muted: #6b7280;
  --color-bg: #f6f7fb;
  --color-danger: #d33a3a;
  --color-success: #1f9d55;
  --color-warning: #d98b00;

  --font-main: 'Inter', system-ui, sans-serif;
  --radius: 12px;
  --space-1: 8px;   /* шаг 8pt из ПР7 */
  --space-2: 16px;
  --space-3: 24px;
}

body { font-family: var(--font-main); color: var(--color-text); background: var(--color-bg); }
.btn-main { background: var(--color-primary); border-radius: var(--radius); padding: var(--space-1) var(--space-2); }
.btn-main:hover { background: var(--color-primary-dark); }
```

Если используешь Bootstrap 5, его можно перекрасить теми же переменными: `--bs-primary`, `--bs-body-font-family`, `--bs-border-radius` задаются в `:root` после подключения bootstrap.css. Bootstrap 5.3 читает многие цвета из CSS-переменных, но кнопки — из своих: `.btn-primary { --bs-btn-bg: var(--color-primary); --bs-btn-border-color: var(--color-primary); }`.

Как достать точные значения из Figma: выдели элемент → правая панель (Inspect / Dev Mode) показывает цвет в HEX, шрифт, размер, межстрочный, отступы auto layout. Не угадывай — копируй.

**Шаг 2. Проверка в мобильном размере.** Макет у тебя 390×844. В DevTools нажми Ctrl+Shift+M (Device toolbar) и выставь ширину 390, высоту 844. Теперь страница выглядит так, как на экране из макета. Без этого шага сверка бессмысленна: на широком мониторе всё растягивается иначе.

**Шаг 3. Наложение макета поверх страницы (pixel-perfect оверлей на JS).** Профессиональные верстальщики сравнивают не «на глаз», а накладывая полупрозрачную картинку макета прямо на страницу. Сделаем это на чистом JS — десяток строк. Экспортируй из Figma каждый экран в PNG 1x (390 px шириной) в папку `mockups/` с именами как у страниц: `register.png`, `login.png` и т.д.

```js
// js/overlay.js — подключать ТОЛЬКО при разработке, перед сдачей убрать
(() => {
  const page = location.pathname.split('/').pop().replace('.php', '') || 'index';
  const img = document.createElement('img');
  img.src = `mockups/${page}.png`;
  img.alt = '';
  Object.assign(img.style, {
    position: 'absolute', top: '0', left: '0', width: '390px',
    opacity: '0.5', pointerEvents: 'none', zIndex: '9999', display: 'none',
  });
  document.body.append(img);

  document.addEventListener('keydown', (e) => {
    if (!e.altKey) return;
    if (e.code === 'KeyO') img.style.display = img.style.display === 'none' ? 'block' : 'none';
    if (e.code === 'ArrowUp')   img.style.opacity = Math.min(1, +img.style.opacity + 0.1).toFixed(1);
    if (e.code === 'ArrowDown') img.style.opacity = Math.max(0, +img.style.opacity - 0.1).toFixed(1);
  });
})();
```

Alt+O включает/выключает макет, Alt+↑/↓ меняют прозрачность. `pointer-events: none` — чтобы картинка не мешала кликать по форме. Обрати внимание на `e.code`: он не зависит от раскладки, с русской раскладкой `e.key` вернул бы «щ», а не «o».

Что ищем при наложении: сдвинутые заголовки (неверный margin), разную высоту полей ввода, другой размер шрифта, лишние или недостающие элементы.

**Шаг 4. Единый вид статусов.** В макете (ЛР7, ЛР9) ты рисовал бейджи статусов. В коде статусы хранятся как `new`, `in_work`, `done`, `cancelled` — пользователю нельзя показывать эти слова. Удобно держать соответствие в одном месте. На PHP это делается при выводе, но если интерфейс что-то перерисовывает на JS (а в ЛР36 будет именно так), нужна такая же таблица и в JS:

```js
// js/statuses.js
const STATUS = {
  new:       { text: 'Новая',     cls: 'badge-new' },
  in_work:   { text: 'В работе',  cls: 'badge-work' },
  done:      { text: 'Выполнена', cls: 'badge-done' },
  cancelled: { text: 'Отменена',  cls: 'badge-cancel' },
};

function renderBadge(el, status) {
  const s = STATUS[status] ?? { text: status, cls: '' };
  el.textContent = s.text;
  el.className = `badge ${s.cls}`;
}
```

```css
.badge-new    { background: var(--color-primary); color: #fff; }
.badge-work   { background: var(--color-warning); color: #fff; }
.badge-done   { background: var(--color-success); color: #fff; }
.badge-cancel { background: var(--color-muted);   color: #fff; }
```

Оператор `??` подставит запасное значение, если статуса нет в таблице, — интерфейс не упадёт.

**Шаг 5. Подсветка текущего пункта меню.** Мелочь, которую эксперт замечает сразу: в макете активная вкладка выделена, а в коде нет. Чтобы не писать условие в каждом PHP-файле, сделаем это на JS в общем `header`:

```js
// js/nav.js
const current = location.pathname.split('/').pop() || 'index.php';
document.querySelectorAll('nav a').forEach((link) => {
  const target = link.getAttribute('href').split('/').pop();
  if (target === current) {
    link.classList.add('active');
    link.setAttribute('aria-current', 'page');
  }
});
```
