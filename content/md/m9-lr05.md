## Лекция

**Почему Figma.** Figma — это редактор интерфейсов, который работает прямо в браузере (есть и приложение для Windows/macOS). В нём рисуют дизайн почти все продуктовые команды, а на демоэкзамене это самый удобный инструмент для задания по дизайну: быстро, есть готовые размеры экранов, экспорт в PNG в два клика. Сегодня мы освоим четыре кита Figma: фреймы, слои, auto layout и компоненты. Без них любой макет превращается в мучение, с ними правка на 5 экранах занимает минуту.

**Интерфейс за 2 минуты.** Слева — панель слоёв (Layers) и страниц (Pages). В центре — холст (canvas), бесконечное поле. Справа — панель свойств (Design): размеры, цвет, шрифт, отступы, эффекты. Сверху — инструменты. Масштаб: `Ctrl + колесо` или `Shift+1` (показать всё), `Shift+2` (показать выделенное).

Полезные горячие клавиши:

```
F или A      — Frame (фрейм)
R            — прямоугольник, O — эллипс
T            — текст
Shift+A      — добавить auto layout
Ctrl+Alt+K   — создать компонент (на Mac Cmd+Option+K)
Ctrl+G       — группа, Ctrl+Shift+G — разгруппировать
Ctrl+D       — дублировать
Alt + наведение — показать расстояния между объектами
Ctrl+R       — переименовать слой
```

**Фрейм (Frame)** — это «экран» или «контейнер». Отличие от группы: у фрейма есть свои размеры, фон, скругление, обрезка содержимого, и только фрейм может иметь auto layout и сетку. Нажмите `F`, справа появится список готовых размеров. В разделе Phone выберите **iPhone 13/14** — это ровно **390×844**, размер с экзамена. Если пресет называется иначе в вашей версии, просто введите W = 390, H = 844 вручную.

Внутри экрана тоже используем фреймы, а не группы: карточка, форма, шапка — всё фреймы. Правило: группа (`Ctrl+G`) — для временного объединения, фрейм — для всего, что является блоком интерфейса.

**Слои и именование.** Каждый объект — слой в панели слева. Новички оставляют имена вида `Rectangle 47`, `Frame 112`, `Group 9`. Через час работы найти что-то невозможно. Называйте слои по смыслу: `header`, `form`, `input-login`, `btn-primary`. Это пригодится и в модуле 3: имена слоёв почти готовые имена CSS-классов. Экраны называйте так, как будут называться PNG при сдаче: `01-registration`, `02-login`, `03-my-requests`.

**Ограничения (Constraints)** говорят, как элемент ведёт себя при изменении размера родителя: прилипает к левому краю, к правому, растягивается. Для мобильного макета чаще всего нужно: шапка `Left & Right` + `Top`, нижняя панель `Left & Right` + `Bottom`.

**Auto layout — главная суперсила.** Представьте кнопку: текст «Войти» и прямоугольник под ним. Если поменять текст на «Зарегистрироваться», прямоугольник придётся растягивать руками. С auto layout кнопка сама подстраивается под текст, как блок в CSS с `padding`.

Выделите текст и нажмите `Shift+A`. Figma обернёт его во фрейм с auto layout. Справа появятся настройки:

- **Направление:** вертикально (элементы друг под другом) или горизонтально (в ряд). Есть и режим Wrap — перенос строк.
- **Gap (промежуток между элементами)** — расстояние между детьми, например 16.
- **Padding** — внутренние отступы, например 12 сверху/снизу и 24 по бокам.
- **Выравнивание** — сетка 3×3: слева/по центру/справа, сверху/по центру/снизу.
- **Размеры:** у каждого элемента режим ширины и высоты — **Fixed** (фиксированная), **Hug contents** (обнимать содержимое), **Fill container** (заполнить родителя).

Если вы знаете CSS, auto layout — это почти Flexbox:

```css
.button {                 /* фрейм с auto layout */
  display: flex;          /* auto layout */
  flex-direction: row;    /* горизонтальное направление */
  gap: 8px;               /* Gap: иконка и текст */
  padding: 12px 24px;     /* Padding */
  align-items: center;    /* выравнивание по центру */
}
.form { display: flex; flex-direction: column; gap: 16px; }
.input { width: 100%; }   /* Fill container */
```

Типичная структура экрана формы в Figma:

```
01-login (Frame 390×844, auto layout vertical, padding 24 16, gap 24)
├── header (Hug)
│   ├── title "Вход" 28/Bold
│   └── subtitle "Войдите, чтобы оформить заявку"
├── form (Fill × Hug, vertical, gap 16)
│   ├── input-login (Fill)
│   └── input-password (Fill)
├── btn-primary "Войти" (Fill, height 48)
└── link "Нет аккаунта? Зарегистрируйтесь"
```

Добавили новое поле — всё ниже само сдвинулось. Удалили подзаголовок — экран сам «схлопнулся». Именно это экономит время на экзамене.

**Компоненты (Components).** Компонент — это «шаблон» элемента. Делаете одну кнопку, жмёте `Ctrl+Alt+K` — она становится главным компонентом (значок из четырёх ромбиков, фиолетовая рамка). Копии компонента называются **экземплярами (instances)**. Поменяли цвет в главном компоненте — поменялись все кнопки на всех экранах. В экземпляре можно менять текст, но стиль остаётся общим. Это и есть единство стиля, которое оценивает эксперт.

Готовые компоненты лежат в панели **Assets** (слева, вкладка рядом с Layers): оттуда их перетаскивают на экран. Главные компоненты принято держать на отдельной странице `UI-kit` или в отдельном фрейме сбоку.

**Свойства компонентов и варианты (Variants).** У кнопки бывают состояния: обычная, наведение, нажата, неактивна. Вместо четырёх разных компонентов делают один набор вариантов: выделяете компонент, жмёте **Add variant** (плюсик) в панели справа — Figma создаёт набор (component set) с пунктирной рамкой. Каждому варианту задаёте значение свойства, например `State = Default / Disabled`. В экземпляре вариант переключается из выпадающего списка. Кроме вариантов, есть **component properties**: текстовое свойство (менять надпись), boolean (показать/скрыть иконку), instance swap (заменить иконку). Подробно варианты будем делать в ЛР7, сегодня — первый простой компонент.

**Экспорт.** Выделите фрейм экрана, в правой панели внизу раздел **Export**, нажмите `+`, выберите PNG и масштаб `1x` (получится 390×844) или `2x` (780×1688, четче на ретина-экранах). На экзамене сдаётся PNG каждой страницы, поэтому заранее называйте фреймы правильно: имя файла возьмётся из имени фрейма.

**Типичные ошибки:**

- Рисуют экран прямо на холсте без фрейма. Тогда нечего экспортировать.
- Используют группы вместо фреймов и двигают всё руками; потом один сдвиг ломает весь экран.
- Делают кнопку из прямоугольника и текста, которые лежат рядом, а не во фрейме с auto layout.
- Копируют кнопку `Ctrl+C/Ctrl+V` 20 раз вместо экземпляров компонента; при правке цвета приходится перекрашивать 20 штук.
- Режим Fixed у поля вместо Fill container: поле не растягивается по ширине формы.
- Отсоединяют экземпляр (Detach instance) «чтобы поправить» и теряют связь с компонентом.

**Связь с экзаменом.** На экзамене время ограничено, а экранов 5–7. Если вы умеете за 10 минут собрать каркас экрана на auto layout из готовых компонентов, остальные экраны собираются копированием и правкой. Единые компоненты — это и есть «дизайн-концепция»: одинаковые кнопки, поля и отступы на всех страницах.

## Задание

**Цель:** создать файл проекта в Figma, освоить фреймы, auto layout и компоненты; собрать каркас первого экрана своего портала.

**Исходные данные:** ваш вариант портала заявок (выдан преподавателем) и карта сайта из ЛР4. Пример для образца — портал клининговой компании «ЧистоДом»: пользователь регистрируется, входит, создаёт заявку на уборку и смотрит статусы; администратор меняет статусы.

**Ход работы:**
1. Зарегистрируйтесь или войдите в Figma, создайте файл `Портал-<вариант>-<Фамилия>`.
2. Создайте страницы: `UI-kit`, `Screens`, `Черновики`.
3. На странице `Screens` создайте фрейм 390×844 (пресет iPhone 13/14), назовите `02-login`.
4. Внутри фрейма создайте заголовок «Вход» (28 px, жирный) и подзаголовок (16 px).
5. Нарисуйте поле ввода: прямоугольник 48 px высотой со скруглением 8 и текстом-подсказкой. Оберните в auto layout (`Shift+A`), задайте padding 12/16, ширину Fill.
6. Сделайте кнопку «Войти» на auto layout: padding 12/24, высота 48, скругление 8, текст по центру. Превратите кнопку в компонент (`Ctrl+Alt+K`), назовите `Button/Primary`, перенесите главный компонент на страницу `UI-kit`.
7. Сделайте компонент поля `Input` и перенесите на `UI-kit`.
8. Соберите экран входа из экземпляров: заголовок, два поля, кнопка, ссылка «Регистрация». Корневой фрейм экрана тоже переведите в вертикальный auto layout с padding 24/16 и gap 16.
9. Проверка «живучести»: поменяйте текст одной кнопки на «Зарегистрироваться» — кнопка должна вырасти сама. Поменяйте цвет главного компонента — цвет должен смениться на экране.
10. Продублируйте экран (`Ctrl+D`), переименуйте в `01-registration`, добавьте поля ФИО, телефон, email.
11. Назовите все слои по смыслу. Экспортируйте `02-login` в PNG 1x.

**Что сдать:** ссылку на файл Figma (доступ «может просматривать») и PNG экрана входа 390×844.

## Критерии оценки

| Аспект | 2 балла | 1 балл | 0 баллов |
|---|---|---|---|
| Фреймы экранов | 390×844, названы по схеме, 2 экрана | размер верный, имена не по схеме | неверный размер или нет фреймов |
| Auto layout | кнопка, поле и экран на auto layout, Fill/Hug выставлены верно | auto layout только у кнопки | нет auto layout |
| Компоненты | Button и Input — компоненты на странице UI-kit, на экране экземпляры | компонент есть, но экраны собраны из копий | нет компонентов |
| Слои | все слои названы по смыслу | частично | Rectangle 47, Frame 112 |
| Экспорт | PNG 390×844 (или 2x) с верным именем | PNG с ошибкой размера/имени | нет файла |
