## Коротко о теории

**Типографика** — то, как оформлен текст: шрифт, размер, интервалы, ширина строки. От неё зависит, дочитают ли статью до конца.

Пять правил удобного текста:

1. **Размер основного текста** — 16–18px. Меньше читать тяжело, особенно с телефона.
2. **Межстрочный интервал** (`line-height`) — 1.4–1.6 для основного текста. Пишите число без единиц: `line-height: 1.6`. Тогда интервал считается от размера шрифта каждого элемента. У крупных заголовков интервал меньше — 1.1–1.3.
3. **Длина строки** — 50–75 знаков. Слишком длинную строку глаз теряет при переходе на следующую. Поэтому у статьи ограничивают ширину: `max-width: 680px` и ставят её по центру через `margin: 0 auto`.
4. **Иерархия**: заголовок заметно крупнее подзаголовка, подзаголовок — крупнее текста. Отступ над подзаголовком больше, чем под ним: так подзаголовок «прилипает» к своему разделу.
5. **Контраст** текста и фона — не ниже 4,5:1 для обычного текста и 3:1 для крупного (от 24px или от 19px жирным). Это требование стандарта доступности **WCAG** уровня AA.

**Шрифтовой стек** — список шрифтов через запятую. Браузер берёт первый, который есть на компьютере. В конце всегда пишут общее семейство: `serif` (с засечками) или `sans-serif` (без засечек).

```css
h1, h2 { font-family: Georgia, "Times New Roman", serif; }
body { font-family: Arial, sans-serif; }
```

Название из нескольких слов берут в кавычки: `"Times New Roman"`.

Пример страницы, где всё это уже работает:

```html
<style>
  body { margin: 0; padding: 24px; font-family: Arial, sans-serif; font-size: 18px; line-height: 1.6; color: #222222; }
  .article { max-width: 680px; margin: 0 auto; }
  h1 { font-family: Georgia, "Times New Roman", serif; font-size: 36px; line-height: 1.2; margin: 0 0 16px; color: #1f4e79; }
  p { margin: 0 0 16px; }
  a { color: #1f4e79; }
  a:hover { color: #222222; }
</style>
<article class="article">
  <h1>Как готовиться к сессии</h1>
  <p>Выпишите все экзамены с датами и разделите темы на дни. Последний день оставьте для повторения.</p>
  <p>Подробный план — в статье <a href="#plan">«Календарь сессии»</a>.</p>
</article>
```

Что увидите: узкая колонка текста по центру, крупный синий заголовок с засечками, спокойный читаемый текст и подчёркнутая ссылка.

> **Попробуйте сами.** В примере выше поменяйте `line-height: 1.6` на `1` и посмотрите, как слипаются строки. Потом уберите `max-width` у `.article` и растяните окно: строки станут слишком длинными.

**Как проверить контраст.** На сайте курса контраст проверяется автоматически: в чек-листе задания есть строка «Контраст текста по WCAG AA». Дома можно открыть инструменты разработчика в браузере (F12), выбрать элемент и навести на цвет — Chrome показывает коэффициент контраста. Ориентиры: `#595959` на белом — 7:1, `#767676` на белом — ровно 4,5:1, а светло-серый `#aaaaaa` на белом — всего 2,3:1, этого мало.

## Ход работы

### Задание 1. Типографика статьи (задание на сайте k1501)

**Шаг 1.** Дома: создайте папку `article`, в ней файл `index.html` и папку `css` с файлом `style.css`. В `<head>` подключите стили: `<link rel="stylesheet" href="css/style.css">`. Вставьте в `<body>` текст статьи из задания k1501. На сайте этот шаг уже сделан — откройте задание k1501.

**Шаг 2.** Задайте основной текст в `body`: размер 18px и межстрочный интервал 1.6. Обратите внимание: в CSS уже есть правило `body` — допишите свойства в него, а не создавайте второе. Два правила для одного селектора проверка посчитает ошибкой: так их легко потерять.

```css
body { margin: 0; padding: 24px; font-family: Arial, sans-serif; font-size: 18px; line-height: 1.6; color: #222222; background: #ffffff; }
```

**Шаг 3.** Ограничьте ширину статьи: `.article { max-width: 680px; margin: 0 auto; }`. Проверьте в предпросмотре: колонка встала по центру.

**Шаг 4.** Оформите заголовки и абзацы:

- `h1, h2` — шрифтовой стек `Georgia, "Times New Roman", serif` (одно правило для двух селекторов);
- `.article__title` — 36px, `line-height: 1.2`, `margin: 0 0 16px`;
- `h2` — 26px, `margin: 32px 0 12px`;
- `p` — `margin: 0 0 16px`;
- `.article__lead` (вводный абзац) — 22px, цвет `#444444`.

Нажмите «Проверить». Все пункты чек-листа должны стать зелёными.

### Задание 2. Цвета с контрастом и ссылки (задание на сайте k1502)

**Шаг 5.** Откройте задание k1502. Посмотрите на предпросмотр: светло-голубой заголовок, бледная подпись и жёлтый текст на жёлтом. Нажмите «Проверить» и найдите в чек-листе строку про контраст — она покажет, какой текст не проходит.

**Шаг 6.** Соберите палитру в переменных — в начале CSS, после правила `body`:

```css
:root {
  --color-text: #222222;
  --color-brand: #1f4e79;
  --color-muted: #595959;
  --color-note-bg: #fff4cc;
}
```

Замените цвета в правилах на `var(…)`: заголовок и ссылки — `--color-brand`, подпись `.article__meta` — `--color-muted`, заметка — фон `--color-note-bg` и текст `--color-text`.

**Шаг 7.** Ссылки. Верните подчёркивание: `text-decoration: underline`. Ссылку в тексте нельзя отличать только цветом. Добавьте два состояния:

```css
.article a:hover { color: var(--color-text); }
.article a:focus-visible { outline: 3px solid #f2a541; }
```

Проверьте с клавиатуры: щёлкните по предпросмотру и нажимайте Tab — рамка фокуса должна переходить от ссылки к ссылке.

### Задание 3. Цитата, списки и пометки (задание на сайте k1503)

**Шаг 8.** Откройте задание k1503. Оформите цитату `.quote`: отступы `margin: 24px 0`, внутренние `padding: 16px 24px`, полоса слева `border-left: 4px solid #1f4e79`, фон `#eef3f8`, курсив и размер 20px. Подпись `cite` поставьте на отдельную строку (`display: block`), уберите курсив (`font-style: normal`), размер 16px, цвет `#595959`.

**Шаг 9.** Списки: у обоих (`.tips` и `.steps`) — `padding-left: 24px`; у каждого `li` — `margin-bottom: 8px`, чтобы пункты не слипались. Маркированному списку `.tips` задайте квадратные маркеры: `list-style-type: square`.

**Шаг 10.** Пометка `mark`: фон `#ffe58f` и небольшие поля `padding: 0 4px`. Проверьте задание и покажите преподавателю все три задания.

**Дома (по желанию).** Соберите все три части в одном файле `style.css` для одной статьи и откройте страницу в браузере. Покажите преподавателю на следующем занятии.
