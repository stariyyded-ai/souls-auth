Регулярные выражения для этого варианта (держите под рукой, но попробуйте сначала написать сами):

const rules = {

Обратите внимание на госномер: в нём используются только 12 кириллических букв, совпадающих по написанию с латинскими. Если пользователь вводит строчными — приведите к верхнему регистру через `value.toUpperCase()` до проверки, это тоже плюс к удобству.

Маску телефона проще всего сделать «от цифр»: на каждое событие `input` вытаскиваем из поля все цифры, отбрасываем первую семёрку и собираем строку заново.

```js
phone.addEventListener('input', () => {
  let d = phone.value.replace(/\D/g, '');
  if (d.startsWith('7') || d.startsWith('8')) d = d.slice(1);
  d = d.slice(0, 10);
  let r = '+7';
  if (d.length > 0) r += '(' + d.slice(0, 3);
  if (d.length >= 3) r += ')';
  if (d.length > 3) r += '-' + d.slice(3, 6);
  if (d.length > 6) r += '-' + d.slice(6, 8);
  if (d.length > 8) r += '-' + d.slice(8, 10);
  phone.value = r;
});
```

Для поочерёдного появления карточек достаточно одного правила `@keyframes` и задержки, которую задаёт JS через CSS-переменную:

```css
.card { animation: rise .35s ease-out both; animation-delay: calc(var(--i) * 80ms); }
@keyframes rise { from { opacity: 0; transform: translateY(16px); } to { opacity: 1; transform: none; } }
@media (prefers-reduced-motion: reduce) { .card { animation: none; } }
```

```js
document.querySelectorAll('.card').forEach((c, i) => c.style.setProperty('--i', i));
```

Это готовые решения из ЛР33 и ЛР35. На экзамене вы будете писать их по памяти, поэтому на пробнике честно попробуйте сначала без подсказки и только потом сверьтесь.

**Как проходит разбор.** После сдачи эксперты (преподаватель и, если так решено, студенты-эксперты из другой подгруппы) проверяют работы по таблице аспектов. Разбор — это не «раздача оценок», а работа с тремя вопросами:

1. **Где я потерял баллы?** Каждый получает свою заполненную таблицу: аспект, оценка 2/1/0, комментарий эксперта («нет причины отмены у клиента», «фрейм 375×812»).
2. **Почему?** Здесь поможет «лист времени» из ЛР39. Сравните план и факт: потеря баллов от незнания («не помню, как сделать хеш») лечится повторением, потеря от времени («35 минут искал опечатку») — тренировкой и правилом «10 минут», потеря от невнимательности («не прочитал про причину отмены») — чек-листом.
3. **Что я делаю до экзамена?** Каждый уходит с личным планом из 3–5 конкретных действий.

**Классификация потерь.** На разборе каждую потерю отнесите к одному из типов — так видно, что именно тренировать:

| Тип | Пример | Как лечить |
|---|---|---|
| Не знаю | Не смог сделать маску телефона | Повторить ЛР33, написать маску 3 раза с нуля |
| Не успел | Админка не начата | Хронометраж, контрольные точки, упрощения |
| Невнимательность | Причина отмены не видна клиенту | Чтение ТЗ с выпиской, финальный прогон сценария |
| Сломал | Сайт не открывается после правки | Копировать рабочую версию в папку сдачи после каждого шага |
| Не сдал | PNG не экспортированы, нет дампа | Последние 5 минут — только сдача |

**Самопроверка и взаимопроверка.** Перед экспертной проверкой каждый сначала оценивает свою работу сам по той же таблице, а потом сравнивает с оценкой эксперта. Расхождение больше 10 баллов — тревожный сигнал: вы плохо видите собственные ошибки, значит, на экзамене финальная проверка особенно важна. Во взаимопроверке вы проверяете работу соседа как эксперт: идёте по аспектам, делаете действие, ставите 2/1/0 с комментарием. Это лучший способ понять, как думает эксперт, и запомнить все аспекты.

**Как ставится 1 балл, а когда 0.** Типичная логика для аспектов этого варианта:

- 2 — требование выполнено полностью и проверяется с первого раза;
- 1 — выполнено частично: работает, но есть отклонение (нет одного поля, валидация не всех полей, анимация есть, но только на одном экране, макеты 4 страниц из 5);
- 0 — не выполнено, не работает или не найдено в папке сдачи.

Спорные случаи эксперты решают по тексту ТЗ. Поэтому дословное следование ТЗ (тексты сообщений, формат телефона, логин админа) — самый дешёвый способ не терять баллы.

**После разбора.** Сохраните свою заполненную таблицу оценки — это стартовая точка.
