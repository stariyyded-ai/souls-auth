**Скелет валидации — пишем по памяти за 10 минут.** Ниже — сжатая версия ЛР33, которую стоит выучить «руками». Повтори её дома 3–4 раза на чистом листе, пока не будешь писать без подсказок.

```js
// js/validation.js — минимальный экзаменационный вариант
const rules = {
  fio:   [/^[А-ЯЁа-яё]+(?:[ -][А-ЯЁа-яё]+)*$/, 'ФИО — только кириллица'],
  phone: [/^\+7\(\d{3}\)-\d{3}-\d{2}-\d{2}$/,  'Формат: +7(XXX)-XXX-XX-XX'],
  email: [/^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/,     'Некорректный email'],
  login: [/^.{6,}$/,                            'Логин — не менее 6 символов'],
};

function check(input) {
  const rule = rules[input.name];
  if (!rule) return true;
  const ok = rule[0].test(input.value.trim());
  input.classList.toggle('is-invalid', !ok);
  const box = document.getElementById(input.name + '-error');
  if (box) box.textContent = ok ? '' : rule[1];
  return ok;
}

const form = document.querySelector('form');
form?.setAttribute('novalidate', '');
form?.addEventListener('focusout', (e) => e.target.name && check(e.target));
form?.addEventListener('submit', (e) => {
  const allOk = [...form.elements].map(check).every(Boolean);
  if (!allOk) e.preventDefault();
});

// маска телефона
document.querySelector('[name="phone"]')?.addEventListener('input', (e) => {
  let d = e.target.value.replace(/\D/g, '');
  if (/^[78]/.test(d)) d = d.slice(1);
  d = d.slice(0, 10);
  e.target.value = !d ? '' : '+7(' + d.slice(0, 3)
    + (d.length > 3 ? ')-' + d.slice(3, 6) : '')
    + (d.length > 6 ? '-' + d.slice(6, 8) : '')
    + (d.length > 8 ? '-' + d.slice(8, 10) : '');
});
```

Здесь `/^.{6,}$/` — логин «любые 6 и больше символов», как в формулировке требования. Если в ТЗ твоего варианта дополнительно указан набор символов (например, латиница) — замени шаблон. `[...form.elements].map(check).every(Boolean)` — проверяем *все* поля (map), потом смотрим, все ли `true` (every).

И серверная часть в `register.php` — те же шаблоны (обрати внимание на флаг `u`):

```php
$errors = [];
if (mb_strlen($login) < 6) $errors['login'] = 'Логин — не менее 6 символов';
if (!preg_match('/^[А-ЯЁа-яё]+(?:[ -][А-ЯЁа-яё]+)*$/u', $fio)) $errors['fio'] = 'ФИО — только кириллица';
if (!preg_match('/^\+7\(\d{3}\)-\d{3}-\d{2}-\d{2}$/', $phone)) $errors['phone'] = 'Формат: +7(XXX)-XXX-XX-XX';
if (!filter_var($email, FILTER_VALIDATE_EMAIL)) $errors['email'] = 'Некорректный email';
```

`filter_var(..., FILTER_VALIDATE_EMAIL)` — встроенная в PHP проверка email, она строже нашей регулярки, и это нормально: сервер — последняя линия обороны.

**Скелет анимации — 7 минут.** Если в проекте ещё нет ЛР35, минимально достаточно уведомления и hover. Самое быстрое и наглядное:

```css
.card { transition: transform .2s ease-out, box-shadow .2s ease-out; }
.card:hover { transform: translateY(-3px); box-shadow: 0 8px 20px rgb(0 0 0 / .1); }

.alert { animation: slide-in .3s ease-out; }    /* сообщения об ошибках/успехе из PHP */
@keyframes slide-in { from { opacity: 0; transform: translateY(-8px); } }

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: .01ms !important; transition-duration: .01ms !important; }
}
```

Анимация должна быть *видна эксперту за 10 секунд*: hover на карточке, появление сообщения, открытие окна. Анимация, которую надо долго искать, может остаться незамеченной.
