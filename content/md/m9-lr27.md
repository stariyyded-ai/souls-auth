## Лекция

Создание заявки — главная функция портала для пользователя. Здесь встречаются почти все типы полей: текст (адрес), телефон, дата и время, выпадающий список из базы, «иное» значение и радиокнопки оплаты.

**Состав заявки (по нашей таблице `requests`):**

| Поле формы | Столбец | Откуда/как проверяем |
|---|---|---|
| — | `user_id` | **Из сессии**, никогда из формы |
| Адрес | `address` | Не пустой, до 255 символов |
| Контактный телефон | `phone` | Шаблон `+7(XXX)-XXX-XX-XX`; по умолчанию подставляем телефон из профиля |
| Дата и время | `date_time` | `datetime-local`, корректная дата, не в прошлом |
| Услуга | `service_id` | Должна существовать в справочнике `services` |
| Описание иной услуги | `custom_service` | Обязательно, если выбрана «Иная услуга», иначе `NULL` |
| Оплата | `payment` | Только `cash` или `card` |
| — | `status` | Ставит база: `DEFAULT 'new'` |
| — | `created_at` | Ставит база: `CURRENT_TIMESTAMP` |

**Список услуг — из базы, а не из HTML.** Если вписать услуги в `<option>` руками, то при добавлении услуги в справочник форма о ней не узнает. Поэтому выбираем их запросом и выводим циклом. Запрос без переменных — можно `query()`:

```php
<?php
$services = $pdo->query('SELECT id, name FROM services ORDER BY id')->fetchAll();
```

**Проверка выбранной услуги.** В `<select>` пользователь может через DevTools подставить любой `value`, например `999`. Поэтому проверяем, что такая услуга есть в списке, который мы только что получили из базы. Мы уже держим `$services` в памяти, так что второй запрос не нужен — достаточно найти услугу в массиве.

**«Иная услуга».** В справочнике есть строка «Иная услуга». Если пользователь выбрал её, поле «Опишите услугу» становится обязательным и сохраняется в `custom_service`. Если выбрана обычная услуга — `custom_service` записываем как `NULL`, даже если пользователь что-то туда ввёл.

**Дата и время.** Поле `<input type="datetime-local">` отправляет строку вида `2027-05-20T14:30`. В MySQL столбец `DATETIME` ждёт `2027-05-20 14:30:00`. Преобразуем через класс `DateTime`:

```php
<?php
$raw = '2027-05-20T14:30';
$dt  = DateTime::createFromFormat('Y-m-d\TH:i', $raw);

if (!$dt || $dt->format('Y-m-d\TH:i') !== $raw) {
    echo 'Некорректная дата';            // например, 2027-02-31T10:00
} elseif ($dt < new DateTime()) {
    echo 'Дата уже прошла';
} else {
    echo $dt->format('Y-m-d H:i:s');      // 2027-05-20 14:30:00 — для базы
}
```

Трюк с повторным `format()` и сравнением ловит «несуществующие» даты: PHP превратил бы 31 февраля в 3 марта, а мы такое отклоним. Чтобы время было правильным, в `config.php` полезно задать часовой пояс: `date_default_timezone_set('Europe/Moscow');` (или ваш регион).

**Оплата — радиокнопки.** Значения ключей берём из константы `PAYMENTS` (`cash`, `card`), подписи — её значения. Проверка: `array_key_exists($payment, PAYMENTS)`. Если не проверять, MySQL в нестрогом режиме молча запишет пустую строку в `ENUM`.

**Полный файл `request_new.php`:**

```php
<?php
require_once __DIR__ . '/includes/auth.php';
require_user();

$user = current_user();
$services = $pdo->query('SELECT id, name FROM services ORDER BY id')->fetchAll();

// Телефон из профиля — значение по умолчанию
$stmt = $pdo->prepare('SELECT phone FROM users WHERE id = ?');
$stmt->execute([$user['id']]);
$profilePhone = (string)$stmt->fetchColumn();

$errors = [];
$old = [
    'address'        => '',
    'phone'          => $profilePhone,
    'date_time'      => '',
    'service_id'     => '',
    'custom_service' => '',
    'payment'        => '',
];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    check_csrf();
    foreach (array_keys($old) as $field) {
        $old[$field] = post($field);
    }

    // Адрес
    if ($old['address'] === '' || mb_strlen($old['address']) > 255) {
        $errors['address'] = 'Укажите адрес (до 255 символов)';
    }

    // Телефон
    if (!preg_match('/^\+7\(\d{3}\)-\d{3}-\d{2}-\d{2}$/', $old['phone'])) {
        $errors['phone'] = 'Телефон в формате +7(XXX)-XXX-XX-XX';
    }

    // Дата и время
    $dt = DateTime::createFromFormat('Y-m-d\TH:i', $old['date_time']);
    if (!$dt || $dt->format('Y-m-d\TH:i') !== $old['date_time']) {
        $errors['date_time'] = 'Укажите дату и время';
    } elseif ($dt < new DateTime()) {
        $errors['date_time'] = 'Дата и время не могут быть в прошлом';
    }

    // Услуга: ищем выбранную среди услуг из базы
    $service = null;
    foreach ($services as $s) {
        if ((string)$s['id'] === $old['service_id']) {
            $service = $s;
        }
    }
    $customService = null;
    if ($service === null) {
        $errors['service_id'] = 'Выберите услугу из списка';
    } elseif ($service['name'] === 'Иная услуга') {
        if ($old['custom_service'] === '' || mb_strlen($old['custom_service']) > 255) {
            $errors['custom_service'] = 'Опишите, какая услуга нужна';
        }
        $customService = $old['custom_service'];
    }

    // Оплата
    if (!array_key_exists($old['payment'], PAYMENTS)) {
        $errors['payment'] = 'Выберите способ оплаты';
    }

    if (!$errors) {
        $stmt = $pdo->prepare(
            'INSERT INTO requests (user_id, address, phone, date_time, service_id, custom_service, payment)
             VALUES (?, ?, ?, ?, ?, ?, ?)'
        );
        $stmt->execute([
            $user['id'],
            $old['address'],
            $old['phone'],
            $dt->format('Y-m-d H:i:s'),
            $service['id'],
            $customService,
            $old['payment'],
        ]);
        redirect('requests.php?created=1');
    }
}

$title = 'Новая заявка';
require __DIR__ . '/includes/header.php';

// Класс и текст ошибки для поля
function invalid(string $f, array $errors): string
{
    return isset($errors[$f]) ? ' is-invalid' : '';
}
function error_text(string $f, array $errors): string
{
    return isset($errors[$f]) ? '<div class="invalid-feedback d-block">' . e($errors[$f]) . '</div>' : '';
}
?>
<div class="row justify-content-center">
<div class="col-md-8 col-lg-6">
    <h1 class="h3 mb-3">Новая заявка</h1>
    <form method="post" action="request_new.php">
        <?= csrf_field() ?>

        <div class="mb-3">
            <label class="form-label" for="address">Адрес</label>
            <input class="form-control<?= invalid('address', $errors) ?>" id="address" name="address"
                   value="<?= e($old['address']) ?>" required>
            <?= error_text('address', $errors) ?>
        </div>

        <div class="mb-3">
            <label class="form-label" for="phone">Контактный телефон</label>
            <input class="form-control<?= invalid('phone', $errors) ?>" id="phone" name="phone" type="tel"
                   value="<?= e($old['phone']) ?>" placeholder="+7(900)-123-45-67" required>
            <?= error_text('phone', $errors) ?>
        </div>

        <div class="mb-3">
            <label class="form-label" for="date_time">Желаемые дата и время</label>
            <input class="form-control<?= invalid('date_time', $errors) ?>" id="date_time" name="date_time"
                   type="datetime-local" value="<?= e($old['date_time']) ?>" required>
            <?= error_text('date_time', $errors) ?>
        </div>

        <div class="mb-3">
            <label class="form-label" for="service_id">Услуга</label>
            <select class="form-select<?= invalid('service_id', $errors) ?>" id="service_id" name="service_id" required>
                <option value="">— выберите услугу —</option>
                <?php foreach ($services as $s): ?>
                    <option value="<?= e($s['id']) ?>" <?= (string)$s['id'] === $old['service_id'] ? 'selected' : '' ?>>
                        <?= e($s['name']) ?>
                    </option>
                <?php endforeach; ?>
            </select>
            <?= error_text('service_id', $errors) ?>
        </div>

        <div class="mb-3">
            <label class="form-label" for="custom_service">Если выбрали «Иная услуга» — опишите её</label>
            <input class="form-control<?= invalid('custom_service', $errors) ?>" id="custom_service"
                   name="custom_service" value="<?= e($old['custom_service']) ?>">
            <?= error_text('custom_service', $errors) ?>
        </div>

        <fieldset class="mb-3">
            <legend class="form-label fs-6">Способ оплаты</legend>
            <?php foreach (PAYMENTS as $value => $label): ?>
                <div class="form-check">
                    <input class="form-check-input" type="radio" name="payment" id="pay_<?= e($value) ?>"
                           value="<?= e($value) ?>" <?= $old['payment'] === $value ? 'checked' : '' ?> required>
                    <label class="form-check-label" for="pay_<?= e($value) ?>"><?= e($label) ?></label>
                </div>
            <?php endforeach; ?>
            <?= error_text('payment', $errors) ?>
        </fieldset>

        <button class="btn btn-primary w-100" type="submit">Отправить заявку</button>
    </form>
</div>
</div>
<?php require __DIR__ . '/includes/footer.php'; ?>
```

Что здесь важно.

- `user_id` берётся из сессии: `$user['id']`. Если бы он шёл из скрытого поля, пользователь мог бы создавать заявки «от имени» другого.
- `selected` и `checked` восстанавливают выбор после ошибки — пользователь не выбирает всё заново.
- В `INSERT` нет `status` и `created_at` — их заполнит база значениями по умолчанию. Меньше кода — меньше ошибок.
- `invalid-feedback d-block` — для радиокнопок Bootstrap не всегда показывает ошибку автоматически, `d-block` делает её видимой.

**Типичные ошибки.**

- `SQLSTATE[23000]: ... a foreign key constraint fails` — в `service_id` попало значение, которого нет в `services`, или `user_id` пустой (страница не защищена `require_user()`).
- `Incorrect datetime value: '2027-05-20T14:30'` — забыли преобразовать формат через `DateTime`.
- Услуга «Иная» сохраняется без описания — проверка сравнивает название с опечаткой (`Иная услуга` в базе и в коде должны совпадать буква в букву).
- После отправки F5 создаёт дубликат — нет редиректа после `INSERT`.
- Время сохраняется со сдвигом на несколько часов — не задан `date_default_timezone_set`.

**Связь с экзаменом.** По ТЗ пользователь формирует заявку, указывая адрес, контакты, дату и время, вид услуги (с возможностью указать иную) и тип оплаты. Эксперт проверит, что заявка появилась в истории пользователя и в панели админа со статусом «Новая», а также попробует отправить форму с пустыми полями.

## Если не успел / для сильных

**Минимум для зачёта:** заявка сохраняется с услугой из справочника, датой и оплатой, `user_id` из сессии.
**Для сильных:** запретите время вне рабочих часов (например, раньше 9:00 и позже 20:00) и даты дальше чем через 3 месяца.
