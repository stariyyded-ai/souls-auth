## Лекция

**Зачем эта разминка.** Вы уже «проходили» HTML и CSS, но на экзамене у вас не будет времени гуглить, почему кнопка вылезла за край экрана. Сегодня мы освежим четыре вещи, на которых держится любая страница портала: семантические теги, блочную модель, Flexbox и Grid. Если эти четыре кирпича лежат ровно, остальное (формы, карточки, адаптив) строится быстро.

**1. Семантика: теги со смыслом.** Можно сверстать всю страницу из одних `<div>`, и браузер её покажет. Но тогда ни поисковик, ни экранный диктор для незрячих, ни ваш одногруппник, который будет проверять код, не поймут, где шапка, где меню, а где главное содержимое. Семантические теги говорят, *что* это за блок:

- `<header>` — шапка страницы (логотип, название портала);
- `<nav>` — навигация (ссылки «Мои заявки», «Новая заявка», «Выход»);
- `<main>` — главное содержимое, на странице он один;
- `<section>` — смысловой раздел с заголовком;
- `<article>` — самостоятельный блок, который можно «вырезать» и он не потеряет смысла: например, карточка одной заявки;
- `<footer>` — подвал (контакты, копирайт);
- `<h1>`–`<h6>` — заголовки по уровням, `<h1>` на странице один.

Пример каркаса страницы «Мои заявки»:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Мои заявки — ЧистоДом</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <header class="header">
    <a href="requests.html" class="logo">ЧистоДом</a>
    <nav class="nav">
      <a href="new-request.html">Новая заявка</a>
      <a href="index.html">Выход</a>
    </nav>
  </header>

  <main class="page">
    <h1>Мои заявки</h1>
    <article class="request-card">
      <h2>Генеральная уборка</h2>
      <p>12.11.2026, 10:00 · ул. Ленина, 5</p>
    </article>
  </main>

  <footer class="footer">© 2026 ЧистоДом</footer>
</body>
</html>
```

Обратите внимание на строку `<meta name="viewport" ...>`. Без неё телефон «думает», что страница рассчитана на компьютер, и уменьшает её до нечитаемой мелочи. Для мобильного портала 390×844 это строка номер один.

**2. Блочная модель.** Каждый элемент на странице — прямоугольник из четырёх слоёв: содержимое (content), внутренний отступ (padding), рамка (border) и внешний отступ (margin). Представьте посылку: товар — это content, пупырчатая плёнка — padding, картонная коробка — border, а расстояние до соседней коробки на складе — margin.

Главная ловушка: по умолчанию `width` задаёт ширину *только содержимого*. Если написать `width: 100%; padding: 16px;`, элемент станет шире родителя на 32px, и на телефоне появится горизонтальная прокрутка — классическая потеря балла за «кривой» интерфейс. Лечится одной строкой, которую стоит ставить в начало каждого проекта:

```css
*,
*::before,
*::after {
  box-sizing: border-box;   /* width включает padding и border */
}

body {
  margin: 0;                /* убираем отступ браузера по умолчанию */
  font-family: system-ui, sans-serif;
  line-height: 1.5;
}
```

Ещё одна особенность — **схлопывание внешних отступов**: если у абзаца `margin-bottom: 20px`, а у следующего `margin-top: 30px`, расстояние между ними будет 30px, а не 50px. Чтобы не путаться, договоритесь с собой задавать вертикальные отступы только в одну сторону, например только `margin-bottom`, или использовать `gap` во Flexbox/Grid.

**3. Flexbox — раскладка в одну линию.** Flexbox нужен, когда элементы надо выстроить в строку или столбец и выровнять. Шапка «логотип слева, меню справа» — идеальный случай:

```css
.header {
  display: flex;                    /* включаем flex у родителя */
  justify-content: space-between;   /* по главной оси: края */
  align-items: center;              /* по поперечной оси: по центру */
  gap: 16px;                        /* расстояние между детьми */
  padding: 12px 16px;
  background: #0f766e;
  color: #fff;
}

.nav {
  display: flex;
  gap: 12px;
}
```

Запомните пару: `justify-content` — вдоль главной оси (по умолчанию горизонталь), `align-items` — поперёк неё. Если поставить `flex-direction: column`, оси меняются местами — и именно это чаще всего путают. Ещё два полезных свойства: `flex-wrap: wrap` (переносить элементы на новую строку, если не помещаются) и `flex: 1` у ребёнка (занять всё свободное место — например, поле поиска рядом с кнопкой).

Форма на телефоне — тоже flex, только колонкой:

```css
.form {
  display: flex;
  flex-direction: column;
  gap: 16px;              /* одинаковый шаг между полями, кратный 8 */
}
```

**4. Grid — раскладка сеткой.** Grid нужен, когда есть и строки, и столбцы одновременно. Например, в карточке заявки слева подписи («Дата», «Адрес», «Оплата»), справа значения:

```css
.request-info {
  display: grid;
  grid-template-columns: 100px 1fr;  /* 100px под подпись, остальное — значению */
  gap: 4px 12px;                     /* строки 4px, столбцы 12px */
}
```

```html
<dl class="request-info">
  <dt>Дата</dt>    <dd>12.11.2026, 10:00</dd>
  <dt>Адрес</dt>   <dd>ул. Ленина, 5, кв. 12</dd>
  <dt>Оплата</dt>  <dd>Наличными</dd>
</dl>
```

Единица `fr` — «доля свободного места». `1fr 1fr` — две равные колонки, `2fr 1fr` — левая вдвое шире. Очень полезна запись `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`: на телефоне получится одна колонка карточек, на планшете две, на компьютере три — без единого media query.

**Flex или Grid?** Простое правило: если думаете «в ряд» или «в столбик» — Flexbox; если думаете «таблицей» — Grid. Они не враги: страница может быть Grid, шапка внутри — Flex, кнопки в карточке — снова Flex.

**Как искать ошибки раскладки.** В DevTools во вкладке Elements рядом с элементами, у которых `display: flex` или `grid`, есть значок-кнопка `flex`/`grid`. Нажмите её — и браузер нарисует поверх страницы оси, колонки и промежутки. Это самый быстрый способ понять, почему элемент «уехал».

**Типичные ошибки:**

1. Забыли `<meta name="viewport">` — на телефоне всё мелкое.
2. Нет `box-sizing: border-box` — поля и кнопки вылезают за край.
3. `display: flex` поставили ребёнку, а не родителю. Flex и Grid всегда включаются у **контейнера**.
4. Страница из сплошных `<div>` и `<br>` вместо отступов.
5. Несколько `<h1>` на странице или заголовки «через уровень» (`h1` → `h4`) ради размера шрифта. Размер меняют в CSS, а уровень заголовка — это смысл.
6. Отступы «на глаз»: 13px, 17px, 22px. В модуле 2 вы договорились о шаге 8pt — значит, 8, 16, 24, 32.

**Как это связано с экзаменом.** Все пять страниц портала (регистрация, вход, мои заявки, новая заявка, админ-панель) — это шапка на Flexbox, колонка формы на Flexbox и список карточек на Grid или Flexbox. Если вы уверенно владеете этими тремя приёмами, вёрстка одной страницы по макету занимает 10–15 минут, а не час. Проверьте себя DevTools: включите режим устройства (Ctrl+Shift+M), выберите iPhone 12 Pro (это как раз 390×844) и убедитесь, что нет горизонтальной прокрутки.
