# Пепельный Пиксель — вход и регистрация

Вёрстка страниц авторизации и регистрации в пиксельном стиле с элементами Souls: склеп, костёр, руны, затмение, готические рамки и баннеры «КОСТЁР ЗАЖЖЁН» / «ВЫ ПОГИБЛИ».

Макет в Figma: https://www.figma.com/design/moDxOqbZLMUTl4PL1uOSHc

## Страницы

| Файл | Что на странице |
| --- | --- |
| `index.html` | Вход. При успехе окно рассыпается на пиксельные кубики и открывается главная. Пароль короче 4 символов показывает «ВЫ ПОГИБЛИ». |
| `register.html` | Регистрация. После нажатия «Зарегистрироваться» слизняк в кнопке уползает в дверь, затем открывается вход с подставленным именем. |
| `home.html` | Заглушка главной страницы. |
| `cabinet.html` | Личный кабинет студента: уровень (Новичок → Джун → Мидл → Сеньор) и опыт до следующего, прогресс курса и модулей полосами HP/XP, баланс душ, достижения с редкостью и датами, история заданий с фильтром, группа и доступные курсы. После входа открывается он. |
| `admin.html` | Админ-панель: дашборд, пользователи, группы, задания, лекции, достижения, магазин, логи. Подробности ниже. |

## Как запустить

Сборка не нужна. Откройте `index.html` в браузере или запустите любой статический сервер:

```bash
npx serve .
# или
python -m http.server 8000
```

## Структура

```
css/style.css   общие стили: палитра, стеклянная панель, поля, кнопки, баннеры
js/common.js    пиксельные спрайты (SVG из сеток), баннеры, переходы между страницами
js/sound.js     8-битные звуки на Web Audio и переключатель «звук вкл/выкл»
js/scene.js     фон на canvas: замок, затмение, костёр, искры, пепел
js/shatter.js   разрушение окна на кубики
js/login.js     логика входа
js/register.js  логика регистрации и анимация слизняка
js/home.js      приветствие на главной
js/data.js      пример данных студента для кабинета (позже заменится ответом сервера)
js/cabinet.js   отрисовка кабинета из данных
css/cabinet.css стили кабинета
js/icons.js     пиксельные иконки и редкости достижений (общие для кабинета и админки)
js/admin-data.js   демо-данные админки
js/admin-store.js  хранилище: изменения в localStorage + журнал событий
js/admin.js        каркас админки, дашборд, пользователи, логи
js/admin-crud.js   группы, задания, лекции, достижения, магазин (схемы + общий CRUD)
css/admin.css      стили админки
```

Шрифты: Cormorant SC (заголовки) и Pixelify Sans (интерфейс) из Google Fonts.

Сервера нет: вход и регистрация всегда проходят успешно, имя персонажа передаётся между страницами через `sessionStorage`. Места для настоящих запросов помечены в `js/login.js` и `js/register.js`.

## Админ-панель

Открывается по адресу `admin.html` (ссылка «Админка» в шапке кабинета). Разделы переключаются по адресу: `admin.html#users`, `#groups`, `#tasks`, `#lectures`, `#achievements`, `#shop`, `#logs`.

- **Дашборд:** активные за 7 дней, график активности по дням, средний прогресс по модулям, топ-5 студентов, последние покупки, счётчик ошибок автопроверки.
- **Пользователи:** поиск по имени и e-mail, фильтры по роли и группе, сортировка, смена роли прямо в таблице, карточка пользователя, сброс прогресса, ручная выдача достижения (с начислением душ).
- **Группы:** создание, изменение, удаление; курсы и модули группы, дедлайн, квота студентов (с предупреждением при превышении).
- **Задания, лекции, достижения, магазин:** создание, изменение, удаление, предпросмотр «как увидит студент», настройка опыта, душ, попыток, условий получения достижений, цен и остатков.
- **Логи:** действия пользователей, ошибки автопроверки, транзакции; фильтр по типу и поиск.

Каждое изменение в админке записывается в логи. Сервера пока нет: данные лежат в `localStorage` браузера, кнопка «Сбросить демо-данные» возвращает исходные примеры. Чтобы подключить API, достаточно заменить загрузку и сохранение в `js/admin-store.js`.

## Звук

Все звуки синтезируются в браузере через Web Audio API, аудиофайлов нет: клик по кнопкам и ссылкам, ошибка в форме, звон разбитого окна, «КОСТЁР ЗАЖЖЁН», «ВЫ ПОГИБЛИ», скрип двери и шлепки слизняка. Звук включается после первого клика (так требуют браузеры). Кнопка «ЗВУК ВКЛ» в шапке выключает его, выбор запоминается.

Анимации учитывают настройку «уменьшить движение» (`prefers-reduced-motion`).
